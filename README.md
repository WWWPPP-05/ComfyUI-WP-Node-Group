# 🐳 WP Node Group

WP Node Group 是一个 ComfyUI 自定义节点包，包含 9 个实用节点，涵盖图像加载、提示词管理、分辨率选择、图像分割、AI API 调用、资产库管理、本地 LLM 推理和注释编辑等功能。

## 版本信息

- **当前版本**: v1.5.0
- **更新日志**:
  - ✅ 新增注释节点（🐳 WP 注释节点）
  - ✅ 支持双击编辑文本内容
  - ✅ 支持文字对齐、颜色、大小、行距调节
  - ✅ 支持背景颜色、透明度、圆角调节

## 节点列表

### 1. 🐳 加载图像 (WP\_ImageLoad)

完全复刻 ComfyUI 原生 LoadImage 功能，并新增按边缩放特性。

**功能特性：**

- 从输入目录加载图像文件
- 支持 JPG、PNG、GIF、WebP 等多种格式
- 支持 GIF 多帧图像
- 支持 EXIF 旋转自动校正
- **新增**: 支持按边缩放图像和遮罩

**输入参数：**

| 参数      | 类型      | 说明                     |
| ------- | ------- | ---------------------- |
| `image` | 文件选择    | 图像文件选择（支持上传）           |
| `尺寸`    | INT     | 目标尺寸（默认 512，范围 1-8192） |
| `模式`    | BOOLEAN | 缩放模式开关                 |

**缩放模式说明：**

- **max 模式**（开启，默认）: 将图像**长边**缩放到指定尺寸
- **min 模式**（关闭）: 将图像**短边**缩放到指定尺寸

**输出：**

| 端口   | 类型    | 说明                           |
| ---- | ----- | ---------------------------- |
| `图像` | IMAGE | 加载的图像张量                      |
| `遮罩` | MASK  | Alpha 通道遮罩（无 Alpha 通道则返回空遮罩） |
| `宽`  | INT   | 图像宽度                         |
| `高`  | INT   | 图像高度                         |

**使用示例：**

假设有一张 1024×768 的图像，设置 `尺寸 = 512`：

| 模式  | 结果尺寸    | 说明                           |
| --- | ------- | ---------------------------- |
| max | 512×384 | 长边 1024→512，短边 768 按比例变为 384 |
| min | 682×512 | 短边 768→512，长边 1024 按比例变为 682 |

### 2. 🐳 WP 提示词预设 (WP\_PromptPreset)

储存和管理提示词预设，支持分组管理和增删改功能。

**功能特性：**

- 支持按分组管理提示词预设
- 提供新增、编辑、删除预设的 UI 界面
- 支持分组管理（添加、删除、重命名分组）
- 预设数据保存在项目根目录的 `prompt_presets.json` 文件中
- 节点创建时自动加载预设列表
- 分组切换时自动过滤显示对应预设

**输入参数：**

| 参数   | 类型   | 说明         |
| ---- | ---- | ---------- |
| `分组` | 下拉选择 | 选择预设所属分组   |
| `预设` | 下拉选择 | 选择具体的提示词预设 |

**输出：**

| 端口    | 类型     | 说明       |
| ----- | ------ | -------- |
| `提示词` | STRING | 选中的提示词内容 |

**内置按钮：**

- ➕ **新增**: 添加新的提示词预设
- ✏️ **编辑**: 编辑当前选中的预设
- ️ **删除**: 删除当前选中的预设

**预设分组示例：**

- 风格提示词
- 少女写真
- 画风
- 🐳 文本处理指令
- 🐳 图像处理指令
- NSFW 图像

### 3. 🐳 分辨率选择器 (WP\_ResolutionSelector)

支持预设分辨率和自定义分辨率两种模式，统一管理 AI 绘画的图像分辨率输出。

**功能特性：**

- 提供 27 个常用 AI 绘画预设分辨率
- 支持自定义分辨率输入
- 覆盖常见比例：1:1、16:9、9:16、3:2、2:3 等
- 支持横屏、竖屏、方形多种比例

**输入参数：**

| 参数         | 类型      | 说明                   |
| ---------- | ------- | -------------------- |
| `使用自定义分辨率` | BOOLEAN | 开关：开启使用自定义，关闭使用预设    |
| `预设分辨率`    | 下拉选择    | 27 个预设分辨率选项          |
| `自定义宽度`    | INT     | 自定义宽度（64-8192，步长 64） |
| `自定义高度`    | INT     | 自定义高度（64-8192，步长 64） |

**输出：**

| 端口   | 类型  | 说明    |
| ---- | --- | ----- |
| `宽度` | INT | 输出宽度值 |
| `高度` | INT | 输出高度值 |

**预设分辨率列表（部分）：**

| 分辨率       | 比例   | 方向 |
| --------- | ---- | -- |
| 512×512   | 1:1  | 方形 |
| 512×768   | 2:3  | 竖屏 |
| 854×480   | 16:9 | 横屏 |
| 1024×1024 | 1:1  | 方形 |
| 1080×1920 | 9:16 | 竖屏 |
| 1920×1080 | 16:9 | 横屏 |
| 2048×3072 | -    | 竖屏 |
| 3072×2048 | -    | 横屏 |

### 4. 🐳 自动分割图像 (WP\_ImageSplit)

将大图均匀分割为网格小图，支持可选自动保存、移除画布边缘和移除描边。

**功能特性：**

- 网格均匀分割：支持任意 N×M 网格分割
- 批量处理：支持单张或批量图像输入
- 自动裁剪：移除描边、移除画布边缘（透明区域）
- 可选保存：可保存到本地，也可仅输出给下游节点
- 多格式支持：PNG / JPG / WEBP

**输入参数：**

| 参数       | 类型      | 默认值    | 说明               |
| -------- | ------- | ------ | ---------------- |
| `图像`     | IMAGE   | -      | 输入图像（支持批量）       |
| `保存到本地`  | BOOLEAN | True   | 是否保存文件到本地        |
| `保存目录`   | STRING  | output | 保存路径（支持相对路径）     |
| `水平张数`   | INT     | 2      | 水平方向分割列数（1-16）   |
| `垂直张数`   | INT     | 2      | 垂直方向分割行数（1-16）   |
| `移除画布边缘` | BOOLEAN | True   | 裁剪透明区域           |
| `移除描边`   | INT     | 0      | 四周裁剪像素数（0-100）   |
| `文件名前缀`  | STRING  | 图像分割\_ | 保存文件名前缀          |
| `保存格式`   | 下拉选择    | PNG    | PNG / JPG / WEBP |

**输出：**

| 端口     | 类型    | 说明            |
| ------ | ----- | ------------- |
| `分割图像` | IMAGE | 所有小图组成的批量图像张量 |

**使用示例：**

将 1024×1024 图像分割为 2×2 网格：

- 水平张数: 2
- 垂直张数: 2
- 结果: 生成 4 张 512×512 的小图

### 5. 🐳 WP\_API 调用工具 (WP\_WhaleAPI)

调用外部兼容 OpenAI 协议的大模型 API 进行文本处理或图像分析。

**功能特性：**

- 支持图片模式：多模态图像理解（最多 3 张图片）
- 支持文本模式：纯文本对话
- 兼容所有 OpenAI 协议 API
- **新增**: 自动图片缩放（超过 2048 像素自动缩放）
- 支持自定义系统提示词和用户提示词
- 支持设置随机种子控制输出稳定性

**支持的平台：**

- **OpenAI**: <https://api.openai.com/v1/chat/completions>
- **ModelScope（魔搭社区）**: <https://api-inference.modelscope.cn/v1/chat/completions>
- 其他兼容 OpenAI 协议的 API 服务

**魔搭社区说明：**

- 免费额度：每个模型每天 500 次，总 2000 次/天
- 需绑定阿里云账号获取 API Key
- 支持视觉模型和文本模型

**输入参数：**

| 参数                | 类型     | 默认值        | 说明                     |
| ----------------- | ------ | ---------- | ---------------------- |
| `mode`            | 下拉选择   | 图片         | 图片模式 / 文本模式            |
| `image`           | IMAGE  | 可选         | 第 1 张输入图片              |
| `image_2`         | IMAGE  | 可选         | 第 2 张输入图片              |
| `image_3`         | IMAGE  | 可选         | 第 3 张输入图片              |
| `prompt_template` | STRING | 请描述这张图片    | 用户提示词模板                |
| `system_prompt`   | STRING | 你是一个有用的助手  | 系统提示词                  |
| `api_url`         | STRING | OpenAI 地址  | API 端点 URL             |
| `api_key`         | STRING | -          | API 密钥（密码输入）           |
| `model`           | STRING | gpt-4o     | 模型名称                   |
| `seed`            | INT    | 1426415715 | 随机种子（0-9999999999）     |
| `max_tokens`      | INT    | 3000       | 最大输出 token 数（1-100000） |

**输出：**

| 端口     | 类型     | 说明          |
| ------ | ------ | ----------- |
| `text` | STRING | API 返回的文本结果 |

**常用模型示例：**

| 平台         | 模型名称                             | 类型 |
| ---------- | -------------------------------- | -- |
| OpenAI     | gpt-4o                           | 视觉 |
| OpenAI     | gpt-4o-mini                      | 视觉 |
| ModelScope | Qwen/Qwen3-VL-235B-A22B-Instruct | 视觉 |
| ModelScope | deepseek-ai/DeepSeek-V3.1        | 文本 |

**自动缩放说明：**

API 对图片尺寸有限制（通常最大 2048×2048），本节点会：

- 自动检测图片尺寸
- 如果任意一边超过 2048 像素，自动等比例缩放
- 使用高质量 LANCZOS 缩放算法
- 在控制台显示缩放信息

### 6. 🐳 导入资产库 (WP\_SaveToLibrary)

将生成的图像保存到资产库，支持按项目、分类进行组织管理。

**功能特性：**

- 项目/分类/资产三级层级结构
- 支持右键菜单将生成图像快速导入资产库
- 支持双击资产导出到画布
- 支持本地文件扫描同步
- 支持上传本地图片
- 悬浮按钮快速打开资产库面板
- 缩略图内存缓存，不占用磁盘空间

**使用方式：**

1. 在节点上右键生成图像 → 选择"保存到资产库"
2. 或使用 WP\_SaveToLibrary 节点直接导入
3. 点击右下角"🐳 资产库"悬浮按钮打开管理面板

**资产库面板功能：**

- 项目管理：新建、重命名、删除项目
- 分类管理：新建、重命名、删除分类
- 资产管理：搜索、上传、扫描、导出、删除
- 支持项目/分类右键操作

- 分类右键：重命名、删除分类

- 本地扫描：检测新增图片并自动入库

### 8. 🐳 WP 模型加载器 (WP\_LlamaLoader)

加载 Qwen3-VL / Qwen3.5-VL 多模态模型到本地 llama-cpp-python 推理引擎。

**功能特性：**

- 支持 Qwen3-VL 和 Qwen3.5-VL 两大视觉模型系列
- 支持 GPU 加速（CUDA）
- 可配置 KV 缓存类型（F16 / q8\_0）
- 可调整上下文长度和 GPU 层数
- 模型加载后自动缓存，避免重复加载

**输入参数：**

| 参数           | 类型      | 默认值        | 说明                                   |
| ------------ | ------- | ---------- | ------------------------------------ |
| `模型系列`       | 下拉选择    | Qwen3.5-VL | Qwen3-VL / Qwen3.5-VL                |
| `主模型`        | 下拉选择    | —          | 主模型文件（.gguf）放到 `ComfyUI/models/LLM/` |
| `视觉投影mmproj` | 下拉选择    | 无          | 多模态需要 mmproj 文件；纯文本可选"无"             |
| `启用思考`       | BOOLEAN | False      | 是否启用模型思考过程                           |
| `上下文长度`      | INT     | 8192       | 对应 llama.cpp 的 n\_ctx（1024-327680）   |
| `GPU层数`      | INT     | -1         | -1=尽可能多上GPU；0=纯CPU                   |
| `KV缓存K类型`    | 下拉选择    | 默认(F16)    | F16 或 q8\_0                          |
| `KV缓存V类型`    | 下拉选择    | 默认(F16)    | F16 或 q8\_0                          |

**输出：**

| 端口       | 类型        | 说明               |
| -------- | --------- | ---------------- |
| `qwen模型` | QWENLLAMA | 加载后的模型对象，连接到推理节点 |

**模型放置：**
将 `.gguf` 模型文件和 `mmproj` 文件放到 `ComfyUI/models/LLM/` 目录，重启 ComfyUI 后即可在节点中选择。

### 9. 🐳 WP 推理节点 (WP\_LlamaInference)

使用已加载的 Qwen3 / Qwen3.5 VL 模型进行图像、视频和文本推理。

**功能特性：**

- 四种输入模式：图片、逐帧、视频、文本
- 图片模式：只读取第 1 张图片
- 逐帧模式：逐张推理，支持多帧独立输出
- 视频模式：从图片序列中均匀抽帧
- 文本模式：纯文字对话，无需图片
- 支持 Think 块输出控制
- 完整的采样参数控制（温度、top\_p、top\_k 等）

**输入参数：**

| 参数          | 类型        | 默认值  | 说明                    |
| ----------- | --------- | ---- | --------------------- |
| `qwen模型`    | QWENLLAMA | —    | 连接模型加载器的输出            |
| `输入模式`      | 下拉选择      | 图片   | 图片 / 逐帧 / 视频 / 文本     |
| `提示词`       | STRING    | —    | 用户提示词                 |
| `系统提示词`     | STRING    | —    | 系统提示词                 |
| `图片`        | IMAGE     | 可选   | 输入图片/图片序列             |
| `最多帧数`      | INT       | 24   | 视频模式下抽取的帧数（2-1024）    |
| `最大边长`      | INT       | 512  | 图片缩放最大边长（128-16384）   |
| `最大生成token` | INT       | 1024 | 最大输出 token 数（20-8192） |
| `温度`        | FLOAT     | 0.7  | 温度控制随机性（0.0-2.0）      |
| `top_p`     | FLOAT     | 0.9  | 核采样参数（0.0-1.0）        |
| `top_k`     | INT       | 20   | Top-K 采样参数（0-200）     |
| `重复惩罚`      | FLOAT     | 1.0  | 重复内容惩罚（0.5-2.0）       |
| `频率惩罚`      | FLOAT     | 0.0  | 频率惩罚（0.0-2.0）         |
| `存在惩罚`      | FLOAT     | 0.0  | 存在惩罚（0.0-2.0）         |
| `seed`      | INT       | 0    | 随机种子                  |
| `输出think块`  | BOOLEAN   | True | 是否保留模型思考过程输出          |

**输出：**

| 端口   | 类型     | 说明        |
| ---- | ------ | --------- |
| `文本` | STRING | 模型生成的推理结果 |

**依赖安装：**

```bash
pip install llama-cpp-python
```

如需 GPU 加速：

```bash
CMAKE_ARGS="-DLLAMA_CUDA=on" pip install llama-cpp-python --force-reinstall --no-cache-dir
```

### 10. 🐳 WP 注释节点 (WP\_Annotate)

在工作流中添加带样式的注释框，用于标注说明、提示信息或备注。

**功能特性：**

- 双击编辑文本内容
- 支持左对齐、居中、右对齐
- 支持文本颜色调节
- 支持文字大小调节（1-100）
- 支持文字行距调节（1.0-3.0）
- 支持背景颜色调节（默认紫色）
- 支持背景透明度调节（0%-100%）
- 支持背景圆角调节（0-300）
- 支持描边开关
- 智能中英文混排自动换行
- 链接解析支持（`[[链接]]`、http/https、[www](http://www). 格式）

**使用方法：**

1. 在节点列表中找到"🐳 WP 注释节点"添加到工作流
2. 双击节点打开编辑界面
3. 在工具栏中调整对齐方式、文本颜色/大小、背景颜色/透明度/圆角、行距
4. 在文本框中输入内容
5. 按 Ctrl+Enter 保存，或点击外部区域自动保存
6. 拖动节点边角可调整大小

**编辑工具栏：**

| 控件   | 范围      | 默认值          | 说明       |
| ---- | ------- | ------------ | -------- |
| 对齐   | 左/中/右   | 居中           | 文字对齐方式   |
| 描边   | 开/关     | 开            | 是否显示边框描边 |
| 文本颜色 | 任意颜色    | 白色 (#ffffff) | 文字颜色     |
| 文字大小 | 1-100   | 16           | 字体大小（像素） |
| 背景颜色 | 任意颜色    | 紫色 (#662ad5) | 背景填充色    |
| 透明度  | 0%-100% | 100%         | 背景不透明度   |
| 圆角   | 0-300   | 30           | 背景圆角半径   |
| 行距   | 1.0-3.0 | 1.4          | 文字行间距    |

## 安装方法

### 方法一：手动安装

1. 将本文件夹复制到 `ComfyUI/custom_nodes/` 目录下
2. 安装依赖（可选，ComfyUI 通常已包含）：
   ```bash
   pip install requests>=2.28.0
   ```
3. 重启 ComfyUI

### 方法二：通过 ComfyUI Manager 安装

1. 打开 ComfyUI Manager
2. 点击 "Install Custom Nodes"
3. 搜索 "WP Node Group" 并安装
4. 重启 ComfyUI

## 常见问题

### Q1: 节点标题栏字体颜色不显示为白色？

**A**: 请确保已重启 ComfyUI。前端扩展需要重启才能生效。

### Q2: API 调用返回 "input size exceed limit" 错误？

**A**: v1.1.0 已修复此问题，节点会自动缩放超过 2048 像素的图片。如果仍报错，请升级到最新版本。

### Q3: 提示词预设节点的分组切换后预设列表为空？

**A**: 请检查 `prompt_presets.json` 文件是否正确保存，并确保分组名称与节点中的一致。

### Q4: 图像分割节点保存的图片找不到？

**A**: v1.1.0 已修复相对路径处理。如果保存目录不是 "output"，请输入绝对路径。

### Q5: 如何修改节点颜色？

**A**: 编辑 `js/node_color.js` 文件中的 `HEADER_COLOR` 和 `TITLE_TEXT_COLOR` 变量，然后重启 ComfyUI。

### Q6: 资产库缩略图不显示？

**A**: 可能是 PNG 图片带有透明通道。v1.2.0 已自动兼容 PNG 透明通道，请确保已重启 ComfyUI。

### Q7: 资产库面板怎么打开？

**A**: 点击 ComfyUI 画布右下角的"🐳 资产库"紫色悬浮按钮即可打开。

### Q8: 如何把生成的图像保存到资产库？

**A**: 右键点击节点上的图像 → 选择"保存到资产库"，或在节点列表中搜索"🐳 导入资产库"节点。

### Q9: 如何把资产库的图片拖到加载图像节点？

**A**: 从资产库面板拖拽图片到画布上已有的"加载图像"节点上，松开鼠标即可替换图片。支持原生 LoadImage 和 WP\_ImageLoad 节点。

### Q10: 资产库面板的排序按钮怎么用？

**A**: 点击搜索框右侧的灰色圆形排序按钮，可切换升序（A-Z）和降序（Z-A）排列，再次点击切换排序方向。
