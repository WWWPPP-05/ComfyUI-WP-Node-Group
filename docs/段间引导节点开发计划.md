# ComfyUI H3 分段衔接工具包 开发计划文档

**版本**：V1.1 MVP 修订版 **适用场景**：本地部署 MiniMax H3 模型的多段独立采样 + 无缝衔接 + 潜空间级最终拼接 **编程交付对象**：Trae AI 编程辅助 **核心特性**：原生能力兼容、极低显存开销、极简参数、模块化解耦

## 修订说明

本次修订基于 V1.0 版本补充核心逻辑、优化交互与验收标准，核心变更如下：

1. 新增段间重叠帧自动裁剪机制，解决硬拼接导致的重复帧、运动卡顿问题
2. 新增潜空间可选加权融合能力，以极低计算成本提升拼接容错性
3. 补全 VAE 局部解码时空维度对齐适配与直通模式零值条件兜底
4. 完善音频格式校验、静音补全与音画同步过渡逻辑
5. 优化前端交互：动态端口支持删除与排序、全参数 Tooltip 说明、参数联动校验
6. 补充边界场景测试用例与客观量化验收指标
7. 细化显存优化策略，明确显存统计口径与多分辨率参考

## 一、项目概述

### 1.1 项目目标

开发一套由两个独立节点组成的工具包，实现 MiniMax H3 多段视频的「段间时序引导衔接 + 末端潜空间拼接」全流程。全程基于官方原生能力，不魔改采样器、不侵入模型结构，在保证衔接效果的同时最大化降低显存占用与使用门槛，解决长视频分段生成中的重复帧、运动断层、多次编解码画质损耗等核心痛点。

### 1.2 核心设计原则

#### 显存负担最小化

- 段间衔接仅解码尾部指定帧数潜空间，不全段解码，单节点新增峰值显存 < 200MB（1080p 分辨率下，不含模型常驻显存）
- 末端拼接采用潜空间级拼接，全程仅一次最终解码，避免多次编解码损耗与冗余显存占用
- 所有中间张量即用即释放，无常驻冗余缓存；关键节点支持手动触发显存回收
- 局部 VAE 解码默认启用半精度计算，进一步压缩显存开销

#### 参数极简主义

- 主界面核心参数 ≤ 2 个，普通用户零学习成本，默认参数即可达到最优效果
- 高阶参数默认折叠收纳，仅专业用户按需调整
- 拼接节点支持动态增删输入段，操作符合直觉，支持单段删除与顺序调整

#### 逻辑完整可追溯

- 所有衔接逻辑完全参考 AIMixer 导演台成熟方案，基于 H3 原生 Ref2VA 通路实现
- 潜空间拼接遵循扩散模型标准张量操作规范，无自研黑盒算法
- 重叠帧裁剪、加权融合均为行业通用方案，逻辑透明可验证
- 每一步输入输出均有明确的数据格式与校验逻辑，异常场景可定位

#### 高兼容性

- 100% 兼容官方原生 H3 采样节点、VAE 节点、条件编码节点
- 不修改原有工作流结构，旁路式接入，可随时移除/添加
- 两个节点完全解耦，可单独使用，也可组合使用
- 输出格式兼容所有原生/第三方后处理节点、导出节点

### 1.3 技术参考依据

- AIMixer/ComfyUI\_MiniMaxH3\_Director 段间引导成熟方案：尾部上下文提取 + 参考条件注入 + 时序权重衰减
- MiniMax H3 官方 Reference to Video (Ref2VA) 原生条件编码机制
- 扩散模型潜空间球面分布特性与标准拼接规范
- 视频生成领域通用自回归分段上下文传递范式
- 音视频拼接行业通用淡入淡出与同步对齐标准

## 二、节点组成与整体工作流

### 2.1 节点清单

- **H3SegmentBridge（段间衔接节点）**
  - 功能定位：纯条件转换工具节点，本身不执行采样推理
  - 核心作用：提取上一段尾部潜空间特征，编码为 H3 标准参考条件，注入下一段采样，实现段间无缝衔接
- **H3LatentConcat（潜空间拼接节点）**
  - 功能定位：末端通用拼接节点，潜空间维度完成多段视频合并
  - 核心作用：支持重叠帧自动裁剪与可选加权融合，按顺序拼接多段潜空间与对应音频，输出完整序列后统一解码

### 2.2 标准三段式完整工作流拓扑

```
【第1段生成】
参考图/提示词 → CLIP编码 → 官方H3采样节点 → 输出 latent_1 + audio_1
                                      ↓（旁路引出一路 latent）
                              H3SegmentBridge 衔接节点
                                      ↓ 输出 ref_condition
【第2段生成】
参考图/提示词 → CLIP编码 → 官方H3采样节点 → 输出 latent_2 + audio_2
                                      ↓（旁路引出一路 latent）
                              H3SegmentBridge 衔接节点
                                      ↓ 输出 ref_condition
【第3段生成】
参考图/提示词 → CLIP编码 → 官方H3采样节点 → 输出 latent_3 + audio_3

【末端拼接输出】
latent_1、latent_2、latent_3 → H3LatentConcat 拼接节点
          （内部流程：格式校验 → 段首重叠帧裁剪 → 可选加权融合 → 潜空间拼接 → 音频同步拼接）
                                                          ↓
                                                    输出完整 latent + audio
                                                          ↓
                                                    官方Video VAE解码
                                                          ↓
                                                    完整视频导出

```

## 三、核心节点详细设计

### 3.1 H3SegmentBridge 段间衔接节点

#### 3.1.1 定位

纯条件转换工具节点，本身不执行采样推理，旁路式接入上游采样输出，提取尾部时序特征，编码为 H3 标准参考条件，供下游采样节点使用。

#### 3.1.2 运行模式

- **直通模式**：未接入有效 prev\_latent 时触发，输出结构完整的零值占位参考条件，完全不影响下游采样效果，等价于未接入节点，避免下游节点报错
- **衔接模式**：接入有效 prev\_latent 时触发，执行尾部提取 → 维度对齐 → 局部解码 → 加权编码 → 条件输出完整流程

#### 3.1.3 输入端口

- prev\_latent
  - 数据类型：LATENT
  - 必填：衔接模式必填
  - 说明：上一段 H3 采样节点输出的完整潜空间序列，张量形状 \[B, F, H, W, C]
- vae
  - 数据类型：VAE
  - 必填：是
  - 说明：H3 官方 Video VAE 模型，用于尾部潜空间局部解码
- base\_condition
  - 数据类型：CONDITIONING
  - 必填：否
  - 说明：本段基础提示词条件，用于和衔接条件做时序融合；不接则仅输出纯衔接条件

#### 3.1.4 输出端口

- ref\_condition
  - 数据类型：CONDITIONING
  - 说明：核心输出，标准 H3 参考视频条件格式，直接接入下游采样节点的参考输入口
- fps
  - 数据类型：INT
  - 说明：辅助输出，视频帧率，与上游保持一致

#### 3.1.5 内部执行流程

总流程：输入校验 → 模式判断 → 尾部潜空间截取 → 时空维度对齐 → 局部VAE解码 → 权重衰减计算 → 参考条件编码 → 时序融合 → 输出

分步详细逻辑：

1. **输入校验**：校验 prev\_latent 维度、格式有效性；校验 vae 类型与 H3 模型匹配
2. **模式判断**：prev\_latent 为空或帧数 < 1 → 直通模式，输出零值占位条件
3. **尾部潜空间截取**
   - 从 prev\_latent 尾部截取 context\_frames 帧（默认 22 帧）
   - 总帧数不足时取全部可用帧，权重序列自动适配长度
   - 截取完成立即释放原始 prev\_latent 张量
4. **时空维度对齐**
   - 检测 VAE 最小解码帧数与空间维度对齐要求
   - 若截取帧数不满足对齐约束，自动复制尾帧向上补全至对齐数
   - 解码完成后裁回有效帧，保证输出条件长度与设定一致
5. **局部VAE解码**
   - 仅对对齐后的尾部潜空间执行解码，默认使用 fp16 精度
   - 解码完成立即释放尾部潜空间张量，仅保留像素数据
6. **权重衰减计算**
   - 生成对应长度的权重序列，尾帧权重 = 1.0，首帧权重 = 0.2
   - 支持余弦/线性/指数三种衰减曲线，默认余弦
7. **参考条件编码**
   - 将加权像素帧转换为 H3 原生 Reference to Video 标准 CONDITIONING 格式
   - 应用「衔接强度」参数做整体权重缩放
   - 严格匹配官方条件字段结构，确保完全兼容
8. **时序融合（可选）**
   - 接入 base\_condition 时生效
   - 前 overlap\_frames 帧（默认 9 帧）：衔接条件权重从高到低衰减，基础条件权重从低到高上升
   - 9 帧后：衔接条件权重降为 0，完全由基础条件主导

#### 3.1.6 参数设计

- **主界面参数（默认展示）**
  - 衔接强度
    - 类型：滑块
    - 取值范围：0.0 \~ 1.0
    - 默认值：0.7
    - 说明：整体控制衔接条件权重，数值越高衔接越紧密、创意自由度越低
  - 输出帧率
    - 类型：整数
    - 取值范围：1 \~ 60
    - 默认值：24
    - 说明：输出视频帧率，需与上游采样保持一致
- **高级折叠参数（默认隐藏）**
  - 上下文帧数
    - 类型：下拉选择
    - 可选值：5 / 11 / 22 / 33
    - 默认值：22
    - 说明：提取上一段尾部的帧数，帧数越多衔接越稳定，显存占用越高；快速运动场景建议 22+，慢镜头/静态场景建议 11
  - 重叠帧数
    - 类型：整数
    - 取值范围：1 \~ 33
    - 默认值：9
    - 说明：衔接条件作用的过渡帧长度，不可超过上下文帧数
  - 衰减曲线
    - 类型：下拉选择
    - 可选值：余弦 / 线性 / 指数
    - 默认值：余弦
    - 说明：尾部权重衰减曲线类型，余弦过渡更自然，指数尾部权重更高
  - 条件融合模式
    - 类型：下拉选择
    - 可选值：时序衰减 / 全局加权
    - 默认值：时序衰减
    - 说明：衔接条件与基础条件的融合方式
  - 局部解码精度
    - 类型：下拉选择
    - 可选值：fp16 / fp32
    - 默认值：fp16
    - 说明：尾部VAE局部解码的计算精度，fp16显存占用更低、速度更快，特殊VAE可切换fp32保证兼容性
  - 强制显存回收
    - 类型：布尔开关
    - 默认值：关闭
    - 说明：解码与编码完成后主动触发显存回收，低显存设备可开启，会轻微增加耗时

### 3.2 H3LatentConcat 潜空间拼接节点

#### 3.2.1 定位

末端通用拼接节点，在潜空间维度完成多段视频的无缝拼接，最终统一解码。避免每段单独解码带来的画质损耗与显存冗余，支持重叠帧自动裁剪与可选加权融合，适配不同精度需求。

#### 3.2.2 核心逻辑

上游衔接节点已在生成阶段完成时序引导与帧对齐，每段潜空间的首尾自然衔接。默认采用帧维度直接张量拼接，无缝效果由生成阶段保证；同时提供可选的重叠帧裁剪与加权融合能力，解决段间重复帧问题，提升微小误差下的容错性。

#### 3.2.3 输入端口（动态可添加）

支持无限新增输入组，每组包含 1 个潜空间端口 + 1 个音频端口，支持单组删除与上下调整顺序。

- latent\_N
  - 数据类型：LATENT
  - 必填：latent\_1 必填，其余按需新增
  - 说明：第 N 段潜空间序列
- audio\_N
  - 数据类型：AUDIO
  - 必填：否
  - 说明：第 N 段对应音频

#### 3.2.4 输出端口

- latent
  - 数据类型：LATENT
  - 说明：拼接完成的完整潜空间序列，标准格式兼容所有原生 VAE、后处理节点
- audio
  - 数据类型：AUDIO
  - 说明：拼接完成的完整音频，无音频输入则输出空
- frame\_count
  - 数据类型：INT
  - 说明：拼接后总帧数

#### 3.2.5 内部执行流程

总流程：输入收集 → 格式校验 → 重叠帧裁剪 → 可选加权融合 → 潜空间拼接 → 音频拼接 → 输出

分步详细逻辑：

1. **输入收集**：自动扫描所有 latent\_N 端口，按序号排序收集有效输入，支持手动调整顺序
2. **格式校验**
   - 校验所有潜空间的分辨率、通道数、batch 维度一致
   - 校验所有输入音频的采样率、声道数一致
   - 不一致时抛出明确错误提示，不强行拼接；可配置为跳过无效段
   - 音频数量少于视频数量时，缺失段自动补静音，格式对齐已有音频参数
3. **重叠帧裁剪**
   - 除第一段外，每段开头自动裁剪 crop\_frames 帧潜空间
   - 开启自动匹配时，裁剪帧数自动同步上游衔接节点的上下文帧数
   - 裁剪后再执行拼接，避免段间重复帧导致的运动卡顿
4. **可选加权融合**
   - 融合过渡帧数 > 0 时生效
   - 对两段衔接处的重叠帧在潜空间做线性加权过渡：前一段尾帧权重从 1 降到 0，后一段首帧从 0 升到 1
   - 以极低计算成本平滑微小的色彩、运动偏差
5. **潜空间拼接**
   - 在帧维度（第 1 维）按顺序拼接所有处理后的潜空间张量
   - 拼接处无额外黑盒处理，无缝效果由上游衔接 + 裁剪 + 融合共同保证
6. **音频拼接**
   - 按对应顺序拼接音频张量
   - 段间接缝处做线性淡入淡出，避免爆音与硬切感
   - 开启音画同步时，淡入淡出时长自动匹配视频融合过渡帧对应的时长
7. **输出**：输出拼接完成的潜空间、音频与总帧数

#### 3.2.6 参数设计

- **主界面参数（默认展示）**
  - 添加片段
    - 类型：按钮
    - 说明：点击新增一组 latent\_N + audio\_N 输入端口，序号自动递增
- **高级折叠参数（默认隐藏）**
  - 重叠裁剪帧数
    - 类型：整数
    - 取值范围：0 \~ 33
    - 默认值：22
    - 说明：每段（除第一段外）开头裁剪的帧数，用于消除段间重复帧；建议与上游衔接节点的上下文帧数保持一致
  - 自动匹配衔接参数
    - 类型：布尔开关
    - 默认值：关闭
    - 说明：开启后自动读取上游衔接节点的上下文帧数，无需手动设置裁剪帧数
  - 融合过渡帧数
    - 类型：整数
    - 取值范围：0 \~ 22
    - 默认值：0
    - 说明：衔接处潜空间加权融合的过渡帧数，0 为纯硬拼接；数值越高过渡越柔和，建议不超过重叠裁剪帧数的 1/2
  - 音频淡入淡出时长
    - 类型：浮点数
    - 取值范围：0 \~ 0.5
    - 默认值：0.05
    - 说明：段间音频过渡时长，单位秒
  - 音频过渡对齐视频
    - 类型：布尔开关
    - 默认值：关闭
    - 说明：开启后音频淡入淡出时长自动等于视频融合过渡帧对应的时长，保证音画过渡同步
  - 异常处理
    - 类型：下拉选择
    - 可选值：报错终止 / 跳过无效段
    - 默认值：报错终止
    - 说明：输入格式不匹配时的处理逻辑

## 四、前端交互设计

1. **动态输入端口管理**
   - H3LatentConcat 节点实现「+」按钮动态新增输入组，每新增一组自动生成 latent\_N + audio\_N 端口，序号自动递增
   - 每个输入组右侧配备「-」删除按钮，支持单独移除某一段
   - 输入组支持上下箭头调整顺序，无需重新接线
2. **高级参数折叠**
   - 所有高阶参数默认收纳在「高级选项」折叠面板中，主界面仅保留核心参数，保证极简体验
3. **全参数 Tooltip 说明**
   - 所有参数悬浮展示详细说明，包含参数作用、影响效果、推荐使用场景
   - 异常参数（如重叠帧数 > 上下文帧数）实时标红并提示修正方向
4. **状态与错误可视化**
   - 节点运行时，标题栏显示轻量运行状态（如「解码中」「拼接完成」）
   - 输入格式不匹配时，节点标题栏显示红色警告，tooltip 展示具体错误原因 + 排查方向
   - 例：「潜空间分辨率不匹配：第2段为720p，第1段为1080p，请统一分辨率」
5. **参数联动校验**
   - 重叠帧数上限自动绑定上下文帧数，禁止「重叠帧数 > 上下文帧数」的无效设置
   - 融合过渡帧数上限自动绑定重叠裁剪帧数，避免无效参数组合
   - 开启自动匹配时，手动裁剪帧数输入框置灰，不可编辑

## 七、测试验收标准

### 7.1 功能测试

- 衔接效果：两段相同场景视频衔接处无画面跳变、运动断层、色彩偏移
- 拼接准确性：多段潜空间拼接后总帧数 = 各段帧数之和 - 裁剪总帧数，画面顺序正确
- 模式切换：不接 prev\_latent 时，节点输出不影响原生采样效果
- 动态输入：拼接节点可自由增删输入段，支持删除与排序，数量无限制
- 重叠裁剪：开启裁剪后，衔接处无重复帧、运动无卡顿
- 音频同步：音频与视频长度匹配，过渡处无爆音、无音画错位

### 7.2 边界测试

- 短片段适配：单段帧数 < 22 帧时，衔接与拼接功能正常，无报错
- 极端参数：衔接强度 0/1.0、上下文帧数 5/33、融合帧数 0/22 等边界值运行正常
- 缺失输入：部分音频缺失时，自动补静音且格式对齐
- 格式不匹配：分辨率/采样率不一致时，错误提示清晰可定位

### 7.3 性能测试

- 显存占用：1080p 分辨率下，衔接节点新增峰值显存 < 200MB（不含模型常驻显存）；720p 下 < 100MB
- 耗时：衔接节点额外耗时 < 单段生成耗时的 5%
- 拼接耗时：潜空间拼接耗时可忽略，远低于解码后像素拼接

### 7.4 客观量化指标

- 衔接处前后帧 PSNR（峰值信噪比）> 30dB
- 衔接处光流向量突变率 < 10%
- 拼接后视频总帧数误差为 0

### 7.5 兼容性测试

- 完全兼容官方原生 H3 采样节点、VAE 节点、CLIP 编码节点
- 输出格式可直接接入所有原生/第三方后处理节点、导出节点
- 工作流保存/加载正常，参数可正确序列化
- 兼容 ComfyUI 主流稳定版本

## 八、AI编程注意事项

1. 严格遵循 ComfyUI 节点开发规范，使用官方 API 进行张量操作与节点注册
2. 显存优化：所有中间张量使用完立即 del 并触发垃圾回收，避免显存累积；关键节点可选调用显存回收
3. 数据格式：所有输入输出严格匹配官方 H3 节点的张量维度与数据类型
4. 错误处理：所有异常场景给出清晰的中文错误提示 + 排查方向，不静默失败
5. 无侵入性：不得修改、Hook 官方节点与模型的内部逻辑，仅通过标准输入输出交互
6. 依赖最小化：优先使用 PyTorch 原生算子与 ComfyUI 内置工具，不引入额外重型第三方库
7. 代码规范：变量命名语义化，核心逻辑添加注释，便于后续迭代维护
8. 边界兜底：所有参数增加合法性校验，避免极端参数导致张量维度错误
