# H3 视频提示词写作规范（万能母模板 + 类型变量）

本规范为跨类型万能母模板：保留跨类型通用骨架，把类型差异全部做成可替换变量（{ } 槽位），并配三个风格迥异的完整示例（A 悬疑科幻 / B 动画治愈 / C 武侠力学因果）示范同一母模板的跨类型迁移。全部描述性内容用中文撰写；仅字段名（integrated_multimodal_description、overall_soundscape）与参考图标签（@image1、@image2、@image3 …）保持英文原样、全小写或原符号，不得翻译、不得改写为"参考图 1"等中文形式。母模板与示例中的 { } 均为待填槽位，生成时必须全部替换为用户场景的实际内容，花括号本身不得出现在最终输出中。

## 0. 内容铁律（最高优先级，优先于本文件的一切其他规则）

- 用户的场景、人物、动作、道具、台词、特效、音效是唯一内容来源。母模板的每个 { } 槽位都必须用用户输入的实际内容填写；示例 A、示例 B 与示例 C 仅示范结构与描述手法，其中的具体情节均为虚构演示，生成时禁止照搬或化用。
- 用户未要求的元素不得虚构：用户未提供台词，就选"无台词表演"分支；用户未要求特效/粒子/天气，就不生成对应小节或把该小节降为最简环境动态；用户未提到的道具、环境元素不进入画面描述。
- 六大类型变量（核心链、物理规则、镜头语法、光影方案、配乐策略、禁止项）按用户场景从"填写规则速查表"选配；一个视频只选一条主链，不混写。
- 收尾小节组的每一小节内容都必须围绕用户场景填写，禁止套用示例场景的词句。

## 1. 输出总结构

只输出两个字段，按以下顺序，前后不加任何解释、说明、前言或后缀：

```text
integrated_multimodal_description:
（类型与核心链定调段 → 连续镜头段落组 → 台词表演/无台词表演 → 收尾小节组）

overall_soundscape:
（按时间顺序汇总全片音效 + 配乐策略声明）
```

## 2. 输入模式识别

- T2VA（纯文生视频）：无参考图，直接从用户文字构建完整画面与时间线。
- I2VA（首帧参考）：@image1 作为首帧/整体画面，正文从该画面起势并向后发展。
- FL2VA（首末帧参考）：@image1 作为首帧，@image2 作为末帧，正文描述两帧之间的连续演变路径。
- L2VA（末帧参考）：@imageN 作为目标末帧，正文推断合理的前序状态并逐渐收敛到该画面。
- 多图角色/场景参考：按上传顺序用 @image1、@image2 …逐张声明职责，绑定规范见 ref-en.txt。

## 3. 万能母模板（跨类型通用骨架，{ } 为待填变量）

```text
integrated_multimodal_description:

【类型与核心链】
{视频类型：言情/文艺/科幻/武侠/悬疑/古装/动画/广告/纪录片式…}，核心链={力学因果链/情绪关系链/信息揭示链/技术规则链/礼仪器物链/风格化动作链}。{渲染风格：UE5电影级/二维赛璐璐/三维卡通/冷硬写实/自然纪实…}，{光影基调}，{场景类型与时间天气}；@image1 作为整体画面、{场景元素}、{关键道具}、{材质纹理}和{氛围}；角色严格 @image2 设定：{固定外观清单：年龄感、发型、五官、服装颜色结构纹样、配饰}，五官、发型、服装结构和纹样全程一致；{可选：@image3 锁定关键道具/机械/界面/风格帧/色指定}。

连续镜头：

镜头1【建立/起势】：
{角色初始姿态与位置}，镜头{角度/机位/景别}，清楚拍到{身体部位/道具/环境关系}。角色不做{错误动作A}，不做{错误动作B}，而是{正确链条：部位1先…部位2再…部位3…}，动作{风格}但保持{物理规则：写实可信/技术可信/风格内可信}。{衣物/发丝/道具/环境介质}产生{物理反馈1}与{物理反馈2}。音效：{音效1}、{音效2}、{音效3}。

镜头2【发展/因果或信息控制】：
{动作或情绪推进}，{接触对象/信息节点}；{对象}不是提前反应，而是被{准确动作/信息触发}后{物理结果/情绪反应/技术反馈}，{火星/雾气/尘埃/光斑/界面闪烁/水汽}产生{反馈}。镜头{必须清楚拍到完整因果链 / 只揭示局部并延迟关键信息}：{"A→B→C→D"或"声音先于画面→局部可见→镜头绕开→延迟揭示"}。音效：{接触声/环境声/方向误导声}。

镜头3【峰值/揭示/情绪转折】：
{动作峰值或情绪转折}，角色{姿态/表情/反应}，{衣物/道具/环境}产生{惯性/余动/光影变化}，{关键部位}保持清晰。{可选台词：他/她{前倾/转头/逼近/停住}，镜头{后撤/降低/推进/静止}，形成{镜头风格}特写。背景{虚化元素}被浅景深虚化，焦点锁定{双眼/手指/关键道具/面部轮廓}。角色{表情}，念出台词："{台词}"，吐字清晰。音效：{人声/呼吸/静默}。}

镜头4【收束/余韵】：
{收势姿态或情绪落点}，{衣物回落/道具余动/环境余动}，{暖光/冷光/火光/窗影}在{墙面/地面/衣物/面部}上轻微变化。{可选：台词结束后保持{姿态}，{环境余动}。}音效：{余韵声}。

【台词表演 / 无台词表演】
{若有台词：角色念"{前半句}"时不是{错误情绪}，而是{正确情绪}，声音{音色/音高/颗粒感}，语速{先慢后加重/低而稳/轻而颤}，眼神{评估/睥睨/躲闪/凝视}；念"{后半句}"时语气从{情绪A}转为{情绪B}，尾音{下压/收住/加重/轻落}，带{威胁感/认可感/脆弱感/温柔感}。前半句{表情动作}，后半句{咬字/嘴角/头部动作}。}
{若无台词：以{眼神/呼吸/手指/嘴角/肩线/停顿}完成表演：先{微动作A}，再{微动作B}，最后{情绪落点}；不靠夸张表情，不靠台词解释。}
音效：{人声细节/呼吸/衣料摩擦/静默留白}。

整体风格：
动态自然鲜活，{布料/被褥/发丝/道具/机械/粒子}物理模拟符合{写实/技术/风格化}规则，动作或情绪参考{参考类型}，{凌厉漂亮但不夸张失真 / 克制细腻不煽情 / 风格化但不漂移}，{视觉重点1/2/3}是重点，画面{电影质感/动画质感/纪实质感}，主体角色全程清晰稳定。

光影与质感：
采用{光比}布光，主光来自{光源}，{方向/色温}光扫过{面部/头饰/肩背/服装边缘/道具表面}，形成{轮廓光/硬阴影/柔光过渡/冷硬反光}；暗部{深邃但保留五官衣料纹理 / 柔和保留层次 / 局部压暗制造信息遮挡}，局部高光{锐利/柔和高光溢出/克制}，阴影层次丰富，{烛光/火光/窗影/屏幕冷光/霓虹}跳动时{墙面/被褥/面部/道具}产生真实{明暗呼吸/光影流动}。镜头带{胶片颗粒/柔光/浅景深/克制暗角/动画线条稳定}，突出{气质}。

环境动态 / 天气 / 粒子：
{起势}时{风力/雾气/尘埃/雨丝/光斑/屏幕反光}，{介质}贴着{床沿/墙面/地面/空气}流动，在角色周围形成{翻卷雾带/尘埃光柱/雨幕/冷光反射}；{衣摆/袖口/长发/流苏/书页/电缆}被{风向/动作/气流}影响，{旋转/移动/停顿}时{介质}形成{环形轨迹/尾迹/局部扰动}，{火星/尘埃/水汽/粒子}随{气流/动作}飞散。{峰值动作/情绪转折}时达到峰值，面部特写时{介质}从镜头边缘掠过但不遮挡五官，最后随{收势}渐弱。音效：{风声/雨声/环境底噪/粒子摩擦}。

镜头运动：
开场{低角度跟随/固定长镜头/缓慢横移/手持轻晃}，镜头沿{方向}做{短距离环绕跟拍/缓慢推近/静止等待}，{关键动作/信息节点}后顺势{后退并压低机位/轻微后撤/切近特写/保持不动}，{台词/情绪落点}时切入{低角度仰拍特写/近景浅景深/侧面长焦/主观视角}，焦点稳定锁定{双眼/手指/关键道具/面部轮廓}。

音频规则：
配乐策略={无背景音乐/极简低频氛围/克制轻柔配乐/类型化配乐但不盖环境音}；仅保留{人物人声/呼吸/道具撞击/布料摩擦/环境底噪/风声雨声/机械反馈/粒子声}等{白名单音效}，{禁止旋律化BGM/允许低音量配乐}。

禁止项：
禁止水印、文字、UI界面（若类型允许界面，则写"界面仅作为场景道具，不出现可读字幕/水印/无关系统UI"），禁止画面卡顿僵硬，人物肢体变形，五官崩坏，{类型专属禁止：风格漂移/线条抖动/比例崩坏/写实过度/信息提前泄露/过度jump scare/屏幕可读文字…}。

overall_soundscape:
{按时间顺序汇总：起始环境底噪→关键动作/信息声→峰值声→收束余韵}，{配乐策略}。
```

## 4. 填写规则（类型变量速查）

| 变量 | 可选值 | 注意 |
|---|---|---|
| 核心链 | 力学因果/情绪关系/信息揭示/技术规则/礼仪器物/风格化动作 | 一个视频只选一个主链 |
| 物理规则 | 写实可信/技术可信/风格内可信 | 不要混写 |
| 镜头语法 | 完整因果跟拍/遮挡延迟/长镜头静止/柔光近景/仰拍压迫 | 服务核心链 |
| 光影 | 烛光暖调/自然柔光/冷硬科技/高对比悬疑/赛璐璐平光 | 写"光如何动" |
| 声音 | 无BGM/极简低频/克制配乐/类型配乐 | 明确是否允许配乐 |
| 禁止项 | UI、文字、风格漂移、比例崩坏、信息泄露等 | 按类型增删 |

## 5. 示例 A：悬疑科幻·信息控制链（冷硬、局部揭示、极简低频）

以下示例仅示范母模板在悬疑科幻类型下的填法，全部情节为虚构演示，生成时禁止照搬或化用任何情节元素。

```text
integrated_multimodal_description:

悬疑科幻，核心链=信息揭示链。冷硬写实电影质感，低饱和青灰冷光，深夜无人数据中心机房；@image1 作为整体画面、成排服务器机柜、冷白指示灯、地面反光、线缆和封闭压抑氛围；角色严格 @image2 设定：三十岁女性工程师，黑色短发别在耳后，灰蓝色工装夹克，胸前工牌无文字，五官清瘦，眼神警觉，服装结构和发型全程一致；@image3 锁定异常终端屏幕的冷蓝反光与界面布局，但界面不出现可读文字。

连续镜头：

镜头1【建立/起势】：
女工程师坐在终端前，镜头从机柜后方低机位缓慢横移，先拍她悬在键盘上的手指、后颈和屏幕冷光在侧脸的反光，不立即给正脸。她不做突然回头，不做夸张惊吓，而是听到风扇骤停后手指停住，肩线先绷紧，呼吸变浅，眼球缓慢转向屏幕反光。工装袖口被手腕压出褶皱，发丝被空调气流轻吹。音效：机房低频嗡鸣、风扇骤停后的突然静默、椅子轻微滚轮声。

镜头2【发展/信息控制】：
屏幕反光里出现门外模糊人影，镜头只给反光局部，不拍门外全貌；她不是立刻尖叫，而是缓慢将手从键盘移开，指尖碰到金属桌沿后停住。镜头必须按"声音先于画面→反光出现局部人影→她停手→镜头绕肩延迟揭示"的顺序控制信息：先让观众看见反光，再让她看见，最后镜头才从她肩后缓慢绕过。线缆轻微晃动，尘埃在冷光中漂浮。音效：远处金属敲击一声、呼吸声、衣料摩擦声、低频氛围渐入。

镜头3【峰值/揭示】：
她低声念出台词："谁在那？"，镜头保持她侧面近景，不切门外。她念"谁"时不是惊讶大喊，而是压低声线、带审视和克制恐惧，语速慢，眼神先看反光再移向门缝；念"在那"时尾音收住，下巴微抬，手指抓紧桌沿。镜头极轻微向前推进，焦点锁定她的眼睛和屏幕冷光轮廓。音效：人声压迫感、呼吸尾音、低频氛围短促增强。

镜头4【收束/余韵】：
她保持不动，门缝外的人影已经消失，只剩屏幕反光轻轻闪动；冷白指示灯在墙面和桌面轻微跳动。镜头缓慢后撤，保持门缝在画外。音效：机房嗡鸣恢复、远处脚步余响、低频氛围渐弱。

台词表演：女工程师念"谁在那？"时不是惊恐尖叫，而是压低、冷静、带审视的恐惧，声音偏低偏干，语速先慢后收，眼神从反光移向门缝，手指抓紧桌沿；后半句尾音下压，像在确认而不是求助。

整体风格：动态克制真实，线缆、发丝、尘埃和屏幕反光符合写实物理，悬疑感来自信息遮挡而非夸张惊吓，反光、门缝、手指和呼吸是视觉重点，画面冷硬电影质感，主体角色全程清晰稳定。

光影与质感：高对比冷硬布光，主光来自终端屏幕冷蓝光与机柜指示灯，侧光扫过她面部、短发边缘和工装肩线，形成冷色轮廓光；暗部深邃但保留五官、衣料纹理和机柜金属细节，局部高光锐利，屏幕反光在面部产生轻微明暗呼吸。镜头带细腻胶片颗粒、浅景深和克制暗角。

环境动态：空调气流吹动发丝和工装袖口，尘埃在冷光中缓慢漂浮，线缆轻微晃动；门缝外的人影只通过反光和局部阴影出现，不提前完整展示。音效：低频嗡鸣、气流声、远处金属余响。

镜头运动：开场低机位横移，镜头从机柜后方缓慢绕过；信息节点后极轻微推进；台词段保持侧面近景，焦点锁定眼睛与屏幕反光；结尾缓慢后撤。

音频规则：配乐策略=极简低频氛围，无旋律化BGM；仅保留人物人声、呼吸、椅子滚轮、金属敲击、衣料摩擦、机房嗡鸣、气流声、低频氛围等白名单音效。

禁止水印，文字，UI界面（屏幕界面仅作为场景道具，不出现可读字幕、系统文字或无关UI），禁止画面卡顿僵硬，人物肢体变形，五官崩坏，禁止信息提前泄露，禁止过度jump scare，禁止夸张惊吓表情。

overall_soundscape:
机房低频嗡鸣→风扇骤停静默→椅子滚轮轻响→远处金属敲击→呼吸与衣料摩擦→低频氛围渐入→人声"谁在那？"→低频短促增强→嗡鸣恢复→脚步余响→低频渐弱，极简低频氛围，无旋律化BGM。
```

## 6. 示例 B：动画治愈·情绪关系链（风格化物理、无台词、轻柔配乐）

以下示例仅示范母模板在动画治愈类型下的填法，全部情节为虚构演示，生成时禁止照搬或化用任何情节元素。

```text
integrated_multimodal_description:

二维赛璐璐动画，治愈系，核心链=情绪关系链。暖色午后自然柔光，旧书店靠窗角落；@image1 作为整体画面、木质书架、窗格光、漂浮尘埃、旧书堆和温暖安静氛围；角色严格 @image2 设定：短发少女，米色针织开衫，深绿围裙，圆框眼镜，小猫为橘白短毛；@image3 锁定二维赛璐璐色指定与线条风格，角色比例和配色全程一致。
```

## 8. 使用结论（通用不变 vs 按类型替换）

母模板为"结构万能、参数类型化"的写法：

- 通用不变：多模态锁定、连续分镜、核心链、可拍细节、镜头同步、表演拆解、光影声音、禁止项、overall_soundscape。
- 按类型替换：核心链、物理规则、镜头语法、光影方案、配乐策略、禁止项。
- 示例 A 展示悬疑科幻的信息控制与冷硬音效；示例 B 展示动画治愈的情绪链、风格化物理与无台词表演；示例 C 展示武侠的力学因果链、狂风粒子特效与台词语气表演。三者沿用同一母模板，证明模板可跨类型迁移；生成时照此迁移逻辑把母模板套在用户场景的类型上，而不是套在示例情节上。
