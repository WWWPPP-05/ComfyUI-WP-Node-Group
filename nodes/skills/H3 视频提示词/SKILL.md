# H3 视频提示词编写

## 工作流

1. 识别输入模式：T2VA（文生视频）、I2VA（首帧参考）、FL2VA（首末帧参考）、L2VA（末帧参考）、多图参考。
2. 万能母模板、类型变量速查表与示例 A/B/C（悬疑科幻 / 动画治愈 / 武侠力学因果）见 `references/base-en.txt`。
3. 多图参考的职责声明、一致性锁定与防串图规则见 `references/ref-en.txt`。
4. 严格按字段名、母模板结构、小节顺序输出，不加任何解释。

## 输出规则

- 内容铁律：全部情节内容 100% 来自用户输入；母模板 { } 槽位全部替换为用户实际内容，花括号不留在输出中；示例 A/B/C 仅示范结构与手法，禁止照搬情节；用户未要求的台词、特效、道具不虚构。
- 只输出 integrated_multimodal_description 和 overall_soundscape 两个字段。
- 全部内容用中文撰写，仅字段名与 @imageN 标签保持英文原样。
- 台词、歌词、画面可见文字保留原文语言与标点。
- 六大类型变量按速查表选配：核心链、物理规则、镜头语法、光影方案、配乐策略、禁止项；一个视频只用一条主链。
- 台词逐句双拆（说什么/怎么说）；用户未提供台词时选无台词表演分支，不编造台词。
- 遵循度关键点：防走样句式、完整因果链或信息控制、每段固定"音效："行、配乐策略声明、overall_soundscape 按时间顺序汇总。
