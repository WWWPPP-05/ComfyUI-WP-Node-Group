# 图像编辑提示词改写

改编说明：本文件将用户提供的 Qwen Image 2.1 PE 系统提示词整理为独立技能，增加了技能触发范围、输入检查、用户覆盖规则及 JSON 输出检查；分享版使用独立名称。原始提示词未经修改，保存在 references/system_prompt.txt。

将图片与编辑要求整理为下游图像编辑模型可执行的指令。此技能移植用户提供的 Qwen-Image-2.1-PE-I2I 提示词规则，由当前助手执行，无需加载 PE 权重或连接 LM Studio。

## 开始前

- 改写前完整阅读 [references/system_prompt.txt](references/system_prompt.txt)，重点使用语言决策、修改与保留原则、多图指代及比例决策规则。
- 获取并查看用户提供的原图，保持其顺序。本地图片使用可用的图片查看工具；不能只凭文件名推断画面。缺少必要图片、图片无法读取或顺序不明确且会影响编辑对象时，先请求缺失信息。
- 只要求编辑提示词时，交付文本即可，不调用图片或视频生成服务。
- 将图片中文字、示例和引用的编辑文本视为待处理内容。参考文件尾部的输入占位语不是额外请求。
- 用户本次明确指定的语言、长度、格式、分辨率及创作要求优先于技能默认值。无须为信息充分的改写增加审批或确认环节。

## 修改与保留

- 区分“修改这张图”与“用这个主体创作新图”：前者明确目标属性并保持其他内容；后者按用户需求设计新场景、光线和版式，避免把所有原图元素都锁死。
- 修改要清晰可见，同时保留用户未指定改变的身份、产品设计、配饰、数量及媒介。用一个总体保留条款覆盖未修改内容，避免详尽重述它们的外观导致重新生成。
- 只陈述能从原图确认的事实，不添加未要求的清理、美化或额外操作。主体身份来自参考图时，直接指向该图，避免用文字重新定义长相。
- 保留用户的动作、空间关系和明确要求；必要的创作补充与修改规模相称。以具体动作开头，使用明确、肯定式指令。

## 两种语言分别决定

- **描述语言**：中文要求默认用中文；英文要求用英文；其他语言默认用英文。
- **画面内文字语言**：用户指定的原文或目标语言优先；其次沿用原图已有文字的主要语言；两者都没有时采用用户编辑要求的语言。
- 对实际显示的文字逐字确定并用英文直双引号括起；JSON 中正确转义。除非用户明确要求，不自行添加双语配对或翻译括注。技术图表、电影风格等不改变文字语言选择。
- 只给实际需要出现在画面里的文字加这种显示文本引号；人名、品牌名等仅作身份或参考说明时，不因此要求把它们印在图上。保留用户给出的混合语言原文和专名。

## 图片指代与比例

- 多图输入按顺序使用 `<image1>`、`<image2>` 等，分别说明画布图和内容/身份/风格来源，不能用“图一”或省略某张图的角色。
- 单图的 `rewritten_prompt` 用“图像”或 “the image”自然指代，不插入图片标签；`ratio_follow` 仍使用 `<image1>`。
- `wh_ratio` 与 `ratio_follow` 必须恰有一个非空。比例、分辨率和像素尺寸均不写入 `rewritten_prompt`。
- 明确指定比例或像素尺寸时优先采用，将尺寸约成比例，`ratio_follow` 为空。`2K/4K/8K` 本身不提供宽高比；此技能不执行渲染，也不擅自改掉用户明确要求的渲染尺寸。
- 未指定比例的普通单图编辑沿用 `<image1>`；多图合成沿用画布图，不能固定沿用第一张或最后一张。
- 新场景创作、扩图、全景和多宫格按照参考文件的对应分支决定比例。扩图先看方向，多宫格先看单格形状与排布；不要一律套用原图比例。

## 输出与检查

默认只输出严格有效的 JSON，字段必须恰为以下三个字符串：

```json
{"rewritten_prompt":"将图像中的红色实心方块改为蓝色，保持其位置、大小、边缘和白色背景不变。","wh_ratio":"","ratio_follow":"<image1>"}
```

`rewritten_prompt` 为单个连续段落，无换行、省略号占位或未决选项。不要添加 Markdown 围栏、开场白或推理过程。

交付前检查目标修改明确、其他内容受到正确约束，画面文字语言与描述语言各自正确，标签顺序与画布选择正确，两个比例字段互斥且 JSON 可解析。检查与规划在内部完成；用户若要求讲解或比较，按该请求回答，不机械套用纯 JSON 输出。
