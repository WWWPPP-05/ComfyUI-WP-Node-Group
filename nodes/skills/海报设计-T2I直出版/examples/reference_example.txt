## 核心变化说明 (T2I 规范)

| 规范项 | 本示例如何体现 |
|--------|---------------|
| **自然语言观察者视角** | 使用"画面中间位置""车顶左侧""画面左下角"等位置短语导航，而非碎片化标签堆砌 |
| **主体优先** | 主角描述置于提示词最前，获得最重注意力权重 |
| **文字双引号锁定** | 所有画面中要渲染的文字均用 `" "` 包裹，如 `"一场遇见爱情的旅行"`、`"4月20日"` |
| **不含分辨率数字** | 提示词中仅有"8K"作为画质修饰词，无任何像素值 |
| **输出 JSON 格式** | 末尾附带 `wh_ratio: "9:16"`，符合 PE-T2I 输出规范 |
| **严谨文案处理** | 用户已提供的文案逐字嵌入；缺失的导演/编剧、出品信息、平台LOGO均以 `【待定】` 占位，未编造 |
| **超精细人物刻画** | 从姿态、神态、服装、妆容四个维度分别刻画陈晓和景甜 |
| **排版类型明确** | 选择"上下结构排版"，并描述各文字层级的位置与字体 |

## 如何使用
将上述"Skill 输出"部分整段复制，粘贴到 Qwen-Image-2.1 的 T2I 输入框中即可生成海报。如需调整画面元素，可修改人物描述、场景光线或排版类型，Skill 会保持相同的结构化输出风格。
