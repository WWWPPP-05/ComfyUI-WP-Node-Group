# NOTE: 排版类型参考。所有排版类型的文字位置描述需配合自然语言观察者视角使用。

# =============================================
# 排版类型A - 上下结构
# =============================================
画面上方2/3区域为主视觉区，画面下方1/3区域为文字信息区。主标题位于画面中下部居中位置，字号最大。档期日期紧接主标题下方。主演信息以小字号排列在档期下方。出品公司信息位于画面最底部居中。

# =============================================
# 排版类型B - 居中/中心式
# =============================================
人物/主体位于画面正中心。主标题以超大字号居中排列在主体下方。档期日期紧随其后。主演信息垂直排列在画面左侧或右侧边缘。

# =============================================
# 排版类型C - 对角构图
# =============================================
主体人物占据画面左下角或右上角，文字信息沿对角线分布在相反方向。主标题倾斜排列在对角线上。

# =============================================
# 排版类型D - 对称构图
# =============================================
画面以中轴线为基准左右镜像对称。文字信息沿中轴线居中垂直排列。

# =============================================
# 排版类型E - 包围式构图
# =============================================
主体位于画面中心，文字元素环绕主体四周。主标题以弧形排列在主体上方。

# =============================================
# 排版类型F - 四角构图
# =============================================
文字信息拆分为四个区块分布在画面四角。主视觉图像居于画面正中心。

# =============================================
# 排版类型G - 满版/骨骼型
# =============================================
主视觉图像铺满整个版面，文字嵌入画面的留白区域。主标题放置在画面顶部留白区域。
