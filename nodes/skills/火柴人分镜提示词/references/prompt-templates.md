## 正向提示词模板（多分镜）

每个分镜独立套用单分镜模板，分镜之间用 `---` 分隔。所有分镜保持相同角色颜色、相同环境颜色、相同角色数量，只改变动作、朝向、图层位置、镜头角度、遮挡关系。

## 完整示例（单分镜）

用户输入：
> 两个人在冰原上一起攻击一只巨兽

输出：

```
彩色编码极简火柴人分镜图，2D 扁平矢量，干净简单线条，纯白背景，无阴影，无渐变，无纹理。广角，轻微仰视，16:9。

前景左下：一条深蓝色冰裂缝。
中景左侧：黑色火柴人 1，仅用黑色轮廓线绘制，不填充，不画成实心剪影，面向右，冲刺，右手持红色长矛，刺向巨兽。
中景右侧：黄色火柴人 2，仅用黄色轮廓线绘制，不填充，不画成实心剪影，面向左，拉绿色弓，瞄准巨兽头部。
中景中央偏后：一只巨大的紫色巨兽，体型远大于火柴人，高高耸立，面向观众，举起爪子，头上有橙色角。
背景：冰蓝色冰原在角色脚下，青色冰山沿地平线排列，浅灰色天空在上方。地平线在画面中间。

层次清晰：前景是深蓝色冰裂缝，中景是黑色和黄色火柴人，背景是紫色巨兽和青色冰山。
主体是紫色巨兽，次要角色在左右中景。
每个元素只使用一种指定颜色，无统一黑色描边，无混色。所有火柴人仅用轮廓线绘制，不填充，不画成实心剪影。
颜色键：黑色 = 火柴人 1；红色 = 长矛；黄色 = 火柴人 2；绿色 = 弓；紫色 = 巨兽；橙色 = 巨兽角；冰蓝色 = 冰原；深蓝色 = 冰裂缝；青色 = 冰山；浅灰色 = 天空。
分镜构图，高对比，清晰剪影，简单形状，无文字，无水印。
```
