# 颜色分配规则

## 基本规则

1. 先列出所有独立元素：角色、道具、环境、背景物件、特效。
2. 每个关键元素分配一个唯一颜色。优先使用高对比基础色：
   黑色、白色、红色、橙色、黄色、青柠绿、绿色、青色、蓝色、藏青、紫色、洋红、粉色、棕色、灰色、米色、金色、银色。
3. 每个元素只使用一种纯色，禁止渐变、阴影、纹理、混色。
4. 正向提示词中必须写：每个元素只使用一种指定颜色，无统一黑色描边，无混色。
5. 颜色分配仅作为内部生成逻辑，最终不输出颜色映射表，但必须在正向提示词末尾写出颜色键。

## 角色推荐颜色顺序

按站位顺序分配，优先使用以下顺序：

| 序号 | 颜色 |
|---|---|
| 火柴人 1 | 黑色 |
| 火柴人 2 | 黄色 |
| 火柴人 3 | 蓝色 |
| 火柴人 4 | 红色 |
| 火柴人 5 | 紫色 |
| 火柴人 6 | 橙色 |
| 火柴人 7 | 青色 |
| 火柴人 8 | 洋红 |
| 火柴人 9 | 青柠绿 |
| 火柴人 10 | 棕色 |

## 道具颜色

- 道具颜色不能与任何角色或环境重复。
- 若重复，改用亮 / 暗 / 浅 / 深修饰，或换成金色 / 银色 / 粉色 / 藏青。
- 常见道具推荐色：
  - 剑：红色 / 洋红
  - 长矛：红色 / 橙色
  - 枪：绿色 / 藏青
  - 弓：绿色 / 青柠绿
  - 盾：金色 / 银色
  - 法杖：紫色 / 洋红
  - 炸弹：橙色 / 红色
  - 绳索：棕色 / 米色
  - 钥匙：金色 / 黄色

## 环境颜色

环境使用自然色但必须区分：

- 蓝色大海
- 浅青色天空
- 棕色大树
- 深绿色草地
- 灰色山脉
- 米色沙滩
- 白色云朵
- 冰蓝色冰原
- 深蓝色冰裂缝
- 深灰色岩石
- 浅黄色沙漠
- 深绿色森林
- 浅灰色雾

## 对比度规则

1. 角色颜色必须与所在图层背景色形成高对比。
2. 禁止出现的低对比组合：
   - 黑色角色 + 深蓝 / 藏青 / 深灰背景
   - 白色角色 + 纯白 / 浅青 / 米色背景
   - 深蓝色角色 + 深蓝环境
   - 深绿色角色 + 深绿环境
3. 若发生冲突，按以下顺序处理：
   - 优先改角色颜色（改角色不影响环境识别）
   - 其次给角色加亮 / 暗修饰
   - 最后才改环境色
4. 白色火柴人必须配一个非白色的背景层，或改为浅灰色。
5. 纯白画布上不允许出现白色火柴人；若场景需要白色角色，改用浅灰或银色。

## 重叠元素规则

1. 任意两个在画面上会重叠或紧邻的元素，不能使用相同颜色。
2. 若无法避免，必须使用明度差极大的修饰：
   - 藏青鸟 + 浅青大海
   - 深绿树 + 青柠绿草地
   - 亮红色剑 + 暗红色血
3. 前景元素与紧邻的中景元素必须使用不同色系。
4. 角色手持道具不能与角色同色。

## 白色环境处理

1. 若环境主色为白色（雪地、云、白雾），画布背景改用极浅灰色。
2. 白色环境元素必须加修饰：纯白雪地、柔白云朵、浅白雾。
3. 白色环境必须有一条可见的边界线（地平线或轮廓），否则 Krea2 会填满整张画布。
4. 禁止在纯白画布上直接画白色环境元素。

## 颜色降级策略（元素超过 12 个时）

按以下顺序降级：

1. 合并同类环境元素（如多棵树合并为“棕色树群”）。
2. 合并同类道具（如多把剑合并为“红色武器”）。
3. 次要背景元素改用灰色 / 浅灰 / 深灰三档灰度。
4. 远景元素改用空气透视色（浅蓝 / 浅灰 / 浅青）。
5. 最后才考虑给两个不重叠的次要元素复用颜色，并在颜色键中注明。

## 去重与区分

若颜色接近，使用以下修饰区分：

- 绿：青柠绿 / 深绿 / 亮绿
- 蓝：浅蓝 / 藏青 / 青色 / 深蓝
- 红：亮红 / 暗红 / 绯红
- 黄：亮黄 / 金色 / 浅黄
- 灰：浅灰 / 深灰 / 银色
- 棕：棕色 / 深棕 / 米色

## 颜色键输出格式

正向提示词末尾必须输出颜色键，格式：

```
颜色键：黑色 = 火柴人 1；红色 = 长矛；黄色 = 火柴人 2；绿色 = 弓；紫色 = 巨兽；橙色 = 巨兽角；冰蓝色 = 冰原；深蓝色 = 冰裂缝；青色 = 冰山；浅灰色 = 天空。
```
