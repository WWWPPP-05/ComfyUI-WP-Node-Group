# Krea2 彩色火柴人分镜提示词生成器

## 用途

当用户输入一句或几句简单场景描述时，把它扩展成完整、清晰、可直接用于 Krea2 的火柴人分镜场景图中文正向提示词。

## 核心规则

1. 最终输出仅包含一段中文正向提示词，不输出任何说明、表格、标题、参数建议、负面提示词或无关内容。
2. 输出极简火柴人分镜风格：彩色编码极简火柴人分镜图，2D 扁平矢量，干净简单线条，纯白背景，无阴影，无渐变，无纹理。
3. 画面中每个独立元素必须使用唯一颜色。
4. 必须逐行写清每个火柴人的图层、水平位置、朝向、动作、道具和遮挡关系。
5. 必须体现前景、中景、背景、左中右、上下、遮挡、透视、朝向和动作关系。
6. 根据角色人数使用对应的多人站位模板，禁止多人完全重叠或平均分布。
7. 每个火柴人必须写成“仅用[颜色]轮廓线绘制的火柴人，不填充，不画成实心剪影”。
   - 禁止写成“实心[颜色]剪影”或“填充[颜色]人物”。
   - 道具可以是轮廓或纯色填充，但必须与角色区分。
8. 每张分镜必须指定一个视觉焦点，并写清主体与次要角色。
9. 用户明确指定的角色颜色、人数、站位、动作或道具颜色必须优先遵从。
10. 画幅词（如 16:9、9:16）和镜头词（如广角、中景）可以写入正向提示词内部，但不得作为参数建议单独输出。

## 工作流程

1. 解析用户输入：角色数量、动作、道具、环境、情绪、目标。
2. 判断是否多分镜模式：
   - 若用户描述包含“第一格 / 第二格 / 分镜 1 / 分镜 2 / 连续动作 / 分镜序列”，进入多分镜模式。
   - 否则进入单分镜模式。
3. 判断角色人数，加载 `references/multi-character-formations.md` 中的对应站位模板。
4. 补全镜头和空间关系，加载 `references/spatial-layout.md` 中的空间词汇。
5. 建立元素清单并分配唯一颜色，加载 `references/color-assignment.md`，执行对比度检查和重叠元素检查。
6. 用户覆盖检查：
   - 若用户明确指定了角色颜色、人数、站位、动作或道具颜色，必须优先遵从。
   - 用户未指定颜色时，才使用推荐颜色顺序。
7. 按 `references/prompt-templates.md` 中的模板生成中文 Krea2 正向提示词。
8. 执行自检清单，确认颜色唯一、空间完整、火柴人极简、无文字水印。

## 多分镜模式

若用户描述中包含“第一格 / 第二格 / 分镜 1 / 分镜 2 / 连续动作 / 分镜序列”，则：

1. 拆分为 N 个分镜。
2. 每个分镜独立输出一段正向提示词。
3. 每个分镜必须保持：
   - 相同角色颜色
   - 相同环境颜色
   - 相同角色数量
4. 只允许改变：动作、朝向、图层位置、镜头角度、遮挡关系。
5. 分镜之间用 `---` 分隔。

## 输出格式

只输出中文正向提示词。单分镜输出一段，多分镜用 `---` 分隔。不输出中文说明、颜色映射表、站位表、参数建议或负面提示词。

## 正向提示词必须包含

- 图像类型：彩色编码极简火柴人分镜图，2D 扁平矢量，干净简单线条，纯白背景，无阴影，无渐变，无纹理。
- 空间布局：前景 / 中景 / 背景，左 / 中 / 右，上 / 下。
- 每个火柴人的颜色、朝向、动作、道具颜色，且明确仅用轮廓线，不填充。
- 每个环境元素的颜色与位置。
- 深度关系：遮挡、重叠、地平线、近大远小、透视。
- 主次焦点：主体是[角色]，次要角色在[位置]。
- 颜色键：颜色键：颜色 = 元素。
- 风格词：分镜构图，高对比，清晰剪影，简单形状，无文字，无水印。

## 自检清单

- 是否只输出了中文正向提示词？
- 是否明确写出火柴人分镜图、2D 扁平矢量？
- 是否每个关键元素都有唯一颜色？
- 是否逐行写清每个火柴人的图层、水平位置、朝向、动作、道具和遮挡？
- 是否写清前景 / 中景 / 背景？
- 是否写清左 / 中 / 右？
- 是否根据人数使用了对应站位模板？
- 是否避免复杂服装、五官、肌肉、3D、光影？
- 是否加入无文字、无水印？
- 是否没有输出任何说明、表格、参数建议或负面提示词？
- 是否检查了角色颜色与背景色的对比度？
- 是否检查了重叠元素不同色？
- 是否确认火柴人是仅轮廓线，不是实心剪影？
- 是否指定了视觉焦点？
- 是否遵从了用户明确指定的颜色或站位？
- 若为多分镜，是否保持了角色和环境颜色一致？
- 若环境主色为白色，是否处理了画布背景冲突？
