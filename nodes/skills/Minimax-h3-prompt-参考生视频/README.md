# Minimax H3 Prompt Director

一个用于将简短视频指令扩写为 Minimax H3 参考生视频完整提示词的技能文件夹。

## 使用方式

1. 将本文件夹放入你的 skills 目录。
2. 用户给出简短指令。
3. 技能按 `SKILL.md` 工作流抽取要素、选择风格、绑定参考图、排时间轴、插入冲击帧、设计音效。
4. 输出一个可直接粘贴的完整提示词。

## 设计边界

- 只复用参考案例的**结构、格式、规则、参数范围**。
- 不复用案例中的专有角色、台词、牌匾文字、道具符号、具体剧情。
- 用户未提供的内容使用通用描述或占位符，不臆造 IP 设定。

## 核心文件说明

- `SKILL.md`：技能入口，定义何时使用、工作流、输出契约与关键原则。
- `references/distilled-format.md`：完整提示词固定格式规范。
- `references/impact-frame-rules.md`：冲击帧定义、必须满足、禁止事项、标准写法与检查清单。
- `references/audio-mixing-rules.md`：音效分层原则与标准格式。
- `references/style-presets.md`：可选风格预设与关键词。
- `references/contamination-guard.md`：防止复用参考案例专有内容的规则。
- `references/performance-layer.md`：表演子层规则；按场景启用（情绪特写、生活流、多主体互动类），用六条表演轨道把情绪写成可见的连续表演；不改变交付格式，不污染冲击帧/硬着陆/音效峰值等战斗结构。
- `templates/full-prompt-template.md`：可直接填充的完整提示词模板。
- `templates/short-command-intake.md`：简短指令采集与缺省策略。
- `checklists/quality-gate.md`：输出前质量检查表。
- `examples/generic-optimization-example.md`：不含案例专有内容的通用优化示例。

## 最小使用示例

用户输入：

```text
角色A在废墟释放能量大招，命中目标B胸口核心，0.2秒冲击帧，热血写实CG，7秒。
```

技能输出：

```text

参考图绑定：
- @Image1（主体绑定）：主体角色A，严格锁定参考图外观、服装结构、配色与识别特征；施法时服装可被狂风与能量气流吹动破损，但角色外观不得漂移；表情冷冽、专注、强势。
- @Image2（招式/特效绑定）：核心能量大招，保留参考图中的能量颜色、旋转结构、雷电/冲击波形态与核心光效。
- @Image3（目标绑定）：目标单位B，锁定体型、材质、关键发光部位与攻击姿态，胸口核心为本次命中点。
- @Image4（场景环境绑定）：指定废墟战场，固定破损街区、残垣、地面裂纹、烟尘与火光；所有镜头发生在同一场景中。
- @Image5（冲击帧绑定）：严格参考本图结构，遵循 Impact Frame 规则；核心大招正面命中目标B胸口核心的顶点瞬间，仅0.2s静态定格，帧内无运动、无变形、无慢动作；主体与目标组合为清晰粗黑轮廓剪影，剪影优先于特效；结束后立刻切回写实CG。
- 标签用途映射：@Image1 锁定图1主体角色A的外观；@Image2 锁定图2大招特效结构；@Image3 锁定图3目标单位B的外观；@Image4 锁定图4废墟战场场景；@Image5 锁定图5冲击帧结构。【2026-11-24 标签化修订】

叙事顺序：主体蓄能近景 → 大招爆发硬切 → 纯能量视角高速突进 → 命中胸口核心冲击帧 → 核心爆裂与破坏反馈 → 远景收束。

镜头1｜0.0–1.8s｜主体侧前方近景蓄能
机位固定在主体侧前方，近景特写为主，围绕上半身、正面微侧脸部与胸前能量核心展开。主体位于废墟高处，正面面对目标方向，但镜头1内不出现目标本体、脚掌、腿部、阴影或尺度参照。0.0–1.4s轻微手持环绕，1.4–1.8s发动瞬间锁定正面微侧脸部并硬切。
- 0.0–0.5s：主体双手拉开至胸前，双眼亮起，能量纹路沿肩颈爬升，背景废墟虚化成火光与烟雾。
- 0.5–1.0s：身体前倾，尾部/披风/裙摆被能量扬起，双臂将能量向胸前合拢，镜头快速推近。
- 1.0–1.4s：镜头锁定正面微侧脸部特写，能量核心与头饰/关键识别点成为焦点，短促停顿形成蓄能顶点。
- 1.4–1.8s【发动切镜点】：主体双手前推，能量爆发同一帧硬切；切镜后人物彻底消失，不保留人物残影。

镜头2｜1.8–3.8s｜纯能量视角高速突进
硬切进入能量内部视角，镜头被高速气流与能量裹挟，沿主体面对方向高速推进。本段无主体入画。
- 1.8–2.4s：镜头冲入能量核心，雷电/冲击波/碎石沿镜头边缘掠过，场景高速后掠。
- 2.4–3.1s：能量贴地穿行，镜头压低后突然抬升，远处目标B首次出现，双脚稳定站在废墟地面。
- 3.1–3.6s：镜头从目标脚边高速仰冲，目标胸口核心成为唯一强光焦点，能量沿核心中心轴逼近。
- 3.6–3.8s【冲击帧｜0.2s 静态定格，帧内无动画】：核心大招正面命中目标B胸口核心的顶点瞬间，正常运动被强行打断，立即插入冲击帧参考图式静态定格。中心爆闪光核对准胸口核心，外圈放射爆点与环形冲击波扩散；主体与目标双剪影同框：主体剪影位于画面左下方呈突进姿态，目标剪影位于画面右侧，招式命中点（胸口核心）位于两剪影之间，目标轮廓、双爪/肢体轮廓、胸口核心轮廓一眼可辨，组合为清晰粗黑轮廓剪影压在画面中心，粗黑描边，剪影优先于特效。高张力荷兰角倾斜构图，仅闪0.2秒，结束瞬间立刻切回写实CG。【剪影句式 2026-11-23 更新为双剪影同框强制版】

镜头3｜3.8–7.0s｜核心爆裂与城市毁灭
冲击帧结束后立刻回归写实CG，承接命中顶点展开破坏反馈。本段无主体入画。
- 3.8–4.5s：目标胸口核心炸裂，能量与碎片向胸口外喷溅，目标身体被强行掀飞。
- 4.5–5.6s：能量贯穿目标并在场景中心二次爆发，冲击波掀起建筑残骸与烟尘。
- 5.6–7.0s：镜头剧烈抖动后缓慢拉远，目标坠落在废墟中，能量余光与烟尘扩散，画面压黑收尾。

音效设计（无BGM，电影分层混音，峰值卡点对准3.6–3.8s冲击帧）：
- 0.0–0.5s：场景风声、碎石坠落声、高频电流滋鸣。
- 0.5–1.4s：能量滋滋预警、低频持续增强、关键识别点短促金属共振。
- 1.4–1.8s【切镜同步】：能量爆发闷响、破空声与硬切同步。
- 1.8–3.6s：强风贴耳、碎石飞掠、低频推进音持续上升，目标核心共振音压近。
- 3.6–3.8s【音效峰值】：中心爆音、短促黑切静音、低频重击、环形冲击爆响。
- 3.8–5.6s：核心爆裂、能量贯穿、冲击波与建筑坍塌高密度破坏音。
- 5.6–7.0s：破坏音衰减，远处火焰、风声与低频余震收束。

负面约束：不出现字幕与水印；主体外观不漂移；冲击帧不做成连续动画、慢动作或爆炸过程；冲击帧特效不得遮挡主体与目标剪影；不复用参考案例专有角色、台词、牌匾文字与道具符号。
```
