# 分段包模板（Segment Pack）

配合 `references/segment-splitting.md` 使用。触发分段输出时，交付物 = 1 张总控卡 + N 段独立提示词；每段提示词的六段结构、编号规则、冲击帧/音效/多主体等要求与 `full-prompt-template.md` 完全一致，本模板只补分段差异项。

`{...}` 占位符替换规则同 `full-prompt-template.md`；未提供项按 `templates/short-command-intake.md` 缺省策略处理。整秒/帧数配对（【2026-11-23 整秒修订】）：3s=73帧、4s=90帧、5s=124帧、6s=141帧、7s=158帧；执行侧一律按帧数设置，禁止按秒输入（会被向上吸附错档）。

---

## 总控卡（不投喂模型）


## 段1 提示词（标准六段，无承接区）

与 `full-prompt-template.md` 完全一致，仅四处分段差异：

- 总时长写整秒（如 6s 而非 5.9s），镜头段/子段与音效结束时间对齐整秒；节点执行侧按配对帧数设置（141 帧而非按秒输入）【2026-11-23 整秒修订】
- 每段镜头数下限【2026-11-24 克苏鲁包单薄修订】：每镜头平均时长 ≤3s（5s 段 ≥2 镜头、7s 段 ≥3）——禁单个镜头糊满全段；每镜头独立机位/景别切换（全景→中景→特写类分镜节奏），机器 FAIL 级拦截；台词须来自用户指令且全包口径统一（用户未给台词→全包无台词，禁自造台词+伪造"已按用户要求"注记）；音效行禁配乐/弦乐/管弦/合成器词（无BGM 包）
- 分段密度铁律【2026-11-24 分段密度修订】：每段只承担一个节奏单元（承接态不计，主节奏节点 ≤3），禁把「承接→推进→峰值→平台」整条起承转合塞进单段；**每镜头 ≥2 个子段**——子段级三槽（动作直述+可见细节+运镜参数）须在每个镜头充分展开，单镜头只写 1 个子段=信息稀薄。分段后每段变短，若仍按"每段一整条弧"写，每镜头只剩 1~2 子段，内容密度反而不如单份长镜头
- 段尾收尾子段补一句稳定化描述（停到动作平台），供段2头部锁定；**稳定化措辞必须与子段实际末态一致**——停步收尾就写停步平台，禁止"停在摊位前侧身回望"+"画面停在安静行走的平台"式自相矛盾句（切点承接行会复制此句并放大矛盾，25s v3 实测）【2026-11-24 稳定化措辞修订】
- 负面约束必含「无背景音乐」禁止项（I11 分段包强制——音效设计 header 声明"无BGM"无强制力，00033 实测成片出现弦乐/悬疑合成器/管弦乐）【2026-11-24 I11 槽位预填修订】
- 段尾收尾的最终状态句须是切点清单承接行的唯一信息源（I15 切点对齐）【2026-11-24 I15 修订】

## 占位符说明

| 占位符 | 含义 | 约束 |
| --- | --- | --- |
| `{整秒}` | 该段提示词总时长 | 必须为整秒：3/4/5/6/7s，禁止小数【2026-11-23 整秒修订】 |
| `{帧数}` | 采样帧数 | 与整秒严格配对：3s=73、4s=90、5s=124、6s=141、7s=158；执行侧按帧数设置，禁止按秒输入 |
| `{context档位}` | 衔接节点 context_frames 建议 | 常规叙事22 / 高速动作39 / 高破坏密度56 / 一致静置5 |
| `{承接区}` | 段首延续描述时长 | 随 context 档位：5→0.2s、22→0.9s、39→1.6s、56→2.3s |
| `{承接}` | 切点处承接描述 | 上段末状态一句话，写入总控卡切点清单 |
| `{段尾动作平台}` | 每段收尾状态 | 运动稳定、可被下段头部锁定的画面状态 |
