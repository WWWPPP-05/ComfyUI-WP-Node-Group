# 简短指令采集与缺省策略

## 一、优先抽取八要素

用户给出简短指令后，按以下顺序抽取信息：

| 序号 | 要素 | 说明 | 示例 |
| --- | --- | --- | --- |
| 1 | 主体 | 谁在施法/行动 | 角色A、白发龙族少女、熊猫、女仆 |
| 2 | 目标 | 打谁/封印谁/对谁释放 | 巨兽、虫王、目标单位B |
| 3 | 场景 | 在哪里发生 | 都市废墟、古风庭院、荒漠战场 |
| 4 | 招式/动作 | 大招、攻击、封印、处刑、突进 | 雷龙风暴、黑红旋风、符箓封印 |
| 5 | 风格 | 写实 CG、热血动漫、国风、暗黑、玄幻、生活流、科幻机甲、空灵唯美、超现实暗黑奇幻，或预设外自定义风格 | 热血写实 CG、国风悲情、写实生活流、赛博朋克雨夜 |
| 6 | 时长 | 视频总时长 | 7 秒、11 秒、5 秒 |
| 7 | 参考图 | 人物图、招式图、目标图、场景图、冲击帧图 | @Image1（主体绑定）、@ImageN（冲击帧绑定）【2026-11-24 标签化】|
| 8 | 冲击帧 | 是否有单次命中顶点；默认有单次命中则加 0.15–0.2s | 0.2s 冲击帧 |

## 二、扩展抽取：多主体 / 多目标 / 多动作 / 无冲击帧 / 持续状态 / 配对关系 / 预设外风格

在八要素基础上，必须额外判断以下七类结构：

### 1. 多主体抽取

用户提到多个主体时：

- 分别抽取每个主体的外观、发型、服装、配饰、比例、特殊状态。
- 分别编号：@Image1（主体绑定）、@Image2（主体绑定）……【2026-11-24 标签化】
- 记录主体之间的空间关系（同空间 / 不同空间 / 前后景 / 谁先入画 / 垂直层级 / 对称对峙）。
- 记录主体之间的互动方式（相遇、对视、回应、并肩、对峙、骑乘、承托、拉扯、拥抱）。

示例：

```text
用户：两个女人在客厅相遇，一个刚洗完头，5秒，写实生活流。
抽取：
- 主体A：坐在客厅的女人，黑色长发、白色短袖衬衫、领口蝴蝶结、耳饰、白色高跟鞋。
- 主体B：刚洗完头的女人，黑色短发盘发、细框眼镜、浅蓝色挂耳式耳机、浅蓝色无袖连衣裙、细项链、浅蓝色高跟鞋；头发湿润微贴、发梢带水光。
- 空间关系：客厅 + 洗手间 + 走廊相连。
- 互动方式：B从洗手间走出，沿走廊走向客厅，A抬头回应，双人同框。
```

```text
用户：两个跪地的角色，背上各骑着一个角色，7秒，超现实暗黑奇幻。
抽取：
- 主体A：承托方A，跪地姿态。
- 主体B：承托方B，跪地姿态。
- 主体C：骑乘方C，骑乘在A背上。
- 主体D：骑乘方D，骑乘在B背上。
- 空间关系：垂直层级，A与B并排跪地，C骑乘A，D骑乘B。
- 互动方式：骑乘 + 承托 + 轻触。
```

### 2. 多目标抽取

用户提到多个目标时：

- 分别抽取每个目标的体型、材质、关键发光部位、攻击姿态。
- 分别编号：@ImageN（目标绑定）、@ImageN+1（目标绑定）……【2026-11-24 标签化】
- 记录目标之间的排列关系或命中顺序。
- 若为同一目标的多个关键部位，写清各命中点关系。

示例：

```text
用户：四组机甲依次坠地，每次坠地要有音效峰值，7秒。
抽取：
- 目标：无独立攻击目标（自设动作序列）。
- 主体：四组机甲，分别为深蓝晶簇、暗红重装、银灰流线、第四组。
- 动作关系：四组依次坠落，每组独立硬着陆。
```

### 3. 连续动作抽取

用户提到连续动作时：

- 标记为“多动作峰值”，**不插入静态冲击帧**。
- 每次动作单独标注动作顶点时间段。
- 每次动作单独配置音效峰值。
- 峰值之间用环境底噪、破空声过渡。

连续动作类型包括：

- 连续硬着陆、连续坠地（并列硬着陆）
- 穿透式双硬着陆（单主体砸穿一层再落到下一层）
- 连续多次命中、连击
- 连续多个重物落地
- 多主体依次入场/依次登场

示例：

```text
用户：四组机甲依次坠地，每次坠地要有音效峰值。
处理：
- 不插入冲击帧。
- 每次硬着陆单独标注【硬着陆】时间段。
- 每次硬着陆单独配置【硬着陆峰值】。
- 最后一次硬着陆后接同框收尾。
```

```text
用户：龙族少女昏迷着从高空坠落，砸穿屋顶，5秒，东方玄幻。
处理：
- 判断为穿透式双硬着陆（砸穿屋顶 → 继续下坠 → 砸向地面）。
- 不插入冲击帧。
- 两次硬着陆分别独立标注【硬着陆】、独立配置【硬着陆峰值】。
- 两次峰值之间保留继续下坠的破空声。
- 镜头段写清“穿透后继续下坠”的因果链。
```

### 4. 无冲击帧场景抽取

用户场景属于以下任一类型时，**不插入冲击帧**：

- 环境叙事类
- 情绪特写类
- 纯氛围类
- 生活流、日常动作、视线交汇
- 多主体依次入场
- 连续硬着陆、连续坠地
- 穿透式双硬着陆

无冲击帧时，音效峰值改为：

- 情绪顶点类：对准情绪顶点或视线交汇
- 动作顶点类：对准每次动作顶点
- 喜剧张力递进类：对准多人同时动作的顶点
- 纯氛围类：写“以层次递进为主，无单点峰值”

示例：

```text
用户：森林池塘，龙族少女坐在池边，5秒，空灵唯美。
处理：
- 不插入冲击帧。
- 音效写“以层次递进为主，无单点峰值”。
- 叙事顺序：环境特写 → 主体近景 → 局部细节 → 侧脸与远景收束。
```

### 5. 角色持续状态抽取

用户提到昏迷、沉睡、被束缚、被定身、无意识、僵直、石化、被操控时：

- 在主体绑定中写明“全程保持XXX状态”。
- 在每个镜头的子时间段中重复强化该状态。
- 在负面约束中写明“全程保持XXX状态，不{睁眼/做表情变化/挣扎/自主动作}”。

示例：

```text
用户：龙族少女昏迷着从高空坠落，砸穿屋顶，5秒，东方玄幻。
处理：
- 主体绑定：全程保持昏迷状态，双眼紧闭、头部无力后仰、四肢自然垂落。
- 每个镜头：重复强调昏迷状态。
- 负面约束：全程保持昏迷状态，不睁眼、不做表情变化。
```

### 6. 多主体配对关系抽取

用户提到多个主体且存在配对关系时：

- 抽取配对类型：骑乘/承托/拉扯/并肩/对峙/拥抱/对视。
- 抽取空间位置：谁在上/下、谁在左/右、谁主动/被动。
- 在参考图绑定末尾补一条“配对关系”说明。
- 在叙事顺序中写清关系确立方式。
- 在镜头段中保持配对关系不漂移。
- 在负面约束中写明“保持XXX配对关系明确”。

示例：

```text
用户：两个跪地的角色，背上各骑着一个角色，7秒，超现实暗黑奇幻。
处理：
- 参考图绑定末尾补“配对关系”：图1与图2并排跪地，图3骑乘图1，图4骑乘图2。
- 叙事顺序：全景确立骑乘关系 → 分左右近景 → 四主体同框。
- 负面约束：保持图1与图2跪地、图3与图4骑乘的明确空间关系。
```

### 7. 预设外风格抽取

用户提到的风格不在 `style-presets.md` 的 A–K 预设内时：

- 判断是否接近某个预设（预设附近）：
  - 接近 → 最近邻派生：保留最近预设的渲染管线、节奏结构、镜头语言，只改风格质感、天光氛围、色彩主调、音效基调中差异的维度。
  - 不接近 → 用户自定义注入：不强行套预设，用参数化 7 维度组合出风格骨架。
- 用 7 维度参数化表填齐：风格质感、渲染管线、天光氛围、色彩主调、节奏结构、镜头语言、音效基调。
- 整体基调必须读起来连贯，不是关键词堆砌。
- 可沉淀到 `style-presets.md` 的“自定义风格记录区”。

示例：

```text
用户：赛博朋克雨夜追逐，不在任何预设里。
处理：
- 判断为完全不接近任何预设 → 用户自定义注入。
- 7 维度：
  1. 风格质感：赛博朋克写实 CG
  2. 渲染管线：UE5 电影渲染、HDR 光追、真实物理、电影景深、动态运动模糊
  3. 天光氛围：雨夜霓虹天光、体积雨雾、地面反光
  4. 色彩主调：青蓝霓虹 + 品红高光 + 暗黑底
  5. 节奏结构：高速追逐、急停、再加速
  6. 镜头语言：贴地跟拍、低角度仰拍、快速横移
  7. 音效基调：雨声底噪、霓虹电流滋滋、脚步踩水、远处警笛
- 生成连贯整体基调，不堆关键词。
```

```text
用户：国风庭院里的赛博机甲坠落。
处理：
- 判断为接近预设 A（暗黑史诗灾难）的坠落节奏 + 预设 B（国风悲情）的场景氛围 → 最近邻派生。
- 骨架：预设 A（坠落 + 硬着陆节奏）。
- 保留：蓄-冲-爆-收节奏、贴地跟拍、硬着陆峰值音效。
- 改：风格质感 → 国风 + 赛博混搭；天光氛围 → 国风庭院阴云天光 + 机甲冷光；色彩主调 → 青灰庭院 + 冷蓝机甲光；音效基调 → 寒风底噪 + 金属共振。
```

## 三、缺省策略

缺失信息不反复追问；优先用占位符或通用描述补齐。只有缺少主体/目标/场景导致无法成片时，最多追问 3 个关键问题。

### 1. 主体缺失

缺省写法：

```text
主体角色
```

保留用户已有外观词，如“白发”“双角”“紫瞳”“长裙”等。

### 2. 目标缺失

缺省写法：

```text
目标单位
```

若用户描述了目标类型（巨兽、虫群、人形），保留类型词。
若为生活流/氛围类无攻击目标，省略目标绑定，不硬塞“目标单位”。

### 3. 场景缺失

缺省写法：

```text
指定场景
```

若用户描述了场景氛围（废墟、古风、都市、室内、森林），保留氛围词。

### 4. 招式名缺失

缺省写法：

```text
核心招式/能量爆发
```

若用户描述了招式形态（龙卷、雷电、符箓、旋风），保留形态词。
若为生活流/氛围类无招式，省略招式绑定，不硬塞“核心招式”。

### 5. 时长缺失

默认：

```text
7.0s
```

复杂破坏可 10–12s；环境叙事可 5–7s；生活流可 5–8s；连续动作可 7–10s；穿透式双硬着陆可 5–7s。

### 6. 冲击帧参考图缺失

缺省写法：

```text
冲击帧参考图
```

规则仍按 `impact-frame-rules.md` 执行。
若场景不适用冲击帧，省略冲击帧绑定图，不预留空号。

### 7. 头饰/识别点缺失

缺省写法：

```text
关键识别点
```

### 8. 法器/道具缺失

缺省写法：

```text
法器/能量核心
```

生活流类可写“随身道具/手持物”。

### 9. 牌匾文字缺失

缺省写法：

```text
场景固定牌匾
```

不臆造具体文字。

### 10. 台词缺失

不写具体台词，只写气音/口型/情绪。

缺省写法：

```text
目标发出压抑低沉的痛苦气音
```

生活流类可写“轻声回应/气音”，不写具体句子。

### 11. 风格缺失

按 `style-presets.md` 三层决策处理：

- 预设内 → 命中预设，补差异维度。
- 预设附近 → 最近邻派生。
- 预设外 → 用户自定义注入，用参数化 7 维度组合。

快速判断：

- 战斗类 → 按招式形态选 A/C/E
- 封印类 → D
- 国风情绪 → B
- 生活流 → F
- 奇幻跨界 → G
- 超现实喜剧 → H
- 空灵唯美 → I
- 连续硬着陆 → J
- 超现实暗黑奇幻 → K
- 预设外 → 参数化 7 维度组合

### 12. 音频要求缺失

默认：

```text
无BGM，电影分层混音
```

有冲击帧时：峰值卡点对准冲击帧。
无冲击帧时：峰值对准情绪顶点/动作顶点/喜剧张力顶点，或写“以层次递进为主，无单点峰值”。

### 13. 负面约束缺失

默认写入：

```text
不出现字幕与水印；角色外观不漂移；冲击帧不做成连续动画、慢动作或爆炸过程；冲击帧特效不得遮挡主体与目标剪影；连续硬着陆不做成慢动作或静态冲击帧；穿透式硬着陆不做成静态冲击帧；场景固定构件不漂浮、不遮挡角色；不复用参考案例专有角色、台词、牌匾文字与道具符号。
```

无冲击帧时，可删去冲击帧相关负面约束。
角色持续状态时，追加“全程保持XXX状态，不{睁眼/做表情变化/挣扎/自主动作}”。
多主体配对关系时，追加“保持{主体A}与{主体B}{骑乘/承托/拉扯}关系明确”。

## 四、最多追问条件

只有以下情况最多追问 3 个问题：

1. 不知道主体是什么
2. 不知道目标是什么（且场景类型需要目标）
3. 不知道是战斗、封印、生活流、环境叙事、连续动作还是预设外自定义风格

追问示例：

```text
为了生成完整提示词，请补充：
1. 主体是谁？（角色外观/参考图；多主体请分别列出）
2. 目标是什么？（巨兽/人物/环境/无目标）
3. 这是单次命中战斗、封印、生活流、环境叙事、连续动作还是预设外自定义风格？
```

其他缺失项一律用缺省策略处理，不追问。

## 五、用户指令解析示例

### 示例 1：标准战斗指令（单主体 + 单目标 + 单次命中 + 冲击帧）

用户输入：

```text
角色A在废墟释放能量大招，命中目标B胸口核心，0.2秒冲击帧，热血写实CG，7秒。
```

解析结果：

| 要素 | 抽取结果 |
| --- | --- |
| 主体 | 角色A（单主体） |
| 目标 | 目标B（单目标） |
| 场景 | 废墟 |
| 招式 | 能量大招 |
| 风格 | 热血写实CG（预设 C） |
| 时长 | 7秒 |
| 参考图 | 未提供，用占位符，连续编号图1–图5 |
| 冲击帧 | 0.2秒，单次命中，命中胸口核心 |

处理：

- 选择风格预设 C（热血都市巨兽）
- 插入 0.2s 静态冲击帧
- 音效峰值对准冲击帧
- 参考图编号：主体图1 → 招式图2 → 目标图3 → 场景图4 → 冲击帧图5

### 示例 2：信息不足指令

用户输入：

```text
帮我写一个大招命中巨兽的提示词。
```

解析结果：

| 要素 | 抽取结果 | 处理 |
| --- | --- | --- |
| 主体 | 未提供 | 写“主体角色” |
| 目标 | 巨兽 | 保留 |
| 场景 | 未提供 | 写“指定场景” |
| 招式 | 大招 | 写“核心招式/能量爆发” |
| 风格 | 未提供 | 按动作选“热血都市巨兽” |
| 时长 | 未提供 | 默认 7.0s |
| 参考图 | 未提供 | 用占位符，连续编号 |
| 冲击帧 | 有单次命中 | 默认 0.2s |

此例不需要追问，可直接生成。

### 示例 3：环境叙事指令（无冲击帧 + 层次递进音效）

用户输入：

```text
国风庭院，角色被锁链捆住，痛苦特写，7秒。
```

解析结果：

| 要素 | 抽取结果 |
| --- | --- |
| 主体 | 角色 |
| 目标 | 无 |
| 场景 | 国风庭院 |
| 招式 | 无 |
| 风格 | 国风悲情写实（预设 B） |
| 时长 | 7秒 |
| 参考图 | 未提供，用占位符 |
| 冲击帧 | 无命中顶点，不插入 |

处理：

- 选择风格预设 B（国风悲情写实）
- 叙事顺序：环境构件特写 → 被束缚主体近景 → 痛苦面部特写
- 不插入冲击帧
