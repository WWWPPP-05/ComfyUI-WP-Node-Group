# 长片分段规则（Segment Splitting）

本文件定义"单一完整提示词 → 多段独立提示词包"的拆分规则，配合 WP H3 段间衔接节点（latent-continue 桥接）+ H3 视频拼接节点实现长视频生成。触发方式见 SKILL.md「分段输出（条件触发）」。

**适用前提**：用户工作流使用 WP_H3SegmentBridge（latent 硬拷贝 + 锥形锁定接缝）+ WP_H3VideoConcat（按元数据裁头裁尾）。连续性由 latent 级硬保证，文本不承担"求模型连续"的职责，只承担"与锁定头不冲突"的职责。

---

## 一、三条实测硬规则（2026-11-23 双段定位测试结论）

### 1. 时间轴规则：直接照写，无偏移

桥接段（段N，N≥2）的提示词时间轴**按"导出可见画面"从 0.0s 直接书写**，与段1 写法完全一致，不做 +0.9s 之类的头部缓冲偏移。

实测依据：接缝后紫烟事件写在 5.0s，实测出现在 4.88s（接缝后计时），无系统性前移；若存在 0.92s（22帧/24fps）偏移则应出现在 4.08s。剩余偏差在 H3 已知 ±1s 天然漂移内（见 camera-motion-layer.md「时刻与配速」）。

推论：绝对秒数只是引导；关键事件的同步靠**段内对齐**（冲击帧与音效峰值写同一时间戳、峰值对准动作顶点），不靠跨段绝对时刻。

### 2. 段长规则：整秒制，整秒与帧数严格配对【2026-11-23 整秒修订】

分段规划与提示词时间轴一律使用**整秒**，禁止小数秒。整秒档与 17k+5 网格帧数一一配对：

| 提示词总时长 | 段长设置（帧） | 实际生成窗口 | 差异机制 |
| --- | --- | --- | --- |
| 3s | 73 | 3.04s | 尾差 1 帧，可忽略 |
| 4s | 90 | 3.75s | 时间轴压缩 6%（实测安全方向） |
| 5s | 124 | 5.17s | 尾差 4 帧 ≈0.17s，落在段尾稳定平台内（见段尾规则），无害 |
| 6s | 141 | 5.88s | 压缩 2% |
| 7s | 158 | 6.58s | 压缩 6% |

**配对铁律**【2026-11-24 三层架构改造：案情迁出至 lessons.md，此处只留规则】：

- **执行侧一律按帧数设置段长**（空 latent / 生视频节点填 73/90/124/141/158），禁止按秒设置——按秒输入会被系统逐段独立向上吸附错档（填 4s→107 帧、填 3s→73 帧、填 6s→158 帧），每段多出无提示词覆盖区，成片节奏后漂、接缝静音、段尾即兴（契约 I1，校验函数 check_frame_budget；实测数据见 `lessons.md`）
- **交付提示词包时必须口头+预算表双通道向用户强调"执行节点填帧数"**，并在总控卡写明成片验收公式：成片总帧数 = 预算表帧数之和，超出即秒数吸附，回查执行侧设置
- **禁止混搭**：6s 只配 141 帧；158 帧段必须写 7s
- 4–5s 之间的 107 帧档（4.46s）不进整秒表；确需使用时写 5s（压缩 10%），禁止写 4s（尾部 0.46s 失控）
- 8G 显存单段 ≤7s（可见 158 帧）；桥接段实际采样帧数 = 可见 + context + 12（如可见 141 + context 22 → 采样 175）
- 镜头段边界与子段时间戳**优先取整秒**；需要细分时允许 0.5s 粒度（冲击帧 0.15–0.2s 时长等亚秒物理量除外）

差异方向说明（实测）：时间轴**长于**窗口 → H3 按比例压缩、不丢事件（安全兜底）；时间轴**短于**窗口 → 尾部脱离脚本、元素自行漂移（危险）。整秒表按"尾差 ≤0.2s（3s/5s 档，由段尾稳定平台规则兜底）或走压缩方向（4s/6s/7s 档）"设计，均不进危险区。

### 3. 切点规则：避开硬切点、冲击帧、硬着陆

桥接机制下，段N 开头画面被硬锁为上段末帧的延续，因此切点选择与普通拆分**相反**——最忌切在硬切点上。

**切点优先级**：

```text
最佳：动作持续平台——某子时间段动作顶点之后、下一动作启动之前，运动状态稳定
次佳：镜头段边界——但要求下一镜头开头是延续性画面，而非全新构图
兜底：子时间段边界
```

**禁止下刀处**：

- 硬切点、发动切镜点（文本驱动的硬切全部移到段内中后部执行）
- 冲击帧内部及其前后缓冲（冲击帧所在镜头整段落入同一段，且不落在段首——前面要保留蓄势铺垫，距段首 ≥2s）
- 硬着陆瞬间、蓄能中段
- 穿透式因果链中间（砸穿→继续下坠之间）；整链优先不跨段，必须跨段时在承接区写明因果残留
- 角色持续状态转换瞬间（昏迷/束缚状态全程任意点可切，但"清醒→昏迷"这类转换本身不可跨切点）

## 二、分段包结构

分段包 = 1 张总控卡 + N 段独立提示词。每段提示词结构完全遵循 `distilled-format.md` 六段式，不新增交付段落。

### 1. 总控卡（不投喂模型，仅供人调度）

```text
【总控卡】
- 总时长：{全局总秒数}｜分段数：N｜段数规划无上限
- 全局画幅锁定：所有段分辨率/画幅必须一致（衔接节点强制校验）
- 分段预算表【2026-11-23 修订：帧数前置，执行节点只认帧数】：
  段1｜执行填 {帧数} 帧｜提示词写 {网格秒数}s｜全局 0.0–X s
  段2｜执行填 {帧数} 帧｜提示词写 {网格秒数}s｜全局 X–Y s
  …
- 各切点：类型（动作平台/镜头边界/子段边界）+ 全局位置 + 承接描述
- context 档位建议（见第四节）
- 冲击帧归属段 + 全局位置
- 音效峰值全局分布一览
- 整体基调原文（逐字复制区，每段必须完全一致）
```

### 2. 段N 提示词（独立可粘贴）

- 整体基调：从总控卡**逐字复制**，跨段风格统一靠这句话压制
- 参考图绑定：**全量重复**，编号与段1完全一致——桥接只锁定画面 latent，参考图每段都是独立生成、必须重新喂
- 叙事顺序：段内局部链路，从承接态写起（段N≥2）
- 镜头段：时间轴从 0.0s 直接书写（规则一）
- 音效设计：段内独立切分，峰值随段内时间重算
- 负面约束：全量保留 + 分段专项（见下）

### 3. 承接区规则（段N≥2 段首约 1s）

段首约 1s（context 22 档 ≈0.92s，对应被裁头部缓冲）必须写"延续中的状态"——上段末帧正在进行的动作、姿态、氛围的延续描述。这部分画面会被裁掉，但保证生成时文本与锁定画面一致，接缝后过渡干净。

```text
- 0.0–1.0s：{上段末尾状态的具体延续，如"尘埃在光柱中缓慢下沉，画面延续前一段结尾的安静稳定状态"}
```

context 39/56 档时承接区相应拉长至约 1.6s/2.3s。

**禁止**：承接区写全新构图、新镜头启动、已完成事件的重复叙述。

### 4. 段尾规则：停在动作平台

每段收尾必须停在一个**运动稳定、可被下段头部锁定的状态**——尘埃落定、姿态稳定、镜头停止、氛围平复。段尾禁止停在动作顶点、特效爆发中、镜头剧烈运动中（否则下段锁定头是一张"高速运动残影帧"，接缝质量崩坏）。

这是 `performance-layer.md`「段间留物理痕迹」在长片场景的放大版：段尾留下什么状态，下段承接区就承接什么。

## 三、音效分段专项规则

1. 段首约 1.5s 内（承接区 + 锁定解锁过渡区）**不安排音效峰值**，只写环境底噪延续——音频对引导信号敏感（节点 v3 曾因音频双重引导出现接缝后回声重说）
2. 冲击帧峰值/硬着陆峰值距段首 ≥2s
3. 每段独立保留"无BGM，电影分层混音"声明与收尾衰减——拼接节点只做波形直拼，段尾音频必须自然衰减，否则接缝音量跳变
4. 音效时间段 = 该段整秒总时长（规则二配对表），结束时间写整秒【2026-11-23 整秒修订】
5. **非末段的段尾衰减至"低频余震 + 环境底噪延续"，禁止衰减至静默归零**（契约 I10，校验函数 check_seam_audio；实测波形对比见 `lessons.md`）。标准写法：非末段收尾写"音量衰减至低频余震与环境底噪延续，不归零"；仅全片最后一段才写"静默黑屏"或"低频余震收束"。禁止在非末段出现"静默""无声""完全静音"字样
6. 硬切点同步音效标注规则不变，段内硬切照常标注【切镜同步音效点】

| 5 | 0.21s | 接缝两侧画面状态高度一致（长镜头平移、静置场景） | 最省显存/生成量，接缝容忍度低 |

## 五、分段规划流程

1. **排全局时间轴**：按 `distilled-format.md` 正常排出完整分镜（镜头段连续无重叠、含冲击帧与峰值位置）
2. **标保护区间**：冲击帧镜头（±2s）、硬着陆（前后各 0.5s）、穿透式因果链（整链）、蓄能段——这些区间内禁止切点
3. **选切点**：在保护区间之外，按切点优先级（动作平台 > 镜头边界 > 子段边界）布点，段首为承接区留 1–2.3s（按 context 档）
4. **对齐整秒**：各段可见时长就近吸附到整秒档（3/4/5/6/7s），并按规则二配对表锁定对应帧数（73/90/124/141/158），吸附时优先保镜头段边界、微调子段边界【2026-11-23 整秒修订】
5. **写段尾平台**：每段末镜头/子段改写为可稳定锁定的收尾状态（补一句稳定化描述即可，不改叙事）
6. **生成分段包**：总控卡 + 逐段提示词，逐项过 `checklists/quality-gate.md` + 本文件第六节检查表

## 七、与现有规则的关系

- 冲击帧、音效、多主体、持续状态、表演子层等规则**段内照常适用**，本文件只管"段间怎么切、怎么接"
- 本文件不改写 `distilled-format.md` 的任何段落格式；分段包中每段提示词就是一份合规的完整提示词
- 多主体配对关系、角色持续状态三重强化在**每段内**独立成立（配对关系写进每段绑定、持续状态在每段的绑定/子段/负面三处强化）
