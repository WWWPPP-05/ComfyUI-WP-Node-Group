# 表演子层规则

表演子层是镜头内容的生产规则，不是新的交付格式。启用后，表演细节注入现有 H3 格式的四个位置：参考图绑定（表情气质边界）、镜头子时间段（可见动作）、音效设计（呼吸与情绪声音）、负面约束（表演类禁止项）。交付格式仍为"整体基调/参考图绑定/叙事顺序/镜头/音效/负面约束"，不新增段落。

**【无台词场景唇部禁令 2026-11-24 v5 复发修订】** 注入惊恐/震惊/欲言又止类表情细节时，禁用唇部开口类措辞（"嘴唇微张/微启/口鼻微张"）——该措辞诱导模型生成清晰说话口型（00033 与 25s v5 两次成片/包实测复现）。替代轨道：喉结滚动、一次清晰吞咽、短促倒吸气、瞳孔收缩、眼白露出、下颌绷紧、额角渗汗、眉毛上挑。

---

## 一、启用判定（按场景启用，不污染战斗结构）

### 1. 默认启用

- 情绪特写、生活流、视线交汇类
- 多主体对峙/拉扯/互动/同框类
- 环境叙事中含人物近景的情绪段
- 用户点名要求"表演、情绪、演技、反应"的场景

### 2. 默认不启用

- 大招命中、封印、处刑等单次命中顶点（冲击帧结构不动）
- 连续硬着陆、穿透式硬着陆、连续命中（硬切 + 峰值结构不动）
- 纯能量突进、纯环境氛围、无人物近景的镜头

### 3. 战斗类局部启用

用户要求战斗中的表演时，只在**蓄能近景、收尾互动**等写实镜头加入表演细节；冲击帧、硬着陆、音效峰值结构不插表演内容。冲击帧是剪影定格，帧内不写表情。

## 二、六条表演轨道

把情绪翻译成镜头能看见的连续表演，六轨不必每秒全出，但必须互相支持：

| 轨道 | 内容 |
| --- | --- |
| 眼神 | 看向哪里、何时移开、何时重新聚焦 |
| 面部 | 眉眼、嘴角、下颌、鼻翼与面部张力 |
| 头肩 | 头部朝向、下巴高度、肩膀松紧、颈部状态 |
| 手部 | 手指、手掌、手臂与场景物件互动 |
| 身体 | 躯干、重心、步伐、靠近或远离 |
| 呼吸声音 | 吸气、呼气、停顿、叹息、吞咽、笑声、哭腔 |

支持原则：

- 眼睛表达防备时，身体不能完全敞开；嘴角在笑时，眼神和肩膀决定是真笑、假笑还是苦笑。
- 情绪爆发时，呼吸和身体幅度同步升级。
- 只写脸会像滤镜动画；完整表演让情绪从面部传到头肩、手部、重心和呼吸。

## 三、情绪决策层

### 1. 单一情绪内部变化

不是整段保持同一张脸，而是同一方向内变化：

```text
微弱出现 → 逐渐清晰 → 做出动作 → 留下余韵
```

### 2. 先后转换（三阶段）

情绪 A 经事件触发转成情绪 B，必须走完：

1. **原状态残留**：上一种情绪仍有可见痕迹（抿紧的嘴、僵住的手）；
2. **争夺阶段**：新旧信号短暂并存，动作可能停顿或不完整；
3. **新状态接管**：眼神、姿态和呼吸共同稳定到新方向。

写法示例（正确）：

> 她原本抿紧的嘴唇慢慢松开，目光在物件上停了一拍；确认之后，眉眼才舒展开，嘴角跟着浮起一丝笑意。

禁止直接写"她从紧张变成开心"这种标签跳变。

### 3. 同刻混合（又气又委屈/笑中带泪/强装镇定）

- 选一个主情绪控制眼神、头肩和身体姿态；
- 另一种情绪只从嘴角、眼眶、手指或呼吸中的一两个细节泄露；
- 不把两种情绪平均铺在全身；保留一个互相冲突的可见瞬间。

### 4. 四档强度

| 档位 | 常见用词 | 面部 | 肢体 | 呼吸 |
| --- | --- | --- | --- | --- |
| 微弱 | 一丝、有点 | 一个局部先变化 | 手指、视线或头部小动作 | 平稳 |
| 克制 | 忍住、假装没事 | 两到三个局部对抗 | 身体收紧，动作可能中断 | 停顿、短吸或长呼气 |
| 明显 | 很、越来越、压不住 | 眉眼嘴部下颌共同变化 | 头肩手和重心明显响应 | 变快、变重或不均匀 |
| 爆发 | 彻底、崩溃、失控 | 全脸高幅度 | 全身参与，出现大动作 | 急促、断续或大口呼吸 |

强度必须同时影响幅度、速度、面部范围、身体程度和呼吸，不能只把"微微"改成"剧烈"。

### 5. 相似情绪快速区分

| 易混对 | 区分要点 |
| --- | --- |
| 自然微笑 vs 讨好假笑 | 前者眼神稳定肩膀放松；后者嘴角用力、眼睛频繁观察对方反应 |
| 隐忍怒意 vs 坚毅不屈 | 前者视线带攻击性、下颌积压张力；后者目光清醒稳定、呼吸受控、身体站稳 |
| 忧郁惆怅 vs 绝望麻木 | 前者仍会看、会叹气、会回应；后者视线失去抓取、支撑感消失 |
| 惊讶 vs 惊恐 | 前者短暂睁大停住后开始理解；后者身体后撤、防御、呼吸卡住 |
| 高傲鄙视 vs 冷漠无视 | 前者用余光、单侧嘴角、仰头主动表达；后者几乎不给信号、视线越过对象 |
| 委屈 vs 哀求 | 前者身体缩小、想表达又退回；后者主动靠近或降低姿态、视线持续追随 |

## 五、微剧情结构

情绪不是孤立动作，人物必须正在做事、受到触发或做出决定：

```text
想做什么 → 发生变化 → 做出决定
```

- 目标必须具体可拍：拿起、放下、递出、收回、查看、遮住、折叠、整理衣物、关窗、想说一句话又停住。
- 转折来源优先级：图中已有物件 > 人物正在做的动作 > 与镜头的关系 > 同框角色的动作 > 环境声音或光线变化 > 用户给出的剧情。
- 防套路化检验：换个完全不同的图，这个转折是否照样成立？若是，说明转折太通用，回到图中找更具体的物件、姿势或光线证据。
- 单人场景默认镜头是交流对象；画外人物只写声音（"画外传来一句模糊人声"），不写画外身体动作。

## 六、表演时间轴规则

时间连续、从 0.0s 到总时长、段间不重叠等基础规则沿用 `distilled-format.md`，此处只补表演专用规则：

1. **一段一个主动作**：每段 = 主动作 + 一两个面部/视线变化 + 一个身体/呼吸或物理结果。不在同一小段里塞转身、落泪、拿物件、说台词、坐下。
2. **按动作复杂度切段**：视线弹开、眨眼、突然停住约 0.6–1s；抬手、回头、表情变化约 1–1.4s；拿取、放下、转身、坐下约 1.2–1.8s。不机械地每两秒切一段。
3. **先写视线，再写表情**：犹豫、发现、警惕、躲避、回神类变化，观众先读视线。
4. **段间保留物理痕迹**：泪痕仍在、眼眶仍红、呼吸仍乱、手仍悬在半空、物件仍被握住、头发衣摆仍有惯性——上一段留下什么，下一段先承接什么。
5. **状态变化要有开关**：眨眼使泪滑落、吞咽压回话语、倒吸气抬起肩膀、指尖碰到物件使动作停住、提示音使视线转移。不写无触发突变。
6. **动静交替**：大动作推进剧情，小动作做情绪纹理；不让全片只剩眨眼和指尖颤动，也不让每秒都满动作。
7. **大动作按动力顺序**：目光先转 → 头部跟上 → 肩膀带动上半身侧转；先收紧腹部直腰 → 再收回撑桌的手掌。
8. **主动作补一个物理结果**：快速抬头带起额前碎发、转身后发尾延迟甩动、杯子落桌液面轻晃、握紧时指节变浅、长呼气时胸腔肩膀一起落下。一段最多补一个，不堆砌。
9. **保留中断和不完整**：全片一到三处——手伸出后停住、话到嘴边咽回、笑只出现半边、回头只完成一半。不要每段都中断。
10. **情绪高点不等于动作最多**：高点可以是突然静止（只剩呼吸顶起胸口、视线一动不动）；也可全身爆发，取决于情绪类型。
11. **结尾双锁**：最后一段同时锁定最终姿态/表情/视线/物件状态，以及镜头保持不动、无黑屏无转场。
12. **招式锚定双保险**：动作顶点子段（含【动作顶点】【硬着陆】等标注的子段）必须同时写清"招式名直述 + 物理结果"两件事，缺一即弱锚点。招式名必须以直述句式独立出现（如"{主体}双角前倾冲撞"完整出现，不藏在从句里），物理结果紧跟其后；子段内禁止用"发力""蓄势"等模糊动词替代具体招式名。（实测案情见 `lessons.md`）【2026-11-24 三层架构改造：案情迁出】
13. **生活流关键互动锚定**：生活流/情绪类剧情中承担剧情转折的关键互动事件（擦肩、肩膀相碰、递物件、牵手、回头、扶住等）与招式同待遇——事件名必须以直述句独立出现 + 紧跟可观察的物理/身体结果，且该事件子段所在镜头的叙事顺序行也要点名它。写法示例："- 2.6–3.2s：两人肩膀在画面中央轻轻相碰，衣料挤压变形，两人脚步同时一顿。"事件词独立成句，不并入过程描写中。（实测案情见 `lessons.md`）【2026-11-24 三层架构改造：案情迁出】

## 七、六轨动作词库（精选）

选择时优先贴合人物当前姿态和场景物件，不把一整组词堆进同一段。

### 眼神

- 聚焦：目光慢慢停在对象上；视线从失焦重新收拢；眨眼后重新锁定同一位置。
- 躲闪：视线刚碰到对象便弹向一旁；只从眼角短暂偷看；对视不到一秒便落向地面。
- 搜寻：余光先发现变化，正视稍后跟上；视线沿桌面逐件扫过物品。
- 失焦：目光越过镜头落向远处；眨眼之后仍没有重新聚焦。

### 面部

- 放松：眉心浅纹慢慢展平；眼角轻轻弯起，笑意进入眼睛；紧绷的唇线恢复自然厚度。
- 收紧：眉头靠拢压低；双唇抿成窄线；下颌两侧绷硬；牙关咬住，面颊线条变硬。
- 不对称：单侧嘴角先扬起，另一侧保持原状；一边眉毛略高；笑意只停在半边脸。
- 湿润落泪：下眼睑边缘先浮起水光；眨眼瞬间一滴泪脱离眼睑；泪痕沿面颊缓慢下移。

### 嘴部与声音前兆

- 想说又停：双唇张开一次又合上；一次吞咽把句子截断；开口前吸气却没有发出声音。
- 压抑：下唇轻颤后被咬住；嘴角刚要下坠又提住；喉结滚动一次，声音没有出来。
- 笑意：嘴角先出现很浅弧度；笑意从嘴角逐渐走到眼睛；笑容停在嘴部，眼神仍紧张。

### 头肩

- 头部：目光先转，头部稍后跟上；下巴缓慢内收；低头进行到一半停下；摇头只完成一次。
- 肩膀：吸气时抬高，呼气时明显落下；双肩内收缩小身体体积；先耸起，再无力垮下。

### 手部与物件

- 抓握：手指逐根收紧；指尖把衣角揉出褶皱；握紧后指节颜色变浅；物件从松弛手指间缓慢下滑。
- 伸出收回：手臂抬起一半停在空中；想触碰对方的手在最后一刻收回；递出的物件因犹豫又往回收。
- 放置决定：杯底轻轻落回桌面；指腹压住纸角慢慢合上；放下后手指仍在旁边停留。

### 身体重心

- 靠近：重心从后脚移到前脚；上半身前倾双脚留在原地；身体降低高度主动缩短距离。
- 远离：重心先向后撤脚步随后退开；躯干向后避开头部仍盯着对象；把身体交给椅背退出对抗。
- 下沉支撑：一只手撑住桌沿身体才没有继续下坠；肩膀和胸腔一起塌下；双脚重新站稳躯干一点点直起。

## 八、呼吸与情绪声音

### 五种呼吸类型

| 类型 | 适用情绪 | 写法要点 |
| --- | --- | --- |
| 平稳 | 自然微笑、专注、冷漠、坚毅 | 胸腔轻微均匀起伏，说话前只做自然吸气 |
| 长呼气 | 释然、欣慰、无奈、疲惫 | 先完整吸气短暂停住，呼气从微张双唇缓慢释放，肩胸随之下沉 |
| 克制 | 隐忍怒意、憋屈、委屈、无声落泪 | 鼻腔呼吸，吸气到喉间停住，一次吞咽压下情绪，偶尔漏出不完整抽气 |
| 急促 | 烦躁、惶恐、狂喜、明显愤怒 | 吸气变短频率增加，句间快速补气，鼻翼轻微张合，高点后逐渐恢复 |
| 断续 | 哽咽、战栗、惊恐、崩溃 | 一口吸气被切成几段，呼吸在喉头卡住，肩膀随每段吸气轻抖，结束逐步减弱 |

### 注入音效设计的方式

表演子层的呼吸/情绪声音写入现有音效设计分层中（不改变"无BGM，电影分层混音"格式）：

- 环境底噪层保持不变；
- 动作声补触发点：衣料在握紧时的很轻摩擦声、纸张展开的连续克制摩擦声、鞋底后撤短促擦过声；
- 情绪声音层：吞咽、短吸气、被压住的哽咽、结尾缓慢呼气——靠近人物但不夸张放大；
- 人物屏息或静止时，环境底噪在主观上更突出，但不写成夸张音效。

### 台词补全规则（用户提出说话但未给具体台词时）

判断信号：用户输入出现“说、喊、骂、吼、叫、对话、交谈、争吵、咆哮、低语、回应、聊天”等台词意图词，但未给出具体台词。

此时不得降级为“无台词/气音/不生成清晰口型”，必须根据场景、人物关系、情绪强度自动补全具体台词。

补全原则：

- 短句口语化：每句 5–12 字，贴近真实对话，不写书面腔。
- 贴合情绪强度：愤怒争吵用短促质问、打断、重复（“你放开！”“放开我！听见没有！”）；伤心哽咽用断续短句。
- 贴合角色关系与身份：陌生人骂架、母女争执、情侣吵架、上下级冲突，用词与称呼不同。
- 情绪激动时不写完整播音句：句子可被打断、吞字、重复，可带语气词（“你……你给我站住！”）。
- 尺度按真实冲突来：冲突类场景允许出现更激烈的词，按人物当时情绪与关系自然补全，不刻意回避、也不为激烈而激烈。
- 5 秒短视频一两句即可，不塞满时间轴；台词服务于冲突顶点，不抢走动作戏。

写入位置（三处一致，避免“正文写说话、约束禁口型”的矛盾）：

- 正文（镜头子时间段）：写清谁说、具体台词（加引号）、音量、语速、说话时视线与身体变化。
- 音效设计：写清说话声 + 音色（压低/提高/沙哑/破音）+ 伴随呼吸与动作声。
- 负面约束：不写“不生成清晰说话口型”，改为“台词与口型自然同步；无台词时不加台词”。

补全示例（“两个人在街上扭打，边打边骂”）：

```text
- 1.2–1.9s：左侧女人揪住对方衣领，压低声音怒骂脱口而出：“你放手！”脖颈绷紧，眼神凶狠。
- 1.9–2.6s：右侧女人反手拽住卫衣前襟，提高音量回骂：“你先松手！”头发甩动，声音带破音。

音效：1.2–2.6s 左侧女人压低怒骂“你放手”、右侧女人提高回骂“你先松手”，衣料撕扯声与急促呼吸交织。

负面约束：台词与口型自然同步，对骂时不出现字幕。
```

### 无台词规则

无台词时必须写：

> 无台词，不生成清晰说话口型，只保留自然呼吸、吞咽、叹息或情绪声音。

无台词时正文（镜头子时间段）同样不得描写说话行为——不写“开口说话”“口型自然连续”“说完一句话”，只写气音、哽咽、嘴唇开合不成句。正文、音效、负面约束三处必须一致，不得正文写说话、约束禁口型。

无台词场景**禁用一切开口类动作词**（嘴唇轻启、开口、欲言又止地张嘴、做出道歉/念白/呼喊姿态等）——此类灰区措辞会被生成模型解读为说话许可，诱导出凭空台词（契约 I9，校验函数 check_dialog；实测案情见 `lessons.md`）。需要表达道歉/欲言/压抑等情绪时，改用**不开口的等价动作**：道歉=颔首拱手/欠身致意/视线致歉；欲言又止=嘴唇抿紧、喉结滚动、视线移开又收回。正文、音效、负面约束三处仍须一致。【2026-11-24 三层架构改造：案情迁出】

凡无台词场景，负面约束必须含“无台词，不生成清晰说话口型”声明；若叙事顺序出现“交谈”“对话”等词，正文或音效必须交代气音/口型处理（如“嘴唇开合似要倾诉，只发出气音”），不留悬念。

有台词时写清：谁说、何时开口、音量、音色、语速、停顿、呼吸、说话时视线和身体是否变化。台词不塞满时间轴，情绪激动时不保持播音式完整句子。

## 九、多角色表演反应链

多主体的外观绑定、配对关系、音效归属沿用现有规则，此处只补表演层：

1. **每一拍只有一个主动者**：主动者做动作 → 对方先接收到（视线/手部第一反应）→ 再完成表情变化或回应 → 主动者接收回应。禁止对方在动作完成前提前做出结果性表情。
2. **一拍一个表演重点**：主角色清晰面部、完整动作、主要声音；次角色只给轮廓、视线、一个回应动作；下一拍可交换主从。禁止两人同时哭、同时挥手、同时转身、同时说话。
3. **对话节拍**：A 开口 B 先听 → B 目光或手部第一反应 → A 说完留短暂停顿 → B 再完成表情或回答。沉默也是对话——一个停住的手、移开的视线，常比立刻回答更有效。
4. **视线对应**：写清 A 在左 B 在右、谁看谁、何时看向镜头；拆单人镜头时视线方向与上一镜头对方位置一致，且承接此前的泪痕、物件和姿态变化。
5. **物件传递控制权**：A 拿起 → A 伸出停在两人之间 → B 先看物件 → B 伸手接触 → A 松开 → B 收回。一次只属于一只明确的手，不写两人同时抓住后瞬间换位。

## 十、注入 H3 格式的写法

### 1. 参考图绑定中

主体绑定追加表情气质变化边界（不改变编号与绑定结构）：

```text
- @Image1（主体绑定）：{外观锁定...}；表情气质由{起始情绪}向{目标情绪}渐变，{边界，如"笑意不超过嘴角、眼眶水光不落泪"}；角色外观不得漂移。
```

### 2. 镜头子时间段中

表演动作按"先视线、后面部、再身体呼吸"的顺序写入子时间段，遵守一段一个主动作：

```text
- 0.0–1.2s：她保持参考图坐姿，视线安静停在桌上信封；指尖碰到信封边角，准备向前拉动。
- 1.2–2.0s：目光停在那道折痕上，手部动作中途僵住；眼皮缓慢垂下，双唇向内抿紧，喉间一次清楚吞咽。
```

### 3. 音效设计中

```text
- 3.2–3.6s：一声克制的吞咽与短吸气，靠近人物但不夸张放大；纸张细微摩擦声。
```

无台词时负面约束追加：不生成清晰说话口型。

### 4. 负面约束中（表演类禁止项，按需选用）

- 无台词时不生成清晰说话口型；
- 表情变化必须有触发，不无原因跳变；
- 不做过场式标准表情（全脸同步到位、左右完全对称）；
- 情绪转换保留前一状态痕迹，不瞬间变脸；
- 眼泪、泛红、呼吸、物件前后连续。

## 十一、常见表演失败与修正

| 症状 | 修正 |
| --- | --- |
| 只有情绪没有动作（"她越来越难过"） | 给具体目标，加入可拿/放/看/遮/推/收回的物件，每个变化绑定一个动作 |
| 动作很多没有情绪 | 每个主要动作补视线和一个面部信号，写明速度力度，加呼吸或停顿 |
| 全片只剩微动作 | 加入完整的拿起、放下、转身、靠近、坐下，写清起点过程终点 |
| 每秒都满动作 | 一段只留一个主动作，情绪高点安排一次静止 |
| 情绪瞬间切换 | 保留上一情绪的下颌、泪痕或呼吸；安排确认、吞咽、触碰物件等转换开关 |
| 表情太对称太完成 | 视线先于头部；用一次单侧嘴角或眉毛；保留一个没完成的动作 |
| 呼吸与强度不匹配 | 微弱克制保持平稳；明显加胸腔鼻翼句间补气；爆发才用断续大口呼吸 |
| 单人场景出现隐形演员 | 交流对象改为镜头；画外人物只写声音；实体互动不可缺少时改为双人同框任务 |
| 负面约束污染正文 | 正文只写希望看见的画面；禁止项集中放负面约束段 |
