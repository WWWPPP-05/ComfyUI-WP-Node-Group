# 风格预设与风格决策

## 零、核心定位

**本文件中的预设不是封闭清单，而是高频组合快捷方式。**

用户需求可能落在三种情况之一：

1. **预设内**：命中某个预设 → 直接用预设，补差异维度。
2. **预设附近**：接近某个预设但不完全匹配 → 最近邻派生，保留骨架改差异。
3. **预设外**：完全不接近任何预设，或用户直接给出完整风格描述 → 用户自定义注入，用参数化维度组合，不强行套预设。

无论哪种情况，最终都落到 **7 维度参数化表**，保证整体基调可读、连贯、不堆关键词。

**禁止**：预设不匹配时强行套错预设；预设外时只堆风格关键词、不填参数化维度。

---

## 一、三层决策结构

```text
第一层：参数化维度（打底，覆盖一切）
   ↓
第二层：预设匹配（高频组合，快速命中）
   ↓
第三层：兜底
   ├── 最近邻派生（预设外，但接近某个预设）
   └── 用户自定义注入（完全预设外，用户给完整风格描述）
```

### 决策顺序

1. 先看能否命中某个预设 → 命中则直接用，补差异维度。
2. 不能命中但接近某个预设 → 最近邻派生：保留最近预设的骨架，只改差异维度。
3. 完全不接近任何预设，或用户给了完整风格描述 → 用户自定义注入：只做规范化，不强行套预设。
4. 无论哪层，最终都填齐 7 维度参数化表，生成连贯整体基调。

## 二、第一层：参数化维度表

任何风格需求都能拆进以下 7 个**正交维度**。预设只是这些维度的高频组合。

| 维度 | 作用 | 常见取值 |

| 3. 天光氛围 | 决定光照与空气感 | 厚重风暴天光 / 室内柔和自然光 / 阴云冷调天光 / 体积雾尘 / 火光烟尘 / 暖白射灯 / 幽暗森林天光 / 冷灰雾气 / 雨夜霓虹天光 |
| 4. 色彩主调 | 决定冷暖与对比 | 黑红金 / 冷灰幽紫 / 银白冷调 / 暖调 + 冷调过渡 / 白金圣光 / 暗红岩浆 / 暖白 + 浅蓝 / 青蓝霓虹 + 品红高光 |

| 6. 镜头语言 | 决定分镜写法 | 低角度仰拍 / 贴地跟拍 / 侧前方近景 / 多主体分述 / 横移跟拍 / 高机位俯拍 / 极缓推近 / 快速横移 |

### 用法

任何风格需求，先填这 7 个维度，再写成“整体基调”句式。

### 示例：预设外风格（赛博朋克雨夜追逐）

```text
1. 风格质感：赛博朋克写实 CG
2. 渲染管线：UE5 电影渲染、HDR 光追、真实物理、电影景深、动态运动模糊
3. 天光氛围：雨夜霓虹天光、体积雨雾、地面反光
4. 色彩主调：青蓝霓虹 + 品红高光 + 暗黑底
5. 节奏结构：高速追逐、急停、再加速
6. 镜头语言：贴地跟拍、低角度仰拍、快速横移
7. 音效基调：雨声底噪、霓虹电流滋滋、脚步踩水、远处警笛
```

生成的整体基调：

```text
整体基调：赛博朋克写实CG，UE5电影渲染，HDR光追，真实物理，雨夜霓虹天光，体积雨雾与地面反光，电影景深，动态运动模糊，青蓝霓虹与品红高光形成冷暖对比，节奏高速追逐、急停再加速，全程无字幕、无水印。
```

这段不在任何预设内，但完全可执行。这就是参数化维度的价值。

## 四、第三层之一：最近邻派生规则

当用户需求接近某个预设，但不完全匹配时：

### 派生步骤

1. 找**最接近**的预设作为骨架。
2. 保留骨架的：渲染管线 + 节奏结构 + 镜头语言。
3. 只改：风格质感 + 天光氛围 + 色彩主调 + 音效基调中**差异的维度**。
4. 输出中不需要标注“派生自预设 X”，但内部决策要明确。
5. 派生后必须再过一遍参数化维度表，确保 7 个维度都填齐、不冲突。

### 示例

用户说“国风庭院里的赛博机甲坠落”。

派生决策：

```text
骨架：预设 A（暗黑史诗灾难，坠落 + 硬着陆节奏）
保留：蓄-冲-爆-收节奏、贴地跟拍、硬着陆峰值音效
改：风格质感 → 国风 + 赛博混搭
改：天光氛围 → 国风庭院阴云天光 + 机甲冷光
改：色彩主调 → 青灰庭院 + 冷蓝机甲光
改：音效基调 → 寒风底噪 + 金属共振
```

最终 7 维度填齐，生成连贯基调：

```text
整体基调：国风庭院与赛博机甲混搭写实CG，UE5电影渲染，HDR光追，真实物理，国风庭院阴云天光与机甲冷光交织，体积冷雾与机械烟尘，电影景深，动态运动模糊，青灰庭院与冷蓝机甲光形成冷暖对比，节奏由高速坠落到硬着陆再至烟尘沉落，全程无字幕、无水印。
```

### 派生检查

- [ ] 是否找对了最近预设？
- [ ] 是否保留了骨架的渲染管线、节奏结构、镜头语言？
- [ ] 是否只改了差异维度？
- [ ] 派生后 7 维度是否填齐、不冲突？
- [ ] 整体基调是否连贯、不堆关键词？

## 五、第三层之二：用户自定义注入规则

当用户直接给出完整风格描述，或需求完全不接近任何预设时：

### 注入步骤

1. **不强行套预设**。
2. 把用户描述整理成“整体基调”句式。
3. 用参数化维度表补齐用户没说的维度（渲染管线、景深、运动模糊默认补）。
4. 推断镜头语言与音效基调（按风格质感就近推断）。
5. 在“自定义风格记录区”中可沉淀，下次可直接命中。

### 示例

用户说：“我要一个梦境般柔焦的慢节奏视频，淡紫粉色，像老胶片。”

处理：

```text
1. 风格质感：梦境柔焦写实（自定义）
2. 渲染管线：UE5 电影渲染、HDR 光追、真实物理、强景深、柔和动态模糊
3. 天光氛围：柔焦梦境天光、体积光晕
4. 色彩主调：淡紫 + 粉色 + 老胶片暖黄
5. 节奏结构：慢节奏、层次递进
6. 镜头语言：极缓推近、缓慢环绕
7. 音效基调：柔和环境底噪、极轻回响
```

生成的整体基调：

```text
整体基调：梦境柔焦写实CG，UE5电影渲染，HDR光追，真实物理，柔焦梦境天光与体积光晕，强电影景深，柔和动态模糊，淡紫与粉色交织、老胶片暖黄点缀，节奏缓慢、层次递进，全程无字幕、无水印。
```

不套任何预设，直接参数化生成。

### 注入检查

- [ ] 是否没有强行套错预设？
- [ ] 是否用 7 维度参数化表填齐？
- [ ] 渲染管线、景深、运动模糊是否默认补齐？
- [ ] 镜头语言与音效基调是否按风格质感就近推断？
- [ ] 整体基调是否连贯、不堆关键词？

## 八、混合使用规则

1. 优先选择与用户关键词重合度最高的预设。
2. 若用户同时提到多个风格，以主体动作决定主预设，以场景决定辅助词。
3. 不得把多个预设的专有角色、台词、道具直接拼接。
4. 风格词可组合，但整体基调必须读起来是一段连贯描述，不是关键词堆砌。
5. 用户明确指定风格时，以用户指定为准，预设仅用于补全渲染词与节奏词。
6. 预设不匹配时，禁止强行套错预设；按最近邻派生或用户自定义注入处理。
