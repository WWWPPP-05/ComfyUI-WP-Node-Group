# Impact Frame 冲击帧规则

## 一、定义

冲击帧是：主体招式与目标发生**单次命中顶点的瞬间**，强行打断正常运动，插入极短静态定格画面的视觉卡点。

冲击帧不是连续动画，不是爆炸过程，不是撕裂过程，不是碎片飞散过程，也不是慢动作。它只表现“单次命中顶点”的静态定格瞬间。

---

## 一之二、适用范围边界

### 适用冲击帧的场景

- 单次招式命中顶点
- 单次封印命中顶点
- 单次碰撞/撞击顶点
- 单次处刑命中顶点
- 单次能量爆发命中核心顶点

### 不适用冲击帧的场景

- 连续硬着陆、连续坠地
- 连续多次命中、连击、连环爆点
- 环境叙事、情绪特写
- 纯氛围镜头
- 慢动作过程
- 爆炸/撕裂/碎片飞散过程
- 生活流、日常动作、视线交汇
- 多主体依次入场/依次坠落

### 边界判定规则

| 场景特征 | 是否插入冲击帧 | 替代方案 |
| --- | --- | --- |
| 单次命中顶点，命中后立即转入破坏反馈 | 是 | 0.15–0.2s 静态冲击帧 |
| 连续多次命中 | 否 | 硬切 + 每次动作峰值音效 |
| 连续硬着陆/连续坠地 | 否 | 硬切 + 每次硬着陆峰值音效 |
| 穿透式双硬着陆 | 否 | 硬切 + 每次硬着陆峰值音效，镜头写清穿透因果 |
| 环境叙事/情绪特写 | 否 | 情绪顶点峰值或“以层次递进为主” |
| 纯氛围镜头 | 否 | “以层次递进为主，无单点峰值” |
| 生活流双人/多人相遇 | 否 | 视线交汇峰值 |
| 多主体依次入场 | 否 | 每次入场单独音效峰值 |

**判定原则：**

- 冲击帧服务于“唯一一次命中顶点”的视觉卡点。
- 连续动作的每一次动作顶点靠“硬切 + 动作峰值音效”承担节奏，不靠冲击帧。
- 无命中关系的场景（生活流、氛围、情绪）不插入冲击帧。
- 有冲击帧需求时，整段视频通常只出现一次冲击帧；多次命中用多段破坏反馈，不堆叠冲击帧。

## 一之三、并列硬着陆 vs 穿透式硬着陆

### 定义对照

| 类型 | 定义 | 典型示例 |
| --- | --- | --- |
| 并列硬着陆 | 多个主体各自独立坠地，每次坠地是并列的独立事件 | 四组机甲依次坠地，每次砸在同一地面 |
| 穿透式硬着陆 | 单主体砸穿一层结构后继续下坠，再砸到下一层地面，两次坠地是因果链 | 单主体砸穿屋顶 → 继续下坠 → 砸向室内地面 |

### 处理方式对照

| 处理项 | 并列硬着陆 | 穿透式硬着陆 |
| --- | --- | --- |
| 是否插入静态冲击帧 | 否 | 否 |
| 每次硬着陆是否独立标注【硬着陆】 | 是 | 是 |
| 每次硬着陆是否独立配置【硬着陆峰值】 | 是 | 是 |
| 峰值之间过渡 | 用环境底噪、破空声过渡 | 保留继续下坠的破空声，形成因果链 |
| 镜头段是否写清穿透因果 | 不适用 | 必须写清“穿透后继续下坠”的因果链 |
| 主体持续状态是否每段重复强化 | 视主体状态 | 视主体状态；若主体昏迷/无意识，每段重复强化 |

### 并列硬着陆写法

```text
- X–Y s：{主体A}高速下坠，镜头{机位}，{环境}被气流卷起。
- Y–Z s【硬着陆】：{主体A}重砸地面，地面碎裂，烟尘/火花/冲击波爆开，硬切转场。
- Z–W s：{主体B}高速下坠，镜头{机位}。
- W–V s【硬着陆】：{主体B}重砸地面，地面二次碎裂，烟尘/火花爆开，硬切转场。
```

对应音效：

```text
- Y–Z s【硬着陆峰值】：低频重击、地面碎裂、烟尘爆开，极短，一击即收。
- W–V s【硬着陆峰值】：低频重击、地面二次碎裂、火花溅射音，极短，一击即收。
```

### 穿透式硬着陆写法

```text
镜头N｜X–Y s｜砸穿{第一层结构}瞬间
硬切转场至{第一层结构}上方，高机位俯拍，主体以{姿态}高速砸向{第一层结构}。
- X–a s：主体高速逼近{第一层结构}，{构件}在画面中迅速放大，气流卷起碎屑。
- a–Y s【硬着陆】：主体重砸{第一层结构}，{构件}瞬间碎裂，碎屑与烟尘向四周爆开，主体穿过破洞继续下坠。

镜头N+1｜Y–Z s｜室内坠地与烟尘收尾
硬切转场至{下一层空间}，低角度贴地仰拍，主体穿过破碎{第一层结构}坠入{下一层空间}，砸向{地面}。
- Y–b s【硬着陆】：主体重砸{地面}，{地面}碎裂，烟尘与碎屑向四周扩散，身体随冲击轻微弹起后落定。
- b–Z s：镜头缓慢拉远，烟尘弥漫，主体{状态}，画面压暗收尾。
```

对应音效：

```text
- a–Y s【硬着陆峰值】：低频重击、{第一层结构}碎裂爆响、碎屑飞溅声，极短，一击即收。
- Y–b s【硬着陆峰值】：低频重击、{地面}碎裂、烟尘爆开、碎屑落地声，极短，一击即收。
```

两次峰值之间保留继续下坠的破空声，形成因果链。

## 二、必须满足

- 时长：通常为 `0.15–0.2s`，或按用户指定时长执行。
- 帧内无运动、无变形、无慢动作。
- 只做静态定格。
- 命中关系必须清楚：谁命中谁、命中哪个部位。
- 主体与目标必须组合为清晰粗黑轮廓剪影。
- 剪影置于画面中心或视觉中心。
- 必须使用粗黑描边。
- 剪影优先于特效。
- 特效不得遮挡主体轮廓、目标轮廓、关键发光部位。
- 使用高张力荷兰角倾斜构图。
- 强明暗反差、边缘色散、色影分离按需使用。
- 冲击帧结束后立刻切回写实 CG，再开始破坏反馈。

---

## 三、禁止事项

- 禁止把冲击帧写成连续动画。
- 禁止写撕裂过程、爆炸过程、碎片飞散过程。
- 禁止写慢动作。
- 禁止帧内运动、变形、镜头运动。
- 禁止特效盖住主体剪影或目标剪影。
- 禁止在冲击帧内表现目标被炸飞后的结果。
- 禁止在冲击帧内表现能量持续喷涌过程。
- 禁止把冲击帧写成“命中后”的破坏反馈。
- 禁止在冲击帧中丢失主体与目标的轮廓识别。
- 禁止用大量特效淹没剪影。
- 禁止把连续硬着陆、连续坠落、连续命中写成多次冲击帧。
- 禁止把穿透式双硬着陆写成冲击帧。
- 禁止在生活流、氛围、情绪类镜头中强行插入冲击帧。

## 五、标准写法

```text
【冲击帧｜X–Y s｜0.15–0.2s 静态定格，帧内无动画】
主体招式正面命中目标关键部位的顶点瞬间，正常运动被强行打断，立即插入冲击帧参考图式静态冲击帧。本帧不表现爆炸、不表现撕裂、不表现碎片飞散，只做静态定格。画面严格复用冲击帧参考图视觉骨架：中心爆闪光核对准命中点，外圈放射爆点与环形冲击波扩散；主体与目标双剪影同框：主体剪影位于画面{方位A}，目标剪影位于画面{方位B}，招式命中点位于两剪影之间，主体轮廓、目标轮廓与命中部位一眼可辨，组合为清晰粗黑轮廓剪影压在画面中心，粗黑描边，剪影优先于特效。高张力荷兰角倾斜构图，仅闪 0.15–0.2 秒，结束瞬间立刻切回写实 CG。
```
（剪影句式【2026-11-23 新增】双剪影同框强制版，禁止回退为单目标剪影）

## 七、冲击帧前后衔接规则

### 1. 冲击帧前

冲击帧前必须表现：

- 主体招式正在逼近目标。
- 来袭招式的能量光从外部**照亮**目标关键部位——是被动被照亮，不是目标自己发光（见下方"命中前状态锁定"）【2026-11-23 修订】
- 速度感、压迫感、临界紧张感达到顶点。
- 命中前一刻，正常运动即将被强行打断。
- 无主体能量视角/纯能量突进段，必须写明能量归属（如"少女发射的金色能量（少女本人不在画面中）"）【2026-11-23 新增】

冲击帧前不得提前表现：

- 目标被击飞。
- 目标核心爆裂。
- 碎片飞散。
- 能量贯穿后的破坏结果。
- 目标身体部位自发光、自带能量核心、被能量环绕或向外发射能量光束（即"提前受击特效"）【2026-11-23 新增】

### 1.5 命中前状态锁定

> 【2026-11-24 三层架构改造】实测案情（00021 神兽提前自发光/发射方反转）已迁出至 `lessons.md`，此处只留规则。三条规则本身即该事故的修复结论。

1. **命中前 1–2s 内，目标的受击部位必须保持常态外观**：无发光、无裂纹、无能量环绕、无向外喷射。受击部位在命中前的唯一允许变化是"被来袭能量照亮/反光"。
2. **禁止为目标发明"核心"类器官**：若参考图绑定的目标没有"胸口核心""能量核心"等器官，提示词不得出现"{部位}核心"字样，命中点一律写"命中{目标}的{部位}"（如"命中神兽胸口"而非"命中神兽胸口核心"）。"核心"只用于目标真实拥有核心设定时（机甲核心、宝石核心等）。
3. **能量归属必须显式声明**：凡"本段无主体入画"的能量视角段，提示词必须写明能量来源（"少女发射的能量（少女不在画面中）"），并在负面约束加"目标不发射能量光束，目标身体不出现自发光或受击特效"。缺归属时模型会让画面内唯一显眼实体（通常就是目标）充当发射方，受击逻辑整体反转。

### 2. 冲击帧中

冲击帧中只表现：

- 单次命中顶点。
- 静态定格。
- 主体与目标的粗黑轮廓剪影。
- 中心爆闪光核。
- 放射爆点、环形冲击波、墨渍飞溅、边缘色散等静态视觉元素。
- 荷兰角倾斜与高张力构图。

冲击帧中不得表现：

- 帧内运动。
- 帧内变形。
- 慢动作。
- 爆炸过程。
- 撕裂过程。
- 碎片飞散过程。
- 目标被炸飞后的结果。

### 3. 冲击帧后

冲击帧结束后必须：

- 立刻切回写实 CG。
- 承接命中顶点继续展开破坏反馈。
- 再表现目标关键部位爆裂、目标被击飞、能量贯穿、碎片飞散、冲击波扩散等结果。

标准衔接句式：

```text
冲击帧结束后立刻回归写实CG，承接命中顶点继续展开破坏反馈。
```

## 八、剪影规则

冲击帧中，主体与目标必须形成清晰粗黑轮廓剪影。

必须做到：

- 主体轮廓清楚可辨。
- 目标轮廓清楚可辨。
- 关键命中部位轮廓清楚可辨。
- 剪影压在画面中心或视觉中心。
- 粗黑描边。
- 剪影优先于特效。
- 特效不能遮挡主体剪影。
- 特效不能遮挡目标剪影。
- 特效不能遮挡关键发光部位。

### 双人剪影同框强制规则

> 【2026-11-24 三层架构改造】实测案情（19.2s 命中帧出招方缺席）已迁出至 `lessons.md`。剪影描述强制三要素：

1. **双剪影必须同框**：出招主体剪影与受击目标剪影同时出现在同一帧内，缺一即违规。
2. **写明相对位置**：必须写清两个剪影的画面方位关系（如"主体剪影位于画面左下，目标剪影位于画面右侧，命中点位于两者之间"）。
3. **招式接触可辨**：两剪影之间必须有招式接触关系（爪/掌/武器/能量球抵达命中点），不能是两个无关剪影并排。

标准写法（双剪影同框强制版，【2026-11-23 新增】）：

```text
{主体}与{目标}双剪影同框：{主体}剪影位于画面{方位A}，{目标}剪影位于画面{方位B}，{招式/命中点}位于两剪影之间，{主体}轮廓、{目标}轮廓与{命中部位}一眼可辨，组合为清晰粗黑轮廓剪影压在画面中心，粗黑描边，剪影优先于特效。
```

反面示例（旧写法，已废弃）：

```text
主体与目标组合为清晰粗黑轮廓剪影，压在画面中心。
```

判定：该写法未指明双剪影必须同框，实测导致出招主体缺席，禁止再单独使用。

## 九、构图规则

冲击帧默认使用：

- 高张力构图。
- 荷兰角倾斜构图。
- 强明暗反差。
- 极简背景或深色背景。
- 中心爆点或视觉中心爆点。
- 放射状视觉引导。
- 环形冲击波向外扩散。
- 剪影居中或处于视觉核心位置。

不得使用：

- 平铺直叙的正面平视构图。
- 主体与目标轮廓混杂不清的构图。
- 特效遮挡剪影的构图。
- 背景信息过载导致剪影不清晰的构图。

## 十、画风反差规则

冲击帧画风应与前后写实 CG 形成强烈反差。

建议表现为：

- 冲击帧为高反差静态图形化定格。
- 前后镜头为写实 CG 渲染。
- 冲击帧结束后立刻切回写实渲染。
- 冲击帧只作为极短视觉卡点存在。

标准写法：

```text
冲击帧画风与前后写实CG强烈反差，结束后立刻切回写实渲染，再开始破坏反馈。
```

## 十一、音效卡点规则

冲击帧必须与音效峰值同步。

建议音效结构：

```text
短促爆音 → 黑切静音 → 低频重击 → 环形冲击爆响 → 破坏反馈音
```

标准写法：

```text
【音效峰值】：冲击帧同步，先短促爆音，再黑切静音，随后叠加低频重击与环形冲击爆响，极短，一击即收。
```

## 十二、常见错误

### 错误 1：把冲击帧写成连续动画

错误示例：

```text
能量持续喷涌，目标被逐渐撕裂，碎片慢慢飞散。
```

正确方向：

```text
命中顶点瞬间静态定格，不表现撕裂、喷涌和碎片飞散。
```

### 错误 2：把冲击帧写成慢动作

错误示例：

```text
时间变慢，能量缓慢接触目标核心。
```

正确方向：

```text
正常运动被强行打断，插入极短静态定格。
```

### 错误 3：特效遮挡剪影

错误示例：

```text
大量墨渍和爆点覆盖主体与目标。
```

正确方向：

```text
主体与目标为清晰粗黑轮廓剪影，剪影优先于特效，特效不得遮挡剪影。
```

### 错误 4：冲击帧内表现爆炸结果

错误示例：

```text
目标核心爆裂，身体被炸飞，碎片四散。
```

正确方向：

```text
冲击帧只定格命中顶点，爆裂与击飞放在冲击帧结束后的写实 CG 中表现。
```

### 错误 5：冲击帧时间过长

错误示例：

```text
冲击帧持续 1 秒。
```

正确方向：

```text
冲击帧通常仅 0.15–0.2 秒，一闪即收。
```

### 错误 6：冲击帧没有命中关系

错误示例：

```text
画面中心出现爆点和剪影，但看不出谁命中谁。
```

正确方向：

```text
主体招式必须清楚命中目标关键部位，命中关系一眼可辨。
```

### 错误 7：把连续硬着陆做成多次冲击帧

错误示例：

```text
1.2–1.4s【冲击帧】机甲重砸地面。
2.2–2.4s【冲击帧】第二组机甲重砸地面。
3.7–3.9s【冲击帧】第三组机甲重砸地面。
```

正确方向：

```text
1.2–1.5s【硬着陆】：机甲重砸地面，地面碎裂，烟尘爆开，硬切转场。
1.2–1.5s【硬着陆峰值】：低频重击、地面碎裂、烟尘爆开，极短，一击即收。
2.2–2.8s【硬着陆】：第二组机甲重砸地面，地面二次碎裂，火花四溅。
2.2–2.8s【硬着陆峰值】：低频重击、地面二次碎裂、火花溅射音，极短，一击即收。
```

判定说明：

- 硬着陆是动态过程，不做静态冲击帧。
- 连续动作靠“硬切 + 每次动作峰值音效”承担节奏。

### 错误 8：在生活流/氛围/情绪类镜头中强行插入冲击帧

错误示例：

```text
【冲击帧｜4.0–4.2s｜0.2s 静态定格】两人视线交汇。
```

正确方向：

```text
4.0–4.6s【音效峰值】：脚步停稳的轻响与两人视线交汇同步，毛巾落下轻响，室内环境声短暂收紧，极短，一击即收。
```

判定说明：

- 视线交汇、情绪顶点、氛围镜头不属于命中顶点，不插入冲击帧。
- 该类场景用情绪顶点峰值音效承担节奏。

### 错误 9：同一段视频堆叠多次冲击帧

错误示例：

```text
【冲击帧1】命中甲壳。
【冲击帧2】贯穿躯干。
【冲击帧3】核心爆裂。
```

正确方向：

```text
只保留唯一一次命中顶点冲击帧；后续贯穿、爆裂、击飞全部放在冲击帧结束后的写实CG破坏反馈中表现。
```

判定说明：

- 一段视频默认只出现一次冲击帧。
- 多次命中或多次爆点用多段破坏反馈表现，不堆叠冲击帧。

### 错误 10：把穿透式双硬着陆做成冲击帧

错误示例：

```text
【冲击帧｜2.4–2.6s】主体砸穿屋顶。
【冲击帧｜3.2–3.4s】主体砸向地面。
```

正确方向：

```text
2.4–3.2s【硬着陆】：主体背部重砸屋顶，青瓦与木梁瞬间碎裂，碎瓦与烟尘向四周爆开，主体穿过破洞继续下坠。
2.4–3.2s【硬着陆峰值】：低频重击、青瓦与木梁碎裂爆响、碎瓦飞溅声，极短，一击即收。
3.2–4.0s【硬着陆】：主体背部重砸石板地面，石板碎裂，烟尘与碎瓦向四周扩散，身体随冲击轻微弹起后落定。
3.2–4.0s【硬着陆峰值】：低频重击、石板碎裂、烟尘爆开、碎瓦落地声，极短，一击即收。
```

判定说明：

- 穿透式双硬着陆是因果链连续动作，不做静态冲击帧。
- 两次硬着陆独立标注、独立峰值，峰值之间保留继续下坠的破空声。
- 与“并列硬着陆”的区别：并列硬着陆是多主体各自坠地，穿透式硬着陆是单主体砸穿一层再落到下一层。

## 十四、最小可用冲击帧句式

```text
【冲击帧｜X–Y s｜0.15–0.2s 静态定格，帧内无动画】
主体招式正面命中目标关键部位的顶点瞬间，正常运动被强行打断，立即插入冲击帧参考图式静态冲击帧。本帧不表现爆炸、不表现撕裂、不表现碎片飞散，只做静态定格。中心爆闪光核对准命中点，外圈放射爆点与环形冲击波扩散；主体与目标双剪影同框：主体剪影位于画面{方位A}，目标剪影位于画面{方位B}，招式命中点位于两剪影之间，主体轮廓、目标轮廓与关键部位轮廓一眼可辨，粗黑描边，剪影优先于特效。高张力荷兰角倾斜构图，仅闪0.15–0.2秒，结束瞬间立刻切回写实CG。
```
（剪影句式【2026-11-23 新增】双剪影同框强制版）
