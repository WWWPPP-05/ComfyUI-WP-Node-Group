# 内容污染防护规则

## 一、核心原则

本技能只蒸馏参考案例的**结构、格式、规则、参数范围与写法范式**，不蒸馏参考案例中的**专有内容**。

输出时必须做到：

- 结构可以复用
- 格式可以复用
- 冲击帧规则可以复用
- 音效分层方式可以复用
- 时间轴写法可以复用
- 参考图绑定写法可以复用
- 通用风格词与渲染词可以复用
- 不得复用案例中的专有角色、台词、牌匾文字、道具符号、具体剧情与专属世界观设定

---

## 二、允许复用

以下内容属于通用结构或通用影视语言，可以复用：

### 1. 结构类

- 整体基调
- 参考图绑定
- 叙事顺序
- 分镜时间轴
- 镜头标题格式
- 子时间段格式
- 冲击帧独立成段
- 音效分层设计
- 负面约束
- 质量检查清单

### 2. 规则类

- 冲击帧 0.15–0.2s 静态定格
- 冲击帧帧内无动画、无变形、无慢动作
- 冲击帧只表现命中顶点
- 冲击帧剪影优先
- 冲击帧结束后立刻切回写实 CG
- 音效峰值与冲击帧对齐
- 音效无 BGM、电影分层混音
- 参考图锁定角色外观不漂移
- 场景固定构件不漂浮、不遮挡角色与特效

### 3. 通用影视语言类

- 低角度仰拍
- 高机位俯拍
- 侧前方近景
- 贴地跟拍
- 硬切转场
- 手持微晃
- 缓慢推镜
- 快速拉远
- 荷兰角倾斜
- 强明暗反差
- 边缘色散
- 色影分离
- 体积光
- 电影景深
- 动态运动模糊

### 4. 通用风格词类

- 写实 CG
- 热血动漫爆发感
- 东方史诗神话灾难大片质感
- 国风写实
- 玄幻封印大片质感
- UE5 电影渲染
- HDR 光追
- 真实物理
- 厚重风暴天光
- 体积云雾烟尘
- 黑红金主色
- 白金圣光
- 暗红岩浆
- 全程无字幕、无水印

### 5. 通用音效词类

- 环境底噪
- 低频轰鸣
- 电流滋滋
- 蒸汽啸响
- 破空呼啸
- 冲击波轰鸣
- 碎片飞溅
- 建筑坍塌
- 余震衰减
- 静默黑屏

## 三、禁止复用

以下内容属于参考案例专有内容，禁止直接复用或改写后复用：

### 1. 专有角色与称号

禁止出现：

- 案例中的具体角色名
- 案例中的具体称号
- 案例中的组织名
- 案例中的种族专属设定名
- 案例中的特定身份称谓

处理方式：

- 用“主体角色”“目标单位”“施法者”“被封印目标”等通用词替代
- 用户提供角色名时，使用用户提供的名称

### 2. 台词与喊话

禁止出现：

- 案例中的求饶台词
- 案例中的喊话
- 案例中的加价/交易语句
- 案例中的口型匹配台词

处理方式：

- 用户未提供台词时，不写具体台词
- 用户提供台词时，只使用用户提供的台词
- 需要表现求饶/挣扎时，写“目标发出压抑低沉的求饶气音”，不写具体句子

### 3. 牌匾、标语与特定文字

禁止出现：

- 案例中的牌匾文字
- 案例中的标语
- 案例中的特定书法字
- 案例中的特定符号文字

处理方式：

- 用“场景固定牌匾”“建筑标识”“环境文字构件”替代
- 用户提供具体文字时，使用用户提供的文字

### 4. 独特道具与特定外观符号

禁止出现：

- 案例中的特定法器名
- 案例中的特定家电名
- 案例中的特定头饰符号
- 案例中的特定图案
- 案例中的特定服装专属符号

处理方式：

- 用“法器”“能量核心”“关键识别点”“头饰”“服装纹样”替代
- 用户提供具体道具时，使用用户提供的道具

### 5. 具体剧情关系

禁止出现：

- 案例中的专属世界观关系
- 案例中的特定前因后果
- 案例中的特定惩罚/封印理由
- 案例中的特定交易关系

处理方式：

- 只写“主体对目标释放招式/封印/处刑”
- 不解释世界观前因
- 不添加案例中的剧情关系

### 6. 大段拼接案例原文

禁止：

- 把案例中的整段镜头描述直接复制
- 把多个案例的段落拼接成新提示词
- 只替换角色名但保留案例原句结构中的专有内容

处理方式：

- 只复用结构
- 每个镜头描述重新组织语言
- 专有内容全部替换为通用描述或用户提供内容

## 四、缺省写法对照表

| 缺失项 | 缺省写法 |
| --- | --- |
| 未给角色名 | `主体角色` |
| 未给目标名 | `目标单位` |
| 未给场景名 | `指定场景` |
| 未给招式名 | `核心招式/能量爆发` |
| 未给冲击帧参考图 | `冲击帧参考图` |
| 未给头饰/识别点 | `关键识别点` |
| 未给法器/道具 | `法器/能量核心` |
| 未给牌匾文字 | `场景固定牌匾` |
| 未给台词 | 不写具体台词，只写气音/口型/情绪 |
| 未给风格 | 根据动作与场景选择最接近的风格预设 |
| 未给时长 | 默认 7.0s |
| 未给音频要求 | 默认无 BGM、电影分层混音 |

## 五、输出前污染扫描

输出前必须逐项扫描：

- [ ] 是否出现参考案例专有角色名？
- [ ] 是否出现参考案例专有称号或组织名？
- [ ] 是否出现参考案例台词或喊话？
- [ ] 是否出现参考案例牌匾文字或标语？
- [ ] 是否出现参考案例独特道具名？
- [ ] 是否出现参考案例特定符号或图案？
- [ ] 是否出现参考案例具体剧情关系？
- [ ] 是否把多个案例原文段落拼在一起？
- [ ] 是否只替换角色名但保留案例原句中的专有内容？
- [ ] 用户未提供的内容是否用通用占位符替代？
- [ ] 是否臆造了用户未提供的 IP 设定？

## 六、安全改写示例

### 错误示例

```text
主体角色A使用某牌电饭煲释放黑红恶魔旋风，命中虫王躯干，牌匾写着【某特定文字】，目标大喊“某句台词”。
```

问题：

- 出现案例特定道具名
- 出现案例特定牌匾文字
- 出现案例特定台词
- 出现案例特定目标称谓

### 正确示例

```text
主体角色A使用法器释放黑红能量旋风，正面命中目标单位B的躯干核心；场景固定牌匾作为环境构件存在，不遮挡角色与特效；目标受击后发出压抑低沉的痛苦气音，不写具体台词。
```

---

## 七、用户提供专有内容时的处理

如果用户主动提供角色名、台词、牌匾文字、道具名，可以按用户提供内容写入，但必须：

1. 只使用用户明确提供的内容。
2. 不额外补充案例中的专有设定。
3. 不把用户提供内容与案例专有内容混合。
4. 台词必须标明“口型严格匹配台词”仅在用户明确要求时添加。
5. 牌匾文字必须说明为场景固定构件，不漂浮、不遮挡角色与特效。

---

## 八、最终原则

一句话总结：

> 复用结构，不复用内容；复用规则，不复用角色；复用写法，不复用台词；用户给什么用什么，用户没给就用通用占位符。
