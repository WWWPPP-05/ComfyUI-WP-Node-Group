# 音效分层规则

## 一、默认原则

- 无 BGM
- 电影分层混音
- 有冲击帧时，峰值卡点对准冲击帧
- 无冲击帧时，峰值改为对准情绪顶点、视线交汇、动作顶点或喜剧张力顶点；纯氛围类写“以层次递进为主，无单点峰值”
- 连续硬着陆、连续坠地、连续命中类动作，每次动作单独标注一个动作峰值
- 穿透式双硬着陆，每次硬着陆单独标注一个硬着陆峰值
- 每个时间段与画面动作对应
- 冲击帧可设计“短促爆音 → 黑切静音 → 低频重击 → 锁合/碎裂音”
- 收尾音量持续衰减，最终静默黑屏或低频余震
- 音效时间段必须与分镜时间段对应，不得出现画面外无归属音效
- 音效描述必须具体到声源类型，不写“好听的音效”“震撼音效”等空泛词
- 多主体互动音效必须写清声源归属

---

## 二、分层结构

### 1. 环境底噪层

作用：建立场景空间感与持续氛围。

常见声源：

- 荒漠风沙低频轰鸣
- 城市风声、远处警报、火焰燃烧
- 古风庭院寒风呼啸
- 木架吱呀、尘土沙沙
- 远处虫群、人群、机械低频
- 室内自然声场、远处窗外微弱环境声
- 森林风声、树叶轻响、远处鸟鸣、水面细微波动声
- 商场室内安静底噪、远处顾客低声交谈、店铺背景音乐微弱透出
- 空旷空间低频底噪、贴地雾气流动的细微沙沙声

写法示例：

```text
0.0–0.5s：场景风声、碎石坠落声、高频电流滋鸣，节奏快速起势。
```

### 2. 蓄能层

作用：表现能量聚集、张力爬升。

常见声源：

- 电流滋滋预警
- 蒸汽啸响
- 能量低频轰鸣
- 符纸沙沙声
- 锁链嗡鸣
- 金属共振
- 衣料气流声
- 晶体装甲轻微金属共振声
- 翼状结构轻微气流声
- 晶体核心轻微嗡鸣

写法示例：

```text
0.5–1.0s：雷电滋滋预警、能量低频持续增强，每一拍都更紧张。
```

### 3. 发动层

作用：与硬切、发动切镜点同步，表现能量释放瞬间。

常见声源：

- 能量爆发闷响
- 破空呼啸
- 能量喷涌声
- 硬切同步重音
- 金属共振短音

写法示例：

```text
1.4–1.8s【切镜同步音效点】：能量爆发闷响、破空声，与硬切同步。
```

### 4. 峰值层

作用：与冲击帧、硬着陆、情绪顶点、喜剧张力顶点或主命中点严格对齐，形成音画卡点。

标准结构（有冲击帧时）：

```text
短促爆音 → 黑切静音 → 低频重击 → 环形冲击爆响
```

常见声源：

- 中心白闪/暗红爆音
- 短促黑切静音
- 低频重击
- 环形冲击波轰鸣
- 金属锁合音
- 碎裂脆响
- 颗粒爆裂溅射音

写法示例：

```text
3.6–3.8s【音效峰值】：冲击帧同步，先短促爆音，再黑切静音，随后叠加低频重击与环形冲击爆响，极短，一击即收。
```

要求：

- 峰值时长必须与冲击帧时长一致或略短
- 必须写明“短促”“极短”“一击即收”等收束词
- 必须写明黑切静音或等效的瞬间抽空处理

### 5. 破坏反馈层

作用：表现命中后的破坏结果。

常见声源：

- 甲壳崩裂脆响
- 碎片破空声
- 颗粒飞溅撞击声
- 冲击波卷动沙尘翻滚轰鸣
- 建筑坍塌
- 岩浆喷溅
- 锁链收紧锁死嗡鸣
- 目标挣扎嘶吼

写法示例：

```text
4.5–5.5s：甲壳崩裂脆响、碎片破空声、颗粒飞溅撞击声、冲击波卷动沙尘翻滚轰鸣。
```

### 6. 收尾层

作用：余威、衰减、收束。

常见声源：

- 低频地震式余震
- 电流残响
- 颗粒与沙尘落地沙沙声
- 远处火焰、风声
- 锁链低沉震颤
- 室内自然底噪回归
- 静默黑屏

写法示例：

```text
5.5–7.0s：低频地震式余震、电流残响、颗粒和沙尘落地沙沙声，音量持续衰减，静默黑屏。
```

### 7. 多主体互动音效层

作用：表现多主体之间的互动动作（承托、骑乘、拉扯、轻触、视线交汇）。

常见声源：

- **A 对 B 的动作音效**：手指轻触、重心前压、衣料挤压、手臂被抱紧、扶肩
- **双方叠加音效**：A 衣料摩擦与 B 装甲共振叠加、A 脚步与 B 金属落地叠加
- **同步动作音效**：多人同时拉扯的衣料绷紧、多人同时坐稳的承压声、多人同时转头的气流声

写法要求：

- 必须写清声源归属：是 A 对 B 的动作，还是 A 与 B 同时动作。
- 必须写清作用部位：肩部、左臂、右臂、龙角、背部、脚踝。
- 必须写清动作性质：轻触、拉扯、承压、前压、开合、拥抱。

标准写法：

```text
{主体C}手指轻触{主体A}{部位}的细微摩擦声，{主体A}长发垂落轻响，环境底噪持续。
```

```text
{主体D}重心前压的衣料摩擦声，{主体B}{翼状结构}开合的金属轻响。
```

```text
三人同时拉扯的衣料绷紧声与身体微晃同步，室内环境声短暂收紧，极短，一击即收。
```

## 三、标准格式

### 3.1 有冲击帧时

```text
音效设计（无BGM，电影分层混音，峰值卡点对准X.X–X.Xs冲击帧）：
- 0.0–A s：环境底噪与蓄能层……
- A–B s：能量爬升、电流/蒸汽/符纸声……
- B–C s：发动同步音……
- C–D s【音效峰值】：冲击帧同步，短促爆音、黑切静音、低频重击……
- D–E s：破坏反馈音……
- E–F s：余震与衰减，静默收尾
```

### 3.2 无冲击帧但有点状峰值（情绪顶点/视线交汇/动作顶点/喜剧张力顶点）

```text
音效设计（无BGM，电影分层混音，峰值卡点对准X.X–X.Xs {情绪顶点/视线交汇/动作顶点/喜剧张力顶点}）：
- 0.0–A s：环境底噪与蓄能层……
- A–B s：动作过渡层……
- B–C s【音效峰值】：{情绪顶点/视线交汇/动作顶点/喜剧张力顶点}同步，{具体音效}，极短，一击即收。
- C–D s：环境底噪持续……
- D–E s：音量持续衰减，收尾
```

### 3.3 无冲击帧且为纯氛围类

```text
音效设计（无BGM，电影分层混音，以层次递进为主，无单点峰值）：
- 0.0–A s：环境底噪层……
- A–B s：动作过渡层……
- B–C s：声源层次递进……
- C–D s：音量缓慢衰减，静谧收尾
```

### 3.4 连续动作峰值（连续硬着陆/连续坠地/连续命中/穿透式双硬着陆）

```text
音效设计（无BGM，电影分层混音，峰值卡点对准每次{动作}瞬间）：
- 0.0–A s：环境底噪、{第一次动作}破空声，A–B s【{动作}峰值】：低频重击、{地面/目标}碎裂、{烟尘/火花}爆开，极短，一击即收。
- B–C s：{环境}持续、{第二次动作}破空声，C–D s【{动作}峰值】：低频重击、二次碎裂、{金属共振/火花溅射}音，极短，一击即收。
- ……
- 最后一段：{余响}、音量持续衰减，静默黑屏。
```

## 四、时间对齐规则

1. 音效时间段必须从 0.0s 开始。
2. 音效时间段必须连续、不重叠。
3. 音效结束时间必须等于视频总时长。
4. 有冲击帧时，音效峰值时间段必须与冲击帧时间段完全一致。
5. 无冲击帧时，音效峰值时间段必须与情绪顶点、视线交汇、动作顶点或喜剧张力顶点时间段完全一致。
6. 连续动作峰值时，每次峰值必须与对应动作顶点对齐，峰值之间用环境底噪、破空声过渡。
7. 穿透式双硬着陆时，两次硬着陆峰值分别独立，峰值之间保留继续下坠的破空声。
8. 硬切点必须有同步音效标注。
9. 冲击帧结束后，破坏反馈音必须紧随其后。
10. 收尾段必须有音量衰减描述。

## 五、冲击帧音效写法

### 标准句式

```text
【音效峰值】：冲击帧同步，先短促黑红闪爆音，再黑切静音，随后叠加低频冲击、颗粒爆裂溅射音与环形冲击爆响，多层音效叠加，极短，一击即收。
```

### 变体句式

封印类：

```text
【音效峰值】：重击闷响、短暂消音、束缚锁合音，极短，一击即收。
```

巨兽核心类：

```text
【音效峰值】：中心白闪爆音、低频重击、黑切静音、环形冲击爆响，短促卡点0.15秒。
```

处刑类：

```text
【音效峰值】：短促爆音、黑切静音、低频重击、颗粒爆裂溅射音，极短，一击即收。
```

### 禁止写法

- 禁止只写“有音效”
- 禁止峰值拖长超过冲击帧时长
- 禁止峰值与冲击帧错位
- 禁止在峰值段加入与命中无关的环境音

---

## 五之二、非冲击帧峰值写法

无冲击帧场景不得留空峰值，必须按以下四类之一处理。

### 1. 情绪顶点类（生活流/情绪特写）

适用场景：

- 双人视线交汇
- 情绪爆发瞬间
- 情绪张力顶点
- 关键表情定格前

标准句式：

```text
X.X–X.Xs【音效峰值】：{具体音效}与{情绪顶点事件}同步，{环境声收紧/短暂静止}，极短，一击即收。
```

示例：

```text
4.0–4.6s【音效峰值】：脚步停稳的轻响与两人视线交汇同步，毛巾落下轻响，室内环境声短暂收紧，极短，一击即收。
```

要求：

- 峰值必须对准画面情绪顶点
- 峰值音效必须具体到声源
- 必须写明“极短/一击即收”
- 不得用冲击帧的爆音结构

### 2. 硬着陆/连续动作类

适用场景：

- 机甲连续坠地
- 连续多次命中
- 多次重物落地
- 连续多个动作顶点
- 穿透式双硬着陆

标准句式：

```text
X.X–X.Xs【{动作}峰值】：低频重击、{地面/目标}碎裂、{烟尘/火花}爆开，极短，一击即收。
```

示例：

```text
1.2–1.5s【硬着陆峰值】：低频重击、地面碎裂、烟尘爆开，极短，一击即收。
2.2–2.8s【硬着陆峰值】：低频重击、地面二次碎裂、火花溅射音，极短，一击即收。
```

穿透式双硬着陆示例：

```text
2.4–3.2s【硬着陆峰值】：低频重击、青瓦与木梁碎裂爆响、碎瓦飞溅声，极短，一击即收。
3.2–4.0s【硬着陆峰值】：低频重击、石板碎裂、烟尘爆开、碎瓦落地声，极短，一击即收。
```

要求：

- 每次动作单独一个峰值时间段
- 峰值之间用环境底噪、破空声过渡
- 穿透式双硬着陆两次峰值之间保留继续下坠的破空声
- 不做成静态冲击帧的音效
- 每次峰值必须有“极短/一击即收”

### 3. 喜剧张力递进类

适用场景：

- 三人争抢、双向拉扯
- 对峙后突然行动
- 喜剧性身体互动顶点
- 生活流喜剧张力顶点

标准句式：

```text
X.X–X.Xs【音效峰值】：{多人同时动作的声源}与{身体反应}同步，{环境声}短暂收紧，极短，一击即收。
```

示例：

```text
4.0–4.6s【音效峰值】：三人同时拉扯的衣料绷紧声与身体微晃同步，室内环境声短暂收紧，极短，一击即收。
```

要求：

- 峰值必须对准多人同时动作的顶点
- 必须写清多人同步声源（衣料绷紧、身体微晃、脚步停稳等）
- 必须写明“环境声短暂收紧”或等效收束词

### 4. 纯氛围类

适用场景：

- 森林水岸氛围
- 情绪沉浸
- 无明确动作顶点或情绪顶点
- 环境叙事类（无牌匾特写、无情绪爆发）

写法：

```text
音效设计（无BGM，电影分层混音，以层次递进为主，无单点峰值）：
```

要求：

- 不写“峰值卡点对准”
- 以层次递进、声源叠加描述
- 收尾必须有衰减

---

## 六、硬切同步音效写法

标准句式：

```text
X.X–X.Xs【切镜同步音效点】：{爆发音}，与硬切同步。
```

示例：

```text
1.4–1.8s【切镜同步音效点】：能量爆发闷响、破空声，与硬切同步。
```

要求：

- 硬切点必须有对应音效
- 音效必须体现“切断感”
- 硬切后音效可短暂抽空，再进入下一层

---

## 七、收尾音效写法

标准句式：

```text
X.X–X.Xs：{余震/残响/落地声}，音量持续衰减，静默黑屏。
```

示例：

```text
5.5–7.0s：低频地震式余震、电流残响、颗粒和沙尘落地沙沙声，音量持续衰减，静默黑屏。
```

要求：

- 必须写明衰减
- 必须写明最终状态：静默黑屏或低频余震收束
- 不得在收尾段突然加入高能量音效

## 九、常见错误

### 错误 1：没有时间轴

错误：

```text
音效：风声、雷电、爆炸。
```

正确：

```text
音效设计（无BGM，电影分层混音，峰值卡点对准3.6–3.8s冲击帧）：
- 0.0–0.5s：城市风声、碎石坠落声、高频电流滋鸣。
```

### 错误 2：峰值与冲击帧错位

错误：

```text
冲击帧在3.6–3.8s，音效峰值写在2.0–3.0s。
```

正确：

```text
3.6–3.8s【音效峰值】：冲击帧同步……
```

### 错误 3：峰值没有收束

错误：

```text
3.6–3.8s：爆炸声持续。
```

正确：

```text
3.6–3.8s【音效峰值】：短促爆音、黑切静音、低频重击，极短，一击即收。
```

### 错误 4：收尾没有衰减

错误：

```text
5.5–7.0s：爆炸声。
```

正确：

```text
5.5–7.0s：低频余震、残响、落地沙沙声，音量持续衰减，静默黑屏。
```

### 错误 5：混入BGM

错误：

```text
背景音乐渐强。
```

正确：

```text
无BGM，电影分层混音。
```

### 错误 6：无冲击帧时留空峰值

错误：

```text
音效设计（无BGM，电影分层混音，峰值卡点对准……）：（没写）
```

正确（情绪顶点）：

```text
音效设计（无BGM，电影分层混音，峰值卡点对准4.0–4.6s 双人视线交汇）：
- 4.0–4.6s【音效峰值】：脚步停稳的轻响与两人视线交汇同步，毛巾落下轻响，室内环境声短暂收紧，极短，一击即收。
```

正确（纯氛围）：

```text
音效设计（无BGM，电影分层混音，以层次递进为主，无单点峰值）：
```

### 错误 7：把硬着陆做成静态冲击帧音效

错误：

```text
1.2–1.4s【音效峰值】：冲击帧同步，短促爆音、黑切静音、低频重击。
```

正确：

```text
1.2–1.5s【硬着陆峰值】：低频重击、地面碎裂、烟尘爆开，极短，一击即收。
```

### 错误 8：连续动作峰值只写一个

错误：

```text
音效设计（无BGM，电影分层混音，峰值卡点对准硬着陆瞬间）：
- 1.2–1.5s【硬着陆峰值】：……
- ……（后面三次硬着陆没有峰值标注）
```

正确：

```text
音效设计（无BGM，电影分层混音，峰值卡点对准每次硬着陆瞬间）：
- 1.2–1.5s【硬着陆峰值】：……
- 2.2–2.8s【硬着陆峰值】：……
- 3.7–4.3s【硬着陆峰值】：……
- 5.5–6.2s【硬着陆峰值】：……
```

### 错误 9：多主体互动音效没有归属

错误：

```text
3.0–5.0s：手指摩擦声、衣料声、金属声。
```

正确：

```text
3.0–5.0s：{主体C}手指轻触{主体A}{部位}的细微摩擦声，{主体A}长发垂落轻响，环境底噪持续。
```

判定说明：

- 多主体互动音效必须写清“谁的什么动作作用于谁”。
- 不得只写声源类型，丢失归属。

### 错误 10：喜剧张力峰值误写成冲击帧音效

错误：

```text
4.0–4.6s【音效峰值】：短促爆音、黑切静音、低频重击。
```

正确：

```text
4.0–4.6s【音效峰值】：三人同时拉扯的衣料绷紧声与身体微晃同步，室内环境声短暂收紧，极短，一击即收。
```

判定说明：

- 喜剧张力递进类峰值不是冲击帧音效，不使用爆音 + 黑切静音结构。
- 使用“环境声短暂收紧 + 具体动作声源”结构。

## 十、输出前检查清单

- [ ] 是否写明“无BGM，电影分层混音”？
- [ ] 是否写明峰值卡点对准哪个时间段？
- [ ] 音效时间段是否从 0.0s 开始？
- [ ] 音效时间段是否连续、不重叠？
- [ ] 音效结束时间是否等于视频总时长？
- [ ] 有冲击帧时，音效峰值是否与冲击帧时间段完全一致？
- [ ] 有冲击帧时，峰值是否包含短促爆音、黑切静音、低频重击？
- [ ] 无冲击帧时，是否写明峰值对准情绪顶点/视线交汇/动作顶点/喜剧张力顶点，或写“以层次递进为主，无单点峰值”？
- [ ] 连续动作峰值时，是否每次动作单独标注峰值时间段？
- [ ] 穿透式双硬着陆是否两次硬着陆峰值独立、峰值之间保留破空声？
- [ ] 峰值是否写明“极短/一击即收”？
- [ ] 硬切点是否有同步音效？
- [ ] 破坏反馈层是否与画面破坏动作对应？
- [ ] 多主体互动音效是否写清声源归属（A 对 B / 双方叠加 / 同步动作）？
- [ ] 多主体互动音效是否写清作用部位与动作性质？
- [ ] 收尾是否写明衰减与最终状态？
- [ ] 是否避免空泛词如“震撼音效”“好听音效”？
