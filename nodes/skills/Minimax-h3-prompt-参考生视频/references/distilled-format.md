# 蒸馏格式规范

## 一、完整提示词固定结构

### 1. 整体基调

一句话到三句话，包含：

- 风格类型：写实 CG / 热血动漫爆发 / 东方史诗灾难 / 国风悲情 / 玄幻封印 / 都市巨兽 / 生活流 / 科幻机甲 / 空灵唯美 / 超现实暗黑奇幻 / 预设外自定义风格
- 渲染关键词：UE5 电影渲染、HDR 光追、真实物理、电影景深、动态运动模糊
- 天光与氛围：厚重阴云、风暴天光、体积雾尘、火光烟尘、室内柔和自然光、林间薄雾等
- 色彩：黑红金、冷灰、白金圣光、暗红岩浆、暖调客厅与冷调走廊、淡紫粉等
- 节奏：干脆迅猛、蓄-冲-爆-收、克制压抑、由爆到毁、舒缓自然、静谧唯美、拉扯递进、静态对峙
- 默认补充：全程无字幕、无水印

要求：

- 整体基调必须读起来是一段**连贯描述**，不是关键词堆砌。
- 预设内风格直接套用；预设外风格按 `style-presets.md` 参数化维度生成，不强行套错预设。

### 2. 参考图绑定【2026-11-24 标签化修订】

必须分条写清（每条以 **@ImageN 标签**开头，括号内注明绑定用途，编号即参考图上传顺序）：

- @Image1（主体绑定，多主体时依次 @Image1、@Image2……）：外观、服装结构、配色、比例、识别特征、表情/气质变化边界、持续状态（如有）
- @ImageN（招式/特效绑定）：能量结构、颜色、运动形态、核心视觉
- @ImageN（目标绑定，多目标时依次顺延）：体型、**参考图实际可见的**材质与识别特征（无发光部位则不写发光；非机械/装甲形象则不写装甲）【2026-11-23 修订】
- @ImageN（场景环境绑定）：固定建筑构件、地面、天空、废墟、烟尘、火光、室内陈设
- @ImageN（道具绑定，存在剧情关键道具时）：道具形态、质感、颜色、与主体的相对位置
- @ImageN（冲击帧绑定）：严格参考本图结构，遵循 Impact Frame 规则
- 配对关系（多主体有配对关系时）：谁与谁形成什么关系
- **标签用途映射（强制，置于绑定区块末尾）**：一行写清每个标签锁定的对象与用途，格式——
  `标签用途映射：@Image1 锁定{对象与用途，如"图1男子的面部与服饰"}；@Image2 锁定{…}；@Image3 锁定{…}。`
  每个标签一句话（对象+锁定内容），与绑定行对应但不重复细节；正文/镜头/配对中的"图N"称呼一律经此映射行与 @ImageN 衔接。

写法要求：

- 用“锁定/保持/不得漂移/必须清楚可辨”约束参考一致性。
- **外观特征唯一真值 = 参考图实际可见内容**：绑定行中的每一项外观特征（装甲、发光、机械结构、披风、配饰……）都必须能在参考图中找到对应像素证据。参考图没有的特征一律不写，不得因叙事需要（巨人/怪兽/机甲等角色类型惯性）虚构补充。【2026-11-23 新增】
- **体型缩放 ≠ 外观改写**：用户要求把参考图形象放大/缩小（如“图2 角色有十层楼高”）时，只写缩放关系（“体型等比放大至约十层楼高”），外观特征仍严格取自参考图原样，不得因尺寸变化追加装甲、发光、粗糙皮肤等“巨大化标配”特征。【2026-11-23 新增】
- 允许服装被风与能量吹动破损，但不允许角色外观漂移。
- 场景构件必须说明是否固定、是否遮挡角色与特效。
- 头发/衣料状态必须写清（如“湿润微贴、发梢带水光”）。

### 2.1 编号规则【2026-11-24 标签化修订】

- **@ImageN 的 N = 参考图实际上传顺序**，从 @Image1 开始连续编号。
- **不跳号、不重复、不沿用案例原始编号。**
- 不得出现“@Image2（招式/特效绑定）→ @Image2（目标绑定）”这种一号两用。
- 不得出现“@ImageN（场景环境绑定）”不带具体编号的写法。
- 单主体标准编号：

  ```text
  @Image1（主体）→ @Image2（招式/特效）→ @Image3（目标）→ @Image4（场景环境）→ @Image5（冲击帧）
  ```

- 多主体编号示例（两主体 + 招式 + 目标 + 场景 + 冲击帧）：

  ```text
  @Image1（主体）→ @Image2（主体）→ @Image3（招式/特效）→ @Image4（目标）→ @Image5（场景环境）→ @Image6（冲击帧）
  ```

- 多目标编号示例（单主体 + 招式 + 两目标 + 场景）：

  ```text
  @Image1（主体）→ @Image2（招式/特效）→ @Image3（目标）→ @Image4（目标）→ @Image5（场景环境）
  ```

- 无冲击帧时，编号到场景环境图为止，不预留空号。
- 无招式/无目标的叙事类，编号从主体开始顺延，不硬塞空位。
- 剧情关键道具（承担转折/互动/被拿放传递的物件，如信件、钥匙、早餐、酒杯）单列为 @ImageN（道具绑定），排在场景环境绑定之后、冲击帧之前；纯装饰道具并入场景环境绑定。

### 2.2 多主体绑定写法【2026-11-24 标签化修订】

多主体时必须分别绑定、分别编号、分别写识别特征：

```text
- @Image1（主体绑定）：{主体A}，严格锁定参考图面部特征、五官比例、发型、服装结构、配饰与比例；保持{姿态/气质}，角色外观不得漂移。
- @Image2（主体绑定）：{主体B}，严格锁定参考图面部特征、发型、服装结构、配饰与比例；{特殊状态，如头发湿润微贴、发梢带水光}；角色外观不得漂移。
- 标签用途映射：@Image1 锁定图1{主体A简述}的面部与服饰；@Image2 锁定图2{主体B简述}的面部与服饰。
```

要求：

- 不得把多主体合并成一条绑定糊在一起写。
- 每个主体必须写清独立识别特征（发型、服装、配饰、比例、特殊状态）。
- 多主体同框时，镜头段必须写清前景/后景关系、谁先入画、谁抬头回应。
- 角色称呼全程统一【2026-11-24 修订】：绑定行一律用 **@ImageN 标签**；正文与配对关系用"图N"（图1、图2、图3……），经**标签用途映射行**与 @ImageN 显式衔接，不得混用描述性称呼。图号指代与 @ImageN 标签一一对应（@Image1=图1），映射行写清后正文不得再混用"主体A/左侧女人"等第三套称呼。

  错误示例（混用多套，禁止）：

  ```text
  # 绑定行丢失标签、正文混用描述性称呼——映射行无法衔接
  - 主体绑定图1：长发女人……
  - 主体绑定图2：粉色系少女……
  配对关系：主体图3与主体图2形成搂肩关系……
  镜头段：图1伏在桌边，图3搂着图2……
  ```

  正确示例：

  ```text
  - @Image1（主体绑定）：左侧女人，严格锁定参考图面部特征、发型、服装结构、配饰与比例；角色外观不得漂移。
  - @Image2（主体绑定）：右侧女人，严格锁定参考图面部特征、发型、服装结构、配饰与比例；角色外观不得漂移。
  - 标签用途映射：@Image1 锁定图1左侧女人的面部与服饰；@Image2 锁定图2右侧女人的面部与服饰。
  - 配对关系：图1与图2形成面对面扭打关系……
  镜头段：图1抓住图2的衣领……
  ```

### 2.3 多目标绑定写法

多目标时必须分别绑定、分别编号：

```text
- @Image3（目标绑定）：{目标A}，锁定体型与参考图实际可见的{识别特征：发型/服装/材质/配饰等}，保持{姿态/气质}。参考图有发光部位才写发光；没有则禁止发明。【2026-11-23 修订】
- @Image4（目标绑定）：{目标B}，锁定体型与参考图实际可见的{识别特征}，保持{姿态/气质}。
- 标签用途映射：……@Image3 锁定图3{目标A简述}的体型与识别特征；@Image4 锁定图4{目标B简述}的体型与识别特征。
```

若为同一目标的多个关键部位，可写：

```text
- @Image3（目标绑定）：{目标}，锁定体型与参考图实际可见特征；{命中部位}为本次连续命中点（命中部位必须是参考图可见的身体部位，不得虚构"核心"类器官）。
```

### 2.4 场景环境绑定写法【2026-11-24 标签化修订】

```text
- @ImageN（场景环境绑定）：{场景名称}，固定{固定建筑构件/室内陈设}、{地面}、{天空/天光}、{废墟/建筑/道具}；所有镜头发生在同一场景中；{固定构件}不漂浮、不遮挡角色与特效。
- 标签用途映射（若本图唯一未列）：@ImageN 锁定图N{场景名称}的场景环境。
```

要求：

- 必须带编号（@ImageN 的 N 与上传顺序一致）。
- 室内场景必须写清固定陈设（沙发、茶几、门框、走廊等）。
- 多空间场景（如客厅 + 洗手间）必须写清空间关系与过渡方式。

### 2.5 冲击帧绑定写法

```text
- @ImageN（冲击帧绑定）：严格参考本图结构，遵循 Impact Frame 规则；{主体招式}命中{目标关键部位}的顶点瞬间，仅{0.15–0.2}s静态定格，帧内无运动、无变形、无慢动作；主体与目标双剪影同框（各自画面方位写清、招式命中点位于两剪影之间），粗黑轮廓剪影优先于特效；结束后立刻切回写实CG。【剪影句式 2026-11-23 更新为双剪影同框强制版】【2026-11-24 标签化修订】
```

### 2.6 角色持续状态绑定

当主体处于昏迷、沉睡、被束缚、被定身、无意识、僵直、石化、被操控等持续状态时，必须在主体绑定中写明：

```text
- @ImageN（主体绑定）：{主体外观...}；全程保持{昏迷/沉睡/被束缚/被定身/无意识/僵直/石化/被操控}状态，{具体表现，如双眼紧闭、头部无力后仰、四肢自然垂落}；角色外观不得漂移。【2026-11-24 标签化修订】
```

要求：

- 持续状态必须写明“全程保持”。
- 必须写清具体表现（眼睛、头部、四肢、表情）。
- 后续每个镜头的子时间段必须重复强化该状态。
- 负面约束必须写明“全程保持XXX状态，不{睁眼/做表情变化/挣扎/自主动作}”。

### 2.7 多主体配对关系绑定

多主体存在配对关系（骑乘/承托/拉扯/并肩/对峙/拥抱/对视）时，必须在参考图绑定末尾补一条配对关系说明：

```text
- 配对关系：{主体A}与{主体B}形成{骑乘/承托/拉扯/并肩/对峙}关系；{主体C}与{主体D}形成{骑乘/承托}关系；{具体空间位置，如A跪地、B骑乘A背上}。
```

要求：

- 配对关系必须在参考图绑定阶段确立，不得只在镜头里补。
- 必须写清谁在上/谁在下、谁在左/谁在右、谁主动/谁被动。
- 后续镜头段必须保持该配对关系不漂移。

### 3. 叙事顺序

用箭头写清镜头叙事链，例如：

`环境/主体特写 → 主体蓄能近景 → 招式突进 → 命中冲击帧 → 破坏反馈 → 收尾`

生活流/多主体类：

`客厅主体静坐起幅 → 另一主体从另一空间走出 → 沿走廊走向客厅 → 客厅主体抬头回应 → 双人同框收尾`

连续动作类：

`环境底噪与风暴天光 → 第一组机甲坠落硬着陆 → 第二组机甲坠落硬着陆 → 第三组与第四组连续坠落 → 多主体同框压迫收尾`

多主体对峙/拉扯类：

`全景三人对峙起幅 → 左侧角色抱住左臂争抢 → 右侧角色抱住右臂争抢 → 三人同框拉扯收尾`

多主体垂直层级类：

`低机位环境起幅 → 多主体关系全景确立 → 左侧关系近景 → 右侧关系近景 → 多主体同框压迫收尾`

无叙事特写时，可写：

`主体蓄能 → 招式爆发 → 目标命中 → 冲击帧 → 破坏反馈 → 远景收束`

### 3.1 多主体空间关系写法

多主体空间关系必须写清：

- **并排同行**：谁在左、谁在右、步伐是否一致、视线朝向
- **前后景**：谁在前景虚化、谁在后景清晰
- **垂直层级**：谁在上、谁在下、谁承托谁、谁骑乘谁
- **对称构图**：谁在左、谁在中、谁在右、左右是否对称互动
- **对峙构图**：三人/多人并排站立，视线如何交汇

标准写法：

```text
{主体A}与{主体B}并排站立/同行，{主体A}在左，{主体B}在右，步伐节奏一致，视线平视前方。
```

```text
{主体A}与{主体B}并排双膝跪地，脊背挺直；{主体C}跨坐在{主体A}背上，{主体D}跨坐在{主体B}背上，四主体形成前后景纵深关系。
```

```text
{主体A}、{主体B}、{主体C}三人并排站立，{主体B}在正中，{主体A}与{主体C}分列两侧，形成对称对峙构图。
```

### 3.2 多主体互动关系写法

多主体互动关系必须写清：

- **拉扯关系**：谁拉谁、拉哪个部位、谁被动、身体如何倾斜
- **承托关系**：谁承托谁、承托部位、承托方姿态
- **骑乘关系**：谁骑乘谁、骑乘方姿态、被骑乘方姿态
- **拥抱关系**：谁抱谁、抱哪个部位、抱紧程度
- **对视关系**：谁看谁、视线方向、表情变化

标准写法：

```text
{主体A}双手紧紧抱住{主体B}的左臂，身体向{主体B}倾斜，用力将左臂向自己方向拉扯，{主体B}身体被带得微微倾斜。
```

```text
{主体C}跨坐在{主体A}背上，双手轻扶{主体A}肩部，{主体A}保持跪地承受姿态，脊背挺直。
```

### 3.3 多主体同步动作写法

多主体同步动作必须写清“同时/分别/交替/轮流”：

- **同时动作**：写“{主体A}与{主体B}同时{动作}”
- **分别动作**：写“{主体A}{动作A}，{主体B}{动作B}”
- **交替动作**：写“{主体A}先{动作A}，{主体B}随后{动作B}”
- **轮流动作**：写“{主体A}与{主体B}轮流{动作}”

标准写法：

```text
{主体A}与{主体C}同时转头看向{主体B}，视线交汇，争抢气氛开始升温。
```

```text
{主体A}与{主体C}同时用力，{主体B}身体左右微晃，三人形成对称拉扯构图。
```

### 4. 分镜时间轴

每个镜头必须包含：

- 标题：`镜头N｜起–止s｜一句镜头目标`
- 机位：低角度仰拍、贴地跟拍、侧前方近景、高机位俯拍、侧后方中景、贴近地面低角度平视等
- 构图：主体位置、目标占比、背景关系、前景/后景关系、垂直层级
- 光照：侧逆光、冷暗光、圣光、火光、体积光、室内自然光、冷雾边缘光
- 镜头运动：固定、手持微晃、推近、拉远、跟拍、横移、环绕、硬切（运镜选型与标准句式见 `references/camera-motion-layer.md`；复杂运镜如环绕/子弹时间必须写清圈数+时长）
- 子时间段：动作、镜头、特效、转场逐段描述

子时间段要求：

- 从 0.0s 开始
- 时间段连续、不重叠
- 每段只写 1–3 个核心动作
- 硬切、发动切镜点、冲击帧、硬着陆必须明确标出
- 运镜用标准句式（正向化，不用裸否定），复杂运镜（环绕/子弹时间/翻滚/螺旋）必须给圈数+时长
- 角色持续状态必须在每个子时间段重复强化

### 4.1 多主体分述镜头写法

多主体复杂关系场景，镜头必须按“全景确立关系 → 分主体近景 → 回到同框”的结构分述：

```text
镜头N｜X–Y s｜多主体关系全景确立
机位切至侧前方中景，{主体A}与{主体B}并排{姿态}，{主体C}与{主体D}分别{姿态}，形成{空间关系}。
- X–a s：镜头横移展现{关系}，{具体动作细节}。
- a–Y s：{主体A}与{主体B}保持{姿态}，{主体C}与{主体D}视线平视前方，冷光勾勒四者轮廓。

镜头N+1｜Y–Z s｜{主体A}与{主体C}近景
硬切至{主体A}与{主体C}侧前方近景，{主体A}{外观细节}，{主体C}{外观细节}，{主体C}身体随{动作}轻微起伏。
- Y–b s：镜头缓慢环绕，{主体A}侧脸{表情}，{主体C}低头看向{主体A}{部位}。
- b–Z s：{主体C}抬手轻触{主体A}{部位}，{主体A}{微反应}，保持{姿态}不动。

镜头N+2｜Z–W s｜{主体B}与{主体D}近景与多主体同框收尾
```

### 5. 冲击帧段

独立成段，必须写明：

- 时间与时长：通常 0.15–0.2s
- 静态定格，帧内无动画、无变形、无慢动作
- 只表现单次命中顶点，不表现爆炸、撕裂、碎片飞散过程
- 中心爆闪、放射纹路、环形冲击波、墨渍飞溅、边缘色散等按需
- 主体与目标双剪影同框（含各自方位与招式接触关系），粗黑轮廓剪影优先于特效【2026-11-23 新增】
- 荷兰角倾斜、高张力构图
- 结束后立刻切回写实 CG，再开始破坏反馈

### 5.1 冲击帧适用范围边界

**适用：**

- 单次招式命中顶点
- 单次封印命中顶点
- 单次碰撞/撞击顶点
- 单次处刑命中顶点

**不适用：**

- 连续硬着陆、连续坠地
- 穿透式双硬着陆（单主体砸穿一层再落到下一层）
- 连续多次命中
- 环境叙事、情绪特写
- 纯氛围镜头
- 慢动作过程
- 爆炸/撕裂/碎片飞散过程
- 生活流、日常动作、视线交汇
- 多主体依次入场/依次坠落

连续动作类应使用“硬切 + 动作峰值音效”，不插入静态冲击帧。

### 5.2 并列硬着陆 vs 穿透式硬着陆

| 类型 | 示例 | 处理方式 |
| --- | --- | --- |
| 并列硬着陆 | 四组机甲依次坠地 | 每次硬着陆独立标注【硬着陆】时间段、独立配置【硬着陆峰值】 |
| 穿透式硬着陆 | 单主体砸穿屋顶 → 继续下坠 → 砸向地面 | 每次硬着陆独立标注【硬着陆】时间段、独立配置【硬着陆峰值】，镜头段写清“穿透后继续下坠”因果链 |

两种均不做静态冲击帧。

### 6. 音效设计

默认写：

`音效设计（无BGM，电影分层混音，峰值卡点对准XX）`

必须覆盖：

- 环境底噪
- 蓄能/电流/蒸汽/风声/室内自然声场
- 发动与硬切同步音
- 峰值层：短促爆音、黑切静音、低频重击（有冲击帧时）
- 破坏反馈：碎裂、冲击波、碎片、沙尘、脚步、衣料
- 收尾衰减至静默或低频余震

无冲击帧场景不得留空峰值，必须按以下四类之一处理：

**环境叙事类 / 情绪特写类：**

```text

- 4.0–4.6s【音效峰值】：脚步停稳的轻响与两人视线交汇同步，道具落下轻响，室内环境声短暂收紧，极短，一击即收。
```

**纯动作类 / 连续硬着陆类：**

```text

- 1.2–1.5s【硬着陆峰值】：低频重击、地面碎裂、烟尘爆开，极短，一击即收。
- 2.2–2.8s【硬着陆峰值】：低频重击、地面二次碎裂、火花溅射音，极短，一击即收。
```

## 三、子时间段写法

标准格式：

```text
- 起–止s：动作、镜头、特效描述。
```

示例：


- 每个子时间段只写 1–3 个核心动作
- 时间段连续、不重叠
- 关键节点用【】标出，如【发动切镜点】【冲击帧】【硬着陆】【音效峰值】
- 角色持续状态必须在每个子时间段重复强化

## 四、硬切与转场写法

可用句式：

- `硬切转场，……`
- `硬切进入……`
- `发动瞬间硬切，切入……`

- 每个硬切点必须在音效设计中标注【切镜同步音效点】或写明切镜同步音效（不限于冲击帧场景）

## 五、多主体场景写法

### 5.1 多主体并排同行


### 5.2 多主体对称对峙 + 双向拉扯

```text

- 子时间段：写清左右角色分别抱哪只手臂、向哪个方向拉扯、中间角色如何被动倾斜。
```

### 5.3 多主体垂直层级 + 骑乘/承托

```text

- 子时间段：写清承托方姿态、骑乘方姿态、谁轻扶谁肩部、谁身体前倾。
```

### 5.4 多主体同框收尾

```text
机位切至{空间}侧后方中景，{主体A}在前景略虚化，{主体B}在侧后方并肩同行，形成前后景关系。

```

## 六、连续动作/硬着陆写法

连续硬着陆、连续坠地必须写清：

- 每次坠落单独成段或单独子时间段
- 每次硬着陆单独标注【硬着陆】时间点
- 每次硬着陆单独配置音效峰值
- 不做静态冲击帧
- 每次硬着陆后可用硬切或镜头快速拉远转场

标准写法：

```text
- X–Y s：{主体}高速下坠，镜头{机位}，{环境}被气流卷起。
- Y–Z s【硬着陆】：{主体}重砸地面，地面碎裂，烟尘/火花/冲击波爆开，硬切转场。
```

对应音效：

```text
- Y–Z s【硬着陆峰值】：低频重击、地面碎裂、烟尘爆开，极短，一击即收。
```

### 6.1 穿透式硬着陆写法

单主体砸穿一层结构后继续坠落到下一层：

```text
- X–a s：主体高速逼近{第一层结构}，{构件}在画面中迅速放大，气流卷起碎屑。
- a–Y s【硬着陆】：主体重砸{第一层结构}，{构件}瞬间碎裂，碎屑与烟尘向四周爆开，主体穿过破洞继续下坠。

```
