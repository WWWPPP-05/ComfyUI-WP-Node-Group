# 通用优化示例

本文件不含参考案例专有角色、台词、牌匾文字与道具符号，只演示“简短指令 → 完整提示词”的扩写方式。

示例覆盖 8 类结构：

1. 单主体 + 单目标 + 单次命中 + 冲击帧
2. 环境叙事 + 无冲击帧 + 情绪峰值
3. 多主体 + 生活流 + 视线交汇峰值
4. 多主体 + 连续硬着陆 + 多动作峰值
5. 单主体持续状态 + 穿透式双硬着陆
6. 多主体并肩同行 + 奇幻跨界
7. 三主体对称对峙 + 喜剧张力峰值
8. 预设外自定义风格

每个示例都演示：参考图连续编号、冲击帧适用性判定、无冲击帧峰值处理、多主体/多动作写法、角色持续状态、配对关系、风格三层决策。

## 示例 2：环境叙事 + 无冲击帧 + 情绪峰值


- 风格决策：预设 B（国风悲情写实）。
- 无命中顶点，**不插入冲击帧**。
- 参考图编号到场景图、道具图为止，无冲击帧空号。
- 音效峰值对准“痛苦情绪顶点”，不是冲击帧。
- 牌匾文字用“场景固定牌匾”替代，不臆造具体文字。

## 示例 3：多主体 + 生活流 + 视线交汇峰值
