# 扩充维度详细清单

本文件详解 8 个扩充维度的填写要求，提供**各类视角**的可见性规则，以及**面部朝向的语境推断表**。

***

## 8 维度详解

### 维度 1 — 镜头与视角

**必答：** 从以下四个子维度选定：**视点类型 + 机位角度 + 景别 + 镜头类型 + 运镜**。

**参考** **`viewpoint-style-theme.md`** **的视角清单。** 例：

- "第一人称 POV，平视机位，中近景，标准焦段，固定镜头"
- "过肩镜头 OTS，略微俯视，中景，长焦压缩空间，跟随运镜"
- "第三人称客观，荷兰角倾斜，全景，广角，固定镜头"
- "鸟瞰/上帝视角，顶视机位，大远景，广角，固定镜头"

### 维度 2 — 构图与空间

**必答：** 主体在画面什么位置？前/中/后景如何分层？特定视角下观察者/摄影机位置对应什么空间关系？

### 维度 3 — 光影

**必答：** 光源方向？色温（暖/冷/中性）？软硬（柔光/硬光）？高光阴影分布？

### 维度 4 — 环境细节

**必答：** 具体空间类型？可见的家具/道具/背景元素？

### 维度 5 — 面部朝向 + 肢体动作（强化）

**必答（人物可见时）：** 本维度拆分为两个独立子项，**都必须显式描述**。缺失任何一项 = 扩充不足。

#### 5.1 面部朝向（必填）

**为什么必须显式描述：**

扩散模型有强烈的"面部正对镜头"训练偏差，若提示词不显式描述面部朝向，模型会默认让角色正脸朝向镜头——即使场景需要侧脸或低头。

**但反过来，如果为了"避免正脸"而总是选择侧脸，也会导致结果偏离场景语境。**

**正确的做法：由场景语境决定面部朝向，明确选择一个符合语境的朝向。**

**可选词（从中明确选择一个）：**

- 正对镜头
- 四分之三侧脸（左/右）
- 侧脸（左/右）
- 低头（俯视）
- 抬头（仰视）
- 转头看向 \[方向]
- 望向画面外
- 视线朝向 \[某处]
- 闭眼
- 眼神下垂
- 眼神斜向
- 越过镜头看向 \[方向]

**优先级：**

1. **用户明确指定** → 严格按用户。
2. **用户没说但语境暗示** → 按下方「面部朝向语境推断表」推断。
3. **用户完全没说，语境也无暗示** → 使用符合场景的合理朝向。**正面、侧面、低头、抬头都是合理的，关键是符合语境。**

#### 面部朝向语境推断表（平衡版）

**按四类分组，让正面、侧面、低头抬头、闭眼各类场景都有覆盖。**

##### 【正面类】应该正对镜头

| 场景线索                   | 面部朝向建议       |
| :--------------------- | :----------- |
| 拍摄肖像 / 证件照 / 头像 / 封面   | 正对镜头，目光看向镜头  |
| 直接对视镜头（POV 或合影）        | 正对镜头         |
| 双人对话 / 互动              | 正对镜头或四分之三侧脸  |
| 表达情绪（微笑、惊讶、生气直视）       | 正对镜头，情绪明确    |
| 唱歌 / 演讲 / 主持 / vlog 出镜 | 正对镜头或四分之三侧脸  |
| 化妆 / 美容 / 展示妆效         | 正对镜头         |
| 时尚大片 / 商业摄影（要求看镜头）     | 正对镜头         |
| 美食评测 / 产品推荐            | 正对镜头         |
| 表情特写                   | 正对镜头         |
| 打招呼 / 告别               | 正对镜头         |
| 家族照 / 团队照 / 合影         | 正对镜头         |
| 递物给镜头（POV 递咖啡等）        | 面部朝向观察者，正对镜头 |
| 主持 / 直播 / 出镜           | 正对镜头         |
| 证件照 / 护照 / 身份证         | 正对镜头，平视      |
| 演员试镜 / 定妆照             | 正对镜头或四分之三侧脸  |

##### 【侧面类】应该侧脸或四分之三侧脸

| 场景线索            | 面部朝向建议              |
| :-------------- | :------------------ |
| 看窗外 / 看远方 / 看日落 | 四分之三侧脸或侧脸，目光望向画面外   |
| 走路 / 跑步 / 散步    | 侧脸或背影，视线朝向前方        |
| 与人对话时看向对方       | 四分之三侧脸，目光朝向对方（不是镜头） |
| 沉思 / 思考         | 四分之三侧脸，眼神下垂或望向别处    |
| 看表演 / 看展览       | 四分之三侧脸，目光朝向展品       |
| 驾驶              | 侧脸，视线看向前方           |
| 运动 / 舞蹈         | 根据动作方向              |
| 演奏乐器            | 根据乐器（钢琴低头、小提琴侧脸）    |
| 手工艺 / 工作 / 操作工具 | 四分之三侧脸或低头           |
| 读书（并非低头特写）      | 四分之三侧脸，视线落在书页       |
| 摄影中的侧拍          | 根据姿势，通常侧脸或四分之三侧脸    |
| 舞台表演（非直接唱段）     | 根据表演方向              |

##### 【低头类】应该低头

| 场景线索             | 面部朝向建议      |
| :--------------- | :---------- |
| 低头看书 / 看手机 / 看图纸 | 低头，视线向下     |
| 做饭 / 操作工具        | 低头看向操作区域    |
| 喝咖啡 / 喝茶 / 吃东西   | 低头看向杯/食物    |
| 写作 / 手账 / 绘画     | 低头，视线落在纸面   |
| 化妆（自己给自己化妆）      | 低头或平视，看镜中   |
| 打字 / 用电脑         | 平视或低头，看向屏幕  |
| 悲伤 / 情绪低落        | 低头或眼神下垂     |
| 害羞 / 撒娇          | 低头或侧脸，眼神斜向上 |

##### 【抬头 / 闭眼类】

| 场景线索     | 面部朝向建议       |
| :------- | :----------- |
| 睡觉 / 休息  | 闭眼，侧卧或仰卧     |
| 冥想 / 放松  | 闭眼或半睁        |
| 仰望 / 惊叹  | 抬头，眼睛睁大      |
| 唱歌（高潮段落） | 抬头或略微仰视      |
| 吹奏乐器     | 低头或平视，专注于乐器  |
| 照镜子      | 看向镜中方向       |
| 亲吻（亲密场景） | 闭眼或眼神柔和      |
| 拥抱       | 侧脸或闭眼，头部贴向对方 |
| 祈祷       | 低头或闭眼        |
| 思考难题     | 眼神下垂或望向远处    |

**注意：** 表格中的场景**不强制**对应唯一的朝向，只是**推荐倾向**。核心原则是——**所选朝向必须与场景语境逻辑自洽**。

#### 5.2 肢体动作（必填）

**必须描述：** 手臂位置、手部动作、腿部姿态、身体倾斜方向、与环境的接触点。

**示例词：**

- 手臂：自然下垂 / 交叉抱胸 / 一只手撑在桌面 / 双臂伸展 / 手肘支撑 / 双手插兜
- 手部：手指自然弯曲 / 握拳 / 轻轻搭在 X 上 / 指尖触碰 X / 掌心向上 / 托腮
- 腿部：双腿并拢 / 双腿交叠 / 盘腿 / 单腿弯曲 / 站立 / 踮脚
- 身体：略微前倾 / 后仰 / 侧倾 / 挺直 / 放松
- 接触点：与椅背、桌面、地面、另一人身体的接触点

### 维度 6 — 情绪与氛围

**必答：** 整体色调？情绪（温馨/暧昧/活泼/宁静/克制/紧张/空灵）？

### 维度 7 — 材质与细节

**必答：** 服装、头发、皮肤、环境材质的质感？

### 维度 8 — 视角可见性（场景重建任务）

**根据选择的视角，应用对应规则。** 见下方。

## 各视角的可见性规则

### 第一人称 POV

**核心原则：摄像机就是观察者的眼睛。只描述取景框内的内容。**

| ❌ 错误做法              | ✅ 正确做法                            |
| :------------------ | :-------------------------------- |
| "双手在镜头后方的颈侧交握"      | "她的双臂从画面左右两侧伸入前景，前臂轮廓在画面边缘可见"     |
| "她的身体紧贴我的胸膛"        | "她的身体从画面中央向前倾，上半身占据画面主要区域"        |
| "她的双腿盘在我腰上，脚踝在身后交叉" | "她的双腿从画面下方两侧进入前景，膝盖在画面下缘可见"       |
| "我的双手环住她的腰"         | "观察者的双手从画面下方伸入，环抱在她的腰侧，手部在画面前景可见" |
| "她转头看向我身后"          | "她的目光越过镜头，视线朝向画面侧后方"              |

**观察者（"我"）描写原则：**

- 只描写镜头可见部分（伸入画面的手、双腿、膝部、前臂）。
- 不描写观察者完整的身体、动作或位置。
- 存在感通过"画面边缘的手部""下三分之一的前景腿部""环抱动作的视觉暗示"建立。

### 过肩镜头 OTS

**核心原则：摄影机位于一个角色的肩后，拍向另一个角色。前景可见该角色的肩部/头部背面。**

- **必写**：前景角色的肩部/头部背面轮廓（虚化或清晰）
- **必写**：被拍角色的面部朝向、上身
- **不写**：前景角色看不见的表情、远处的背景细节

### 第三人称客观

**核心原则：摄影机独立于所有角色，可自由选择机位。** 无特殊可见性限制，但需注意**机位角度与景别一致**（俯拍时不能描述平视才能看到的内容）。

### 半主观视角

**核心原则：摄影机靠近某角色，带有该角色的视角倾向，但不完全等同于其眼睛。**

- 可描写被跟随角色的可见部分
- 可描写该角色视线方向看到的内容
- 不描写该角色背面的细节

### 鸟瞰 / 上帝视角

**核心原则：摄影机在高空俯视。所有内容从上方看。**

- **必写**：地面、头顶、俯视可见的空间关系
- **不写**：平视才能看到的面部表情、侧面轮廓、竖直方向的细节
- **面部朝向**：只能描述"头顶朝上""面部朝下"或"面部被阴影遮挡"等俯视可见的朝向

### 反打镜头

**核心原则：与前一镜头方向相反，拍摄对话的另一方。** 与 OTS 类似但更强调"对话对象的反应"。

### 反应镜头

**核心原则：拍摄某角色对另一事件/角色的反应。** 只描述反应者的可见表情、姿态，背景中触发反应的事件可虚化或部分可见。

### 俯视 / 仰视 / 荷兰角 / 顶视 / 底视

按机位角度处理，与视角类型组合使用：

| 角度  | 特殊规则                |
| :-- | :------------------ |
| 俯视  | 不写平视才能看到的面部细节；阴影向下  |
| 仰视  | 主体显高大；不写头顶细节        |
| 荷兰角 | 画面倾斜，水平线不平行于画框      |
| 顶视  | 只写俯视可见；无面部表情（除非大特写） |
| 底视  | 只写仰视可见；常见于人物脚部向上    |

## 视角选择自检

- 是否从 `viewpoint-style-theme.md` 清单中根据用户输入选择了视角？
- 是否**没有误用 POV** 作为默认？
- 视角描述是否包含：视点类型 + 机位角度 + 景别 + 镜头类型 + 运镜？
- 是否应用了对应视角的可见性规则？
- 场景重建任务的所有描述是否通过该视角的"摄像机能拍到吗"检查？

***

## 面部朝向 + 肢体动作自检

**铁律 5 的执行检查：**

- 输出中是否包含可见人物？
- 如果包含：
  - **面部朝向**是否明确写出？（不能留空让模型默认）
  - 面部朝向是否**从铁律 5 的可选词中明确选择了一个**？
  - 如果用户**明确指定**了面部朝向 → **是否严格按用户**？
  - 如果用户**没指定** → **是否按语境推断了合理朝向**？（**没有无脑偏向侧脸，也没有无脑偏向正脸**）
  - **肢体动作**是否明确写出？（手臂、手部、腿部、身体、接触点）
  - 如果用户**明确指定**了肢体动作 → **是否严格按用户**？

**⚠️ 特别注意：** 面部朝向的选择**不是"避开正脸"或"避开侧脸"**，而是**选择与场景语境最匹配的那一个**。证件照、对话、唱歌、表情特写等场景用正脸是对的；看窗外、走路、沉思等场景用侧脸是对的。**不存在"哪种朝向更安全"的默认答案。**

## 维度覆盖自检表

对每个"构造式"任务，逐项打勾：

- 镜头与视角已明确（视点 + 角度 + 景别 + 镜头 + 运镜）
- 构图与空间已明确（主体位置 + 前后景）
- 光影已明确（方向 + 色温 + 软硬）
- 环境细节已明确（空间类型 + 可见元素）
- **面部朝向**已明确（语境匹配 + 用户优先）
- **肢体动作**已明确（手臂 + 手部 + 腿部 + 身体 + 接触点）
- 情绪与氛围已明确（色调 + 情绪）
- 材质与细节已明确（服装 + 头发 + 皮肤 + 环境）
- 视角可见性规则已应用
